# 界面设计方向

各端后续改造以 [UI 设计基准及可运行原型](../../docs/design/README.md) 为准，采用中性黑白灰、轻量表面与明确的消息／工具／确认层级，替代此前中性灰配蓝色强调的视觉方向。先改造 Web，随后适配 Electron 与手机；翻书登录页保留。色值与组件规则只在设计基准维护。

视觉一致不要求各端共用 CSS。Web 保持 CSS Modules；Electron 与未来移动端各自实现，按输入方式、窗口和平台能力适配，不联动私有样式。

原有业务原则继续保留：全局导航、设置子导航与会议页签各承担一级职责；已结束会议默认纪要，录音中默认实时文字。录音跨页连续，播放器保持唯一实例，服务编辑保留草稿；会议通过纪要、原文和音频关联回顾，`Cmd/Ctrl+K` 命令面板复用已有操作。视觉改造不改变权限、IPC 信任边界、真实接口或数据位置，也不额外引入重复 UI 库。
