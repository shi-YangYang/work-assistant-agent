# 项目关键决策

这里保留影响后续开发的取舍。工程位置与依赖见[技术栈](../../constitution/tech-stack.md)，模块职责见[架构说明](../../docs/architecture.md)，具体功能约定见对应 Spec；变更历史查 Git。

## 产品与工程边界

- 公司 Web 负责工作协作，适配电脑和手机浏览器；Electron 负责本地会议，无需启动公司服务，暂不建设独立手机 App。
- 桌面同时支持 macOS／Windows，平台差异放在适配层，分别验证；一个平台通过不能代表另一个平台通过。
- Web、桌面和服务端同仓库、独立运行与构建。`packages` 只放实际共用的契约、模型参数、品牌和声纹引擎，不反向依赖应用，也不共享私有 CSS。
- Node 使用 npm workspaces 和根锁文件，Python 环境按应用分开；配置就近维护，不提前引入 Nx／Turborepo、空移动工程或重复治理目录。

## 桌面运行与数据

- Electron main 管理窗口、权限和无 shell 的 Python 子进程，通过带请求 ID 的 UTF-8 JSON Lines／stdio 通信，音频不进控制消息。renderer 只能使用受限、类型化的 preload 接口。
- 本地使用 SQLite 和文件，数据根为 Electron userData，数据库记录相对路径；不增加桌面 HTTP 服务或 PostgreSQL。播放只通过授权会议资源。
- 安装包自带 Python 核心及依赖，只启动包内资源，缺失则报错，不回退系统 Python。开发可用 `.venv`／`PAA_PYTHON`，用户界面不提供解释器配置；发布验证无预装 Python／Node 的启动、资源路径和进程退出。
- 会议搜索采用有界分页的本地关键词查询，转义通配符并支持短汉字；不强制 FTS5 trigram，也不引入语义搜索。用户会议名与 AI 纪要标题分开，改名不改变引用或重生成纪要。
- 导出由 main 打开系统保存框，核心提供完整快照。永久删除需确认并协调任务、文件和数据库；测试不得删除用户既有会议。

## 录音与本地转写

- 默认麦克风、一次一场会议，不采集系统声音或录制中换设备。录音回调只入有界队列，由独立线程写单声道 PCM16 WAV，保留实际采样率，不在内存累计整场音频。
- 暂停不补静音，继续追加同一文件；时长和文字定位按累计音频时间计算。正常退出先保存，异常保留源文件和完整帧，恢复失败可重试。
- Whisper 默认 small／中文，支持英文和中英混合，不翻译。用户主动下载固定来源、revision 和 SHA256 的模型，校验并加载成功才就绪；推理不回退云端。
- 全局一次受管推理，活动录音优先，积压落到 WAV 和检查点。任务固定模型、语言、设备及解码配置；重转写成功才原子替换，失败保留旧文字与纪要，不自动重跑历史任务。
- CPU 用 CTranslate2，Windows NVIDIA 用 CUDA，Apple Silicon 用 MLX；默认优先可用 GPU，保留用户 CPU 选择，旧任务缺设备字段按 CPU 处理。MLX 与 CTranslate2 权重分开，Windows CPU／CUDA 共用权重。
- 按 VAD 区间解码，只用通用提示，不喂参考稿。质量与内存指标使用固定公开真人语料；不同设备、文件推理和麦克风回采分别记录，不互相替代。

## 模型服务与凭证

- 桌面纪要和公司聊天使用 OpenAI 兼容 Chat Completions，不自动切换 Responses。可保存多家服务、手动添加模型；目录可见或文本连通不代表有调用权限、参数兼容或报告可用。
- 桌面选一家服务生成纪要；公司聊天与周报共用文字模型，语音转写和图片生成独立配置。按协议适配，不堆厂商型号枚举，不做隐式路由、故障切换或降档。
- 推理设置按服务／模型保存，支持强度字符串或受限 JSON；自定义参数不能覆盖输入、凭证、模型、工具及传输控制。不为探测支持情况额外付费调用，不隐式重试结果不确定的付费请求。
- 公司任务固定协议与配置快照，配置变化使旧检测失效，不用新模型续跑旧工具步骤。用量记录调用时模型和真实返回值，缺失保持未知，估算不冒充实际用量。
- 桌面密钥由 safeStorage 加密，无明文回退；公司凭证用服务端主密钥加密，API／worker 共用密钥文件，与数据库分开备份、配对恢复，不读取桌面密钥。
- 生成纪要只发送所选文字，录音留在本地。程序校验结构、引用和限制；格式正确不代表事实准确。公司聊天、图文和短语音使用外部服务，不默认部署服务器本地大模型或 ASR。

## 公司协作与授权

- 会话是入口，正式成果落到工作、报告等业务记录。仅管理员、员工两类角色；管理员保留本人助手和督办，可看员工已提交上报，不代员工改工作或分派任务。
- 管理员配置汇报安排，员工审阅后提交；没有已确认工作不等于免交，未上报不等于没工作。画像须有依据且可纠正，不做设备监控；站内提醒不调用模型，反馈独立于业务消息和记忆。
- 公司使用 PostgreSQL、私有附件卷、API 和单 worker，任务有界并发、同成员串行。Redis 只存生成中的正文流与恢复快照，不承担业务持久化；不引入 Celery 或向量库。
- Deep Agents／LangGraph 负责运行，harness 管理工具、权限、状态、恢复与人工确认。默认关闭宿主文件、shell、任意网络和子 Agent 能力，不提供任意 SQL。
- 身份来自真实会话与成员关系，工具清单不代替数据授权。员工只查本人资料；管理员团队问答只用已确认业务和关联来源。每次读写仍校验公司、所有权、来源与版本，ID／URL 不是凭证。
- 明确指令可直接创建或修改本人工作、报告草稿，模型推断的进展需确认；提交、删除是否再次确认由账号执行模式决定。角色、来源、操作授权始终校验，报告经服务端校验后事务保存。
- 权限贯穿模型输入、回答、摘要、缓存、checkpoint 和待执行操作；撤权或删除后重新检查，不从旧缓存恢复越权内容。删除会话保留业务来源；管理员删报告清理关联原材料，不递归删除其他已确认工作或报告。

## 材料与来源

- 原件保存在私有持久目录，数据库记录归属、版本、分段和定位，后续可换对象存储。原件、预览、解析结果都检查访问权限，不提供匿名下载。
- 解析在受限子进程运行，限制时间、内存和解压规模。优先提取原生文字和可见表格；需要图像理解时向主模型提供实际页面，不另加 OCR 或图片描述模型。
- 不执行宏或表格公式，XLSX 只读已有数据及公式缓存；旧 Office／RTF／ODF 转换后读取。PDF.js 本地预览，图片处理方向和格式时保留原件；原件、提取结果、模型回答分开保存，回答保留来源。

## 公司声纹与离线使用

- 公司地址由部署者配置，正式连接要求有效 HTTPS；游客仍可录音、转写、生成纪要和手动命名。桌面不自动上传会议、同步密钥或迁移用户资料。
- 管理员在员工知情授权后登记单人录音，只同步本公司姓名和声纹；声纹不用于认证或业务授权。固定 WeSpeaker 模型，不按员工训练；登记与匹配使用兼容模型和预处理版本，原录音私有，模板关联账号，不入 Git。
- 可靠匹配后更新姓名和发言，会后校正保留人工修改；低可信保留编号。缓存按服务、公司、账号隔离，离线和令牌过期不清空，退出账号或主动清缓存才删除；服务端不能撤回已离线副本。

## 界面原则

- 各端共享中性黑白灰与清晰的消息、工具、确认层级，独立维护 CSS，不重复引入 UI 库；色值见[设计规范](../../docs/design/README.md)，保留翻书登录。
- 录音跨页连续、播放器唯一、编辑保留草稿；录音中默认文字，结束后默认纪要，纪要／原文／音频联动。视觉调整不改变权限、IPC、接口和数据位置。
