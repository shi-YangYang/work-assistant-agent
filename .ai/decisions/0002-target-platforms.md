# Decision — 目标平台包括 macOS 和 Windows

日期：2026-09-09

## Context

最初的产品背景以 MacBook 会议场景为例，项目骨架沿用了 macOS 平台表述。用户随后明确澄清：“不一定只运行在macos上，windows上也是可以的”。

## Decision

- 产品目标平台包括 macOS 和 Windows，后续设计不得将产品限定为 macOS 专用。
- macOS 是当前开发环境，须与产品目标平台区分。
- 将用户与录音流程中的设备表述统一为个人电脑和电脑麦克风。
- 技术选型考虑两个平台的兼容性，核心业务逻辑与必要的平台差异解耦。
- 具体系统版本、硬件范围、平台验证计划和交付安排尚未确定。
- 本次仅修正骨架文档与产品约束，不创建具体 Spec 或业务实现。

## Reason

用户当前的平台澄清优先于原始背景中的设备示例。持久记录这一约束，避免后续 Agent 将当前开发环境误当作唯一产品运行平台。

## Alternatives

- 继续限定为 macOS 专用：不符合用户澄清。
- 只修改聊天中的理解：会在仓库文档中保留错误的平台约束。

## Consequences

- README、项目使命、路线图和技术约束同步使用新的平台范围。
- 后续评估录音、ASR、UI、路径处理与打包方式时，需要考虑 macOS 和 Windows 的适配及验证。
- 当前仍是项目骨架，没有应用运行能力；平台目标不代表已经实现或验证双平台支持。
- 本次没有确定双平台同步交付要求，也没有扩大其他 MVP 功能范围。
