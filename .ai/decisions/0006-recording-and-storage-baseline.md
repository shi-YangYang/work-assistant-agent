# 原生录音与本地存储

- 使用系统默认麦克风，一次一场会议；不采集系统声音，不在录制中换设备。
- Python RawInputStream → 有界队列 → WAV 写入线程；回调不执行磁盘、数据库或推理任务，不在内存累计整场音频。
- 原始录音保存单声道 PCM16 WAV，保留实际采样率；转写端自行重采样。
- SQLite 保存元信息和相对路径，数据根为 Electron userData；播放只通过授权会议资源。
- 正常退出先保存；异常保留源文件和完整帧，恢复失败仍可重试，不能清库或假报完成。

## 暂停时间轴

暂停不补静音，继续时追加同一音频。录音时长与文字定位采用累计音频时间，不包含暂停时长。
