# 公司协作与业务 Agent

## 产品方向

- 先打通员工材料、可纠正进展、日报／周报和团队看板；会话是入口，正式结果落到业务记录。
- 仅管理员和员工两类角色。管理员保留本人工作助手与督办，不代员工修改工作。
- 管理员可查看公司员工已发送的上报；Agent 团队问答只使用已确认业务及关联材料。
- 删除会话保留业务来源；管理员删除报告清理关联原材料，不递归删除其他已确认工作或报告。
- 汇报安排由管理员配置，员工审阅后提交；没有已确认工作不等于免交。站内提醒不调用模型，问题反馈独立于业务消息和记忆。
- 画像必须有依据、可纠正，不做设备监控，未上报不等于没工作。

## 客户端与运行方式

- Web 适配电脑和手机浏览器，身份与权限由共享后端统一管理；暂不建设独立手机 App。
- Electron 保留本地会议，不自动上传会议、同步密钥或迁移用户资料。
- 公司使用 PostgreSQL、私有附件卷、API 和单 worker 进程；任务有界并发，同成员串行，不额外引入 Redis、Celery 或向量库。

## 桌面登录与公司声纹

- 公司地址由部署者配置，不写死 IP；正式连接使用有效 HTTPS。游客仍可录音、转写、生成纪要和手动命名。
- 管理员在员工知情授权后登记单人录音，仅管理员可同步本公司的姓名和声纹；声纹不能作为身份认证或业务授权。
- 使用固定 WeSpeaker 模型，不按员工训练；登记和匹配使用兼容的模型与预处理版本。原录音私有保存，模板与账号关联保存在数据库，不入 Git。
- 录音中匹配可靠后更新姓名和对应发言，会后校正并保留人工修改；低可信时保留说话人编号，不承诺即时准确。
- 缓存按服务、公司、账号隔离，长期离线可用；断网或令牌过期不清空，退出账号或主动清缓存才删除。服务端无法撤回已离线的副本。

## Harness 与模型

- Deep Agents／LangGraph 作为运行组件，harness 管理业务工具、权限、状态、恢复和人工确认；默认关闭宿主文件、shell、任意网络和子 Agent 能力。
- 明确指令可直接创建或修改本人工作、报告草稿；模型推断的进展需确认，提交报告和删除需确认。
- 报告结构由服务端校验并事务保存；聊天、图文与短语音使用外部模型服务，不默认部署服务器本地大模型或 ASR。
- 不隐式重试结果不确定的付费请求，保留原始消息与可恢复状态。
