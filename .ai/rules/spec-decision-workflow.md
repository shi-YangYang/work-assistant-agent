# Spec 决策工作规则

记录日期：2026-09-09

来源：用户明确要求“spec决策无需创建子agent验证，写进你的记忆里”。

## 适用范围

本规则适用于本项目当前及后续 Spec 的需求讨论、草案起草、产品与技术选型决策、决策留痕和相关文档同步。它是项目持久规则，任务切换或上下文恢复后仍应遵守。

## 工作方式

- 协调 Agent 直接与用户完成 Spec 讨论与决策。
- 不为 Spec 决策、草案或相关文档更新单独创建验收、审查或验证子 Agent，除非用户明确要求。
- 协调 Agent 自行检查范围、文档一致性、链接及待定 / 已确认状态；必要的资料核对照常进行。
- 用户已明确的决定直接记录并采用，不再通过子 Agent 重复确认。
- 决策记录到 `.ai/decisions/`，同步当前 Spec、Plan 和适用的 `constitution/` 文档。

## 与工程实施的关系

本规则不取消业务代码实施后的独立验收。工程实施、测试、返工和最终验收仍遵循 `AGENTS.md`，但不得将纯 Spec 决策包装成工程验收任务来创建子 Agent。
