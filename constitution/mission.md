# Noria 产品使命

Noria 是围绕用户目标开展任务的 AI 工作助手，名称灵感来自诺亚方舟。用户通过对话交代任务、提供材料，助手结合上下文和工具完成资料研究、写作、数据分析与文件交付，并根据反馈持续修改成果。工作记录、周报和团队协作由用户按需使用。桌面端提供录音、本地转写与可回溯的会议纪要。

## 当前优先目标

优先完善从任务提出到成果交付的完整体验：

- Web 工作助手：提出目标、提供材料 → 查询、分析与制作 → 交付成果 → 根据反馈继续修改。
- 工作与协作：按需保存工作、记录进展、准备周报；提交后用于团队汇报与看板。
- 桌面会议：录音 → 本地转写与说话人识别 → 会议纪要、决策与行动项 → 原文和音频回溯。

Web 面向电脑和手机浏览器，设管理员、员工两类角色；Electron 面向 macOS 和 Windows，可独立处理本地会议。

服务端承载 Web 任务和数据，可部署在云服务器或内网，支持团队共同使用；桌面会议入口保留本地运行与游客模式。

## 产品原则

- 以用户要完成的任务为中心，通过对话理解目标、使用工具并交付可检查的成果；通用问答、研究、写作和文件处理不要求先创建工作或报告。
- 工作管理与汇报是可选的任务去向，是否写入由用户决定；业务操作返回真实记录和结果。
- 推断内容可核对、可纠正。工作助手按账号统一设置执行权限，新账号默认自主执行，已有账号保留原设置；自主执行时，用户明确要求且对象、内容清楚的提交／删除可免除再次确认；不扩大角色和数据权限。
- 权限由服务端执行，模型不能扩大访问范围；未上报不代表没有工作。
- 保留原始材料与来源，不能只剩模型总结；桌面会议不自动上传公司服务。
- 工作管理围绕内容、资料、进展与 AI 协助展开；不建设子任务层级、依赖关系、甘特图或自定义字段。
- 录音独立于转写和模型请求，慢推理不能中断采集。
- 用 harness 管理工具、权限、任务恢复与人工确认，模型和运行框架可替换；计算和生成文件按需使用隔离执行环境。

## 长期方向

逐步连接会议、人员、项目、工作与报告，支持事项跟进、历史问答和有依据的工作画像。组织架构、知识库、个性化日程及独立移动 App 按试点需要扩展，不预先建设完整平台。
