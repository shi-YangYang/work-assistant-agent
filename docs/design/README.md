# UI 设计基准

Web、Electron 与未来手机端使用统一视觉语言，各端独立维护样式。登录页保留翻书交互。

## 可运行参考

[归档原型](prototype/) 包含浅／深色、会话、工作、团队、报告和模型服务页面，支持窄屏。仅作视觉参考，演示数据和模拟反馈不得进入正式功能。

仓库根目录启动：

```sh
node_modules/.bin/vite --config docs/design/prototype/vite.config.mjs
```

访问 http://127.0.0.1:5186/ ，可切换主题和用户视角。原型不连接业务接口，不填写真实密钥。

参考 [BeUI AI Agents](https://beui.dev/components/agents/message-bubble)，以本地归档为准，不依赖 BeUI。

## 配色

支持浅色、深色与跟随系统，保留用户主题偏好。

使用无蓝、紫、绿偏色的中性灰。以表面亮度、文字和留白区分层级，不用大量描边或阴影划分每一块内容。

| 语义             | 浅色                      | 深色                      |
| ---------------- | ------------------------- | ------------------------- |
| 应用外框／侧栏   | `#f5f5f5`                 | `#101010`                 |
| 主内容画布       | `#fcfcfc`                 | `#151515`                 |
| 弹层／独立表面   | `#fcfcfc`                 | `#1c1c1c`                 |
| 柔和内容底色     | `#f5f5f5`                 | `#1c1c1c`                 |
| 悬浮             | `#ebebeb`                 | `#252525`                 |
| 选中背景         | `#e9e9e9`                 | `#242424`                 |
| 主文字           | `#0b0b0b`                 | `#f2f2f2`                 |
| 次文字           | `#454545`                 | `#bcbcbc`                 |
| 辅助文字         | `#636363`                 | `#868686`                 |
| 轻边界           | `#0b0b0b0f`               | `#ffffff0d`               |
| 强边界           | `#0b0b0b1f`               | `#ffffff1a`               |
| 主操作／用户气泡 | `#0b0b0b`，字 `#fcfcfc`   | `#f2f2f2`，字 `#151515`   |
| 成功             | `#16815b`，底 `#00bd6c0d` | `#54bc90`，底 `#00bd6c10` |
| 待确认／阻碍     | `#a26b12`，底 `#f5a5000d` | `#d4ad65`，底 `#f5a50010` |

状态色配合图标或文字，错误和危险操作保证可读对比度。不使用蓝紫选中条、偏色灰阶或带间隙的焦点外圈。

## 排版与组件

- 桌面采用紧凑侧栏、轻量顶部导航；主画布铺满右侧宽高，外层不加卡片圆角、边框、阴影和留白。面包屑表达路径，单个页面只有一个主标题，主操作与标题同行。
- 内容按任务组织。列表筛选、结果、分页形成一个整体；空状态收在对应内容区域，不靠大段空白撑满页面。详情就近进入或展开。
- 输入区、快捷入口和工作结果采用柔和表面；弹层有轻阴影，普通内容不套多层白卡。主要容器圆角约 14～20px，小控件约 8～12px，状态与短操作可用胶囊形。
- 中文优先系统字体，正文 14～16px，区分标题、正文与辅助信息，窄屏保持可读。
- 控件具备默认、悬浮、选中、键盘焦点、禁用、加载和错误状态。焦点效果贴合控件轮廓；下拉层紧靠触发器，不被父容器截断。

## 工作助手

- 用户消息为反色气泡，助手正文直接呈现在画布上，身份和时间保持轻量。
- 工具执行与来源采用紧凑、可展开的摘要，不把技术过程堆成一排大卡片；结果与正文清楚区分。
- 需要确认的业务操作使用独立确认卡，呈现操作对象、关键内容和主按钮；待确认与完成状态可辨认。
- 输入区采用浅灰／炭灰底色，附件、模式与发送动作形成稳定工具栏；附件分类呈现，输入高度有上限。有消息时输入框本体悬浮于聊天内容之上，外层透明且不拦截操作；列表末尾按实际输入框高度留出滚动空间，确保最后一条消息完整可见。
- 新消息可短暂进入，生成中的正文保持稳定；不能反复整段入场、抖动或自动打断用户阅读历史。

## 动效与跨端适配

- 动效用于表达选中、展开、按压、到达等状态。通常 150～350ms，明暗切换可稍长；避免无关循环动画，遵循减少动态效果偏好。
- 手机保留同一套灰阶、层级和组件语言，导航改抽屉，复杂横排改纵排；不要等比例缩小桌面。触摸目标、软键盘、安全区和长内容单独适配，重要操作不能仅靠悬浮出现。
- 共享设计规范，不共享应用私有 CSS。Web 保持现有 CSS Modules 与功能目录；Electron 独立维护；未来原生手机端按其技术栈实现语义色与交互。

## 品牌资源

资源集中在 `packages/ui-web/brand/`，不在各应用保存副本：

| 文件 | 用途 |
| --- | --- |
| `logo.svg` | 唯一标志源文件，黑色透明底的相扣 W |
| `web/favicon-16.png`、`favicon-32.png` | 浏览器标签页 |
| `web/apple-touch-icon.png` | 手机网页图标 |
| `desktop/app-icon.png` | 窗口、Dock、README，浅底黑标 |
| `desktop/app.icns`、`app.ico` | macOS／Windows 安装图标 |

界面导入 `@paa/ui-web/logo.svg`，由各端 CSS 适配明暗主题；旁边已有名称时图标设 `aria-hidden`。更新源图后导出对应尺寸，不改变应用名、appId 或用户数据位置。

视觉检查覆盖浅／深色、桌面／窄屏，以及空数据、有数据、加载和错误状态。本目录只维护一个设计基准，历史版本交给 Git。
