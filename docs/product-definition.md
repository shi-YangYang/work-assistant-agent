# 首版产品定义

状态：Spec 003 已完成模型准备和本地转写，[独立验收](../specs/spec-003-local-transcription/acceptance.md) PASS，实际 macOS / Windows CI 均通过；录音、保存和回放沿用 Spec 002。LLM 和纪要尚未接入。实录与平台证据见 [验证记录](../specs/spec-003-local-transcription/verification.md)。

## 产品与用户

Personal Agent Assistant 是面向 macOS 和 Windows 的个人工作助手。核心用户使用自己的电脑参与会议、了解团队与项目进展，需要减少记录整理工作，并积累可追溯的长期工作信息。

当前以会议为首个使用场景，员工周报和长期 Memory 是后续方向。产品不是团队 SaaS，本阶段不加入账号、云同步或多人协作。

## 当前产品体验

- **会议工作区**：用户主动开始会议，采集系统默认麦克风；成功打开设备后显示“录音中”、实际设备、时长和输入音量。最小化或切换页面保持采集。
- **结束与保存**：先显示“正在保存”，成功后进入详情，展示时间、时长、设备及音频格式。历史列表从本地存储读取，支持分页加载。
- **历史回放**：选择会议后可播放、暂停和拖动进度。重启应用仍可找到记录；开始新录音前停止播放，录音期间不提供回放。
- **状态与设置**：展示核心连接和真实录音能力，提供重新连接及可采取行动的错误提示。核心连接成功不代表设备一定能打开。
- **异常恢复**：录音中退出或重连可选择继续录音，或先停止并保存。保存失败保持窗口可见；设备或进程中断后保留可恢复内容，并标记为不完整录音。
- **模型准备**：设置中点击下载约 487 MB 的默认模型，显示真实进度，支持取消和失败重试；模型就绪后离线转写，未就绪仍可录音。
- **会议文字**：录音时分批出现带时间的片段；结束后补齐尾部，分别显示音频已保存与转写进度。重启可查看文字，点击片段定位回放。
- **历史补转写**：已有录音可以生成文字；失败或关闭后保留进度，用户继续未完成部分。
- **后续能力**：纪要、周报和长期记忆仍为后续方向。

一次只允许一场活动会议，不提供系统声音、暂停续录、设备切换或后台托盘。当前没有删除、导出、标题编辑或云同步。默认不注入演示会议，不伪造录音、音量、文字记录或纪要。

视觉沿用中文桌面工作区、稳定侧栏、浅色内容和绿色强调。窗口可缩放，录音与保存状态保持可见；产品页面不堆叠协议细节。

当前转写需求与验收边界见 [Spec 003](../specs/spec-003-local-transcription/spec.md)。真实模型、物理麦克风和合成故障分别记录；Windows CI 不能代替 Windows 物理设备录音验证。

## 后续 Meeting MVP 用户流程

```text
开始会议 → 检查录音设备与权限 → 持续录音并展示转写
结束会议 → 停止采集 → 处理剩余音频 → 整理完整转写
         → 生成结构化纪要 → 查看与回顾历史会议
```

上述为完整 Meeting MVP 的后续目标。当前已具备录音、回放与转写，纪要尚未实现。

异常体验方向：

| 情况 | 目标行为 |
| --- | --- |
| 麦克风或权限不可用 | 明确提示原因，不能显示已开始录音 |
| ASR 未安装或模型缺失 | 提示前往设置准备模型；原始录音仍独立保存和回放 |
| ASR 失败或积压 | 显示处理状态与保留原始音频，不能阻塞采集，失败后可继续未完成部分 |
| LLM 未配置或总结失败 | 完整转写可保留；后续提供重试总结，不伪造纪要 |
| Python 核心不可用 | 本次窗口仍正常出现，显示核心不可用并可重试连接 |

## 生命周期

无活动录音但存在转写任务时，询问继续处理或保留进度退出；无活动任务时正常退出；活动会议确认后停止、保存再退出；保存失败保持界面可见；恢复暂时失败时保留重试依据，排除存储故障后重新连接可再次恢复。强制终止可能绕过确认，重启后应标记中断并检查已落盘音频，不承诺内存数据零丢失。

## 正式用户安装体验

macOS 与 Windows 正式用户应安装应用后直接使用，不需要自行安装 Python、Node.js、创建虚拟环境或手动启动后台服务。所需运行时和内部处理程序随应用分发，由桌面应用管理生命周期。

“本地核心”是当前内部模块名称；正式界面应说明用户可理解的处理状态和恢复操作，不能要求普通用户配置解释器路径。当前 Python 版本及 `.venv` 提示属于开发骨架的诊断信息，用户安装包尚未实现。默认模型已采用应用内提示下载，用户无需指定模型路径。

交付约束见 [决策 0005](../.ai/decisions/0005-self-contained-desktop-distribution.md)。
