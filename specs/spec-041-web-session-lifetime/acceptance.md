## Spec Coverage

- 密码与钉钉登录共用 7 天签发策略，续期保留创建时间、令牌和 CSRF；30 分钟节流、旧有效会话升级及 30 天上限与规格一致。
- 业务事务先提交并释放连接；续期在独立短事务中重新读取成员与会话，沿用公司锁顺序，提交后才允许回写 Cookie。过期或撤销会话不能恢复，续期故障不改变已成功的业务响应。
- HTTP 层排除错误响应、会话签发／撤销端点、SSE、任务恢复及现有后台轮询路径；独立的反馈、附件预览和钉钉绑定鉴权也检查绝对期限。
- 桌面新令牌同时受 8 小时和 Web 会话截止时间约束；没有 schema、前端轮询或接口响应体改动。

- 后台复用的读取接口仅在 SPA 内阅读时不续期；续期响应丢失可能使浏览器按旧 Cookie 期限提前退出，均已在规格及计划说明。
- 钉钉使用测试提供方，浏览器模型回复受控；未验证真实钉钉授权或真实 LLM。浏览器流程在返工前执行，返工后的 Cookie 竞争由定向 ASGI 回归覆盖，未重复浏览器全流程。
- 未部署、提交、推送或查询远端 CI。
