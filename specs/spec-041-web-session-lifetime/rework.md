# 返工要求

独立验收复现：管理员慢目录请求在途时退出并登录员工，旧请求随后将管理员 Cookie 写回，员工下一次身份请求得到 401。

- 删除节流分支使用请求初始快照无条件补发 Cookie 的行为。
- 仅在续期短事务重新确认当前有效会话并提交后回写 Cookie，保持原业务结果及节流期无额外事务。
- 添加真实 ASGI／PostgreSQL 的慢请求、退出、切换账号回归；旧响应不能覆盖新账号 Cookie。
- 更新受影响的补发测试和实施说明，定向验证后由新的独立 Agent 验收。

证据：`artifacts/spec041/reviewer-cookie-race.json`。
