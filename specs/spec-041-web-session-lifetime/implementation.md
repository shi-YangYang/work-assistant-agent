# 实施结果

- Web 登录改为 7 天闲置续期、原登录起 30 天上限，通常每 30 分钟推进一次。
- Cookie 签发、会话有效性和续期集中管理；业务提交后才进行独立短事务续期，失败保留原业务结果。
- 未达到续期阈值时不补发 Cookie、不增加续期事务；只有短事务重新确认当前会话仍有效并提交后才写 Cookie，避免迟到的旧请求覆盖退出或切换账号后的状态。
- 到期、撤销或停用的身份不能续回有效状态；任务订阅、附件预览和钉钉绑定也检查绝对上限。
- 桌面新令牌最多 8 小时。没有数据库迁移、前端续期接口或新轮询。
- 后台复用的 GET 路径统一不续期；单独在 SPA 内阅读这些数据不算活动，整页身份访问和常规读写仍可续期。
