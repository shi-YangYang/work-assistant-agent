# 验收 — v6 真实矩阵与共享授权纠错

## 结论

FAIL。v6 的写后读取、团队来源与建议保存代码边界通过新的独立只读审查；完整真实矩阵随后复现共用授权纠错缺陷，整体目标也存在未达项。代码边界通过不能代替产品验收。

## 已验证内容

- 冻结 v6 与工作区当时源码一致，23 个不同定向用例最终通过；首轮旧断言失败记录保留，未重复通过检查。
- 团队目录 → 详情 → 分页使用实际返回的对象、版本及 token；建议保存只记录真实已提交版本；原权限校验不变。
- 固定首问 68/68、真实 HTTP 续接 13 次完成。3 个较早首问的续接因临时媒体生命周期已结束未测，不伪造补齐。
- 浏览器实际 R01 澄清、保存、工作附件刷新与 R05 上传、问答、来源卡刷新完成；保存结果新增 11 份、保留原 1 份及正文状态。
- R10 四个版本／强度样本均生成并下载真实 Excel，部门金额正确；模型选用了导出表格工具，未真实调用沙盒，不能宣传沙盒路径已覆盖。

## 共享机制缺陷

R02 high 续接四次授权在错误旧事项 ID 与遗漏材料字段之间振荡。独立只读诊断确认 `authorize_intent` 每次解析清空旧错误，并仅把最后错误附给下一次重试。所有实际用户答复和材料计划均存在，四次 HTTP 200，0 写入；不是用户表达或网络失败。应在同次请求中有界保留契约约束，不扩大重试或拼接多次授权。

## 产品缺口

- R01 多数候选先查询再提问，且选项常预设生成文件含义；曾误报数量或外露步骤限制。
- R01 high、R03 low 中位耗时超过预设调查阈值。后者部分样本有材料来源 ID 误填及授权纠错额外调用，不能统一解释为网络波动。
- 合同及 PPT 个别答复出现过度概括／推断；真实读取事实正确不能证明完整回答准确。
- 全部真实候选首问和续接未提交 `_flow.ready`，控制机制受控测试通过不等于真实及时收束已验证。
