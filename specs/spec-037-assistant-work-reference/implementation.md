# 实施报告

## 实现

- 工作详情进入最近实际发过消息的会话；没有会话时只准备草稿，实际发送才创建。
- 加号菜单可搜索、分页和引用本人工作。一条消息最多一项，可替换／移除；既有文字、附件和成果引用保留。
- 引用随消息持久化 ID。服务端严格检查公司、本人归属和访问范围；每次处理读取最新工作，执行与核对共享同一快照，不把工作描述当授权。
- 请求未确认时保留冻结引用和幂等键；成功后清空本条引用。工作版本进入恢复输入，摘要保留标识，业务回执保证重试不重复执行。
- 已删除工作不再展示名称；本请求已经成功删除时允许基于成功回执恢复答复，不重新删除。
- 改动文件与职责见 plan.md 的实际目录树；没有跨端改造或新增依赖。
