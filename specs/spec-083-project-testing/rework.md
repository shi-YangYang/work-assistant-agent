# 独立验收返工

首轮独立验收发现两项阻断；原始失败证据保留在 `artifacts/project-tests/spec083-independent-review/`。

## 进程树回收

父进程响应 SIGTERM 退出后，运行器会取消强杀计时器。后代若关闭标准输出并忽略 SIGTERM，仍可留存；此时运行器还会提前清理 schema 和媒体目录。

修复必须以本轮自有进程树完成回收为结束条件，不能只看父进程退出。保留有界退出与强杀，回收结束后才能清理环境。复现“父进程退出、后代存活且不持有输出管道”以及已有超时／取消边界；不重跑业务套件。

## Redis 环境隔离

统一入口及直接 Web／server wrapper 会继承 `PAA_REPLY_STREAM_REDIS_URL` 和命名空间，可能访问非本轮 Redis。必须由共享校验路径建立明确的本地测试配置和运行级命名空间，拒绝或清除未授权继承配置；不能只靠说明文档提醒。

检查入口直调及统一入口、错误目标拒绝、不同运行命名空间隔离和清理归属。只使用隔离合成环境，不访问日常或生产服务。本轮已有业务证据使用独占测试 Redis，仍有效。

## 验证与交付

由新的实施 Agent 完成两项耦合修复，再由新的独立验收 Agent 验收。沿用其他已通过证据，只补受影响的运行器／环境检查及必要的小范围真实启动清理验证。保留首轮 FAIL，不把未执行平台或外部能力写成通过；不提交、不推送。
