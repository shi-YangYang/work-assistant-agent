# 剩余问题修复

## 实现

- **工作更新**：根据用户原话独立提取六字段变更计划，再验证助手提案；漏掉状态、覆盖旧说明或修改未授权字段时先纠正，不写入错误数据。计划按消息和目标版本缓存，原权限、确认、版本与幂等机制保留。
- **任务状态**：权限／能力不足标为阻塞；只给真正能通过用户补充解决的事项保留回复入口。部分完成与全部完成分开。
- **联网结果**：普通网页网络失败耗尽有限重试后返回明确限制，保留已经取得的资料；不吞掉取消、权限及预算错误。搜索摘要、实际正文、失败请求地址分别标记，不把猜测地址当作已检索来源。
- **回答准确性**：提供公司时区下的日期与星期；明确数值口径、条件、假设和来源范围。数值关系按需核对，复用缓存；普通聊天不增加无条件审核，原有业务核对和用户明确要求的核验保留。
- **纠错流程**：格式整理与语义纠错分开计数，各最多一次；补操作和改正文仍共用一次语义纠错，恢复不会重放已经完成的业务。
- **展示**：查询范围尾注由服务端统一生成，避免重复。
