| 报告截断、将进行中职责误判为已完成、旧拒绝结果无法恢复 | 保留显式模型参数，生成和审核分别配置；栏目事实核对、审核版本恢复。R01 原稿仅重新审核一次后保存；F05 员工编辑提交、管理员查看完成 |

| 团队查询缺少截止日期、历史无关版本阻止更新 | 补齐日期投影，只核验实际选用来源与持久关联，同时保留撤权和版本冲突保护 |

## 破坏性与性能

- 真实 worker 在读取、写入、保存阶段被终止，租约恢复后 3 个目标各一条记录，无重复写入。
- 25 次相同幂等请求只写一次；10 次相同版本更新只有一次成功、9 次冲突；取消和重复确认遵守终态契约。
- 专用 TCP 代理中断真实数据库写入；媒体权限、部分写入后空间不足、缺少密钥均有回滚及恢复断言。未停止共享 PostgreSQL、填满宿主磁盘或改真实密钥。
- 真实 gVisor 限制网络、越界访问、输出与资源；多用户任务隔离，排队和取消后资源回收。
- 100／1,000／10,000 条数据完整搜索与分页；每档 100 次混合请求，1／10／25 并发均零错误，p95 约 26.8／142.36／176.33ms。

性能来自本机 macOS ARM、10 个逻辑 CPU，不代表 4 核 8GB 云服务器容量。SQL 计数只测工作查询模块，连接池计数只测检查器引擎；未声称观测 API 内部连接池。
