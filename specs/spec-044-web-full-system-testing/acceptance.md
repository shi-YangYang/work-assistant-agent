## Regression Risks

- 意图完整性仍含模型判断。新规则检查原文引用及声明字段的并集，并不等于确定性抽取所有自然语言事实；F02 体现了字段归类的实际限制。
- 报告生成仅在没有显式预设／推理参数时应用已知供应商映射；内部事实审核使用独立有界配置。未知协议不注入推理参数，StrictBool、事实核对及次数限制保留；不能承诺其他模型永不截断或误拒。
- 来源最新性限于本次明确来源与持久关联；历史读取仍执行公司、归属、角色、删除等授权校验。省略 sourceTokens 不能绕过已有关联的最新性，撤权及删除仍拒绝写入。
- 失败槽恢复仅面向新的已授权消息，目标需重新读取，旧 receipt 历史保留；同消息重试及成功／运行／待确认／取消槽仍去重。真实 F06 恢复与确定性回归相互印证，不承诺所有自然语言续接均能正确识别。

- 真实钉钉扫码／真实员工绑定、物理麦克风、手机系统权限及真实 iPhone/Safari 未实测。协议、固定媒体和浏览器引擎证据不能替代这些真实设备或账号条件。
