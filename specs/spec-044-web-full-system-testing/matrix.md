# 功能与风险矩阵

此表规定覆盖范围；实施时展开为带唯一 ID 的用例清单，关联页面／接口、前置数据、步骤、预期、运行方式及证据。没有实际执行前不填写 PASS。

## 功能覆盖

| 编号 | 功能 | 正常流程及主要边界 | 判定依据 |
| --- | --- | --- | --- |
| W01 | 登录书页、账号密码、钉钉登录 | 开合、直接登录、键盘、字段校验、错误占位、密码显隐、提供方开启／关闭、取消／过期／重放回调、登录后跳转 | 只有真实认证成功才进入；错误不扩张布局，不出现误触发校验和 aborted |
| W02 | 会话与账户 | 刷新、空闲续期、绝对到期、注销、改密、管理员重置、禁用／删除、双标签页、换账号、钉钉绑定／解绑 | Cookie 与服务端会话一致；旧身份草稿／缓存／请求不泄露；后台同步不延长用户闲置 |
| W03 | 框架与导航 | 所有路由、历史重定向、前进后退、深链接、加载失败与重试、搜索页面与操作、折叠菜单、主题、窄屏导航 | 无白屏、无权限入口、重复请求、重复错误和不可操作弹窗；页面加载按既有规则展示 |
| W04 | 会话管理 | 无会话直接发送、首条自动创建、最近会话恢复、切换／搜索／重命名／删除、草稿、历史分页、正文选择与 Markdown | 不自动发送演示消息；搜索完整；删除和切换不误用旧上下文 |
| W05 | 发送与录音 | Enter／Shift+Enter／输入法、快速点击、上传中发送、处理时中断按钮、录音权限／暂停／结束／预览、取消发送 | 一个会话的执行限制有效；草稿不闪失；录音可播放、时长有效，失败仍可处理原材料 |
| W06 | 附件 | 图片、语音、所有实际支持的文档格式，混合上传、拖拽／粘贴、预览／下载、转写修正、解析失败 | 9 个总数、3 段语音、图片 30 MiB、其他文件 20 MiB 的边界前后端一致；每种格式有真实内容断言 |
| W07 | 助手任务与权限 | 两种人设、三种权限、单工作引用、提问回答、确认／拒绝、连续改需求、自由任务、工作／报告工具 | 自主执行不重复确认已授权明确操作；模糊任务能澄清，角色权限不能被执行模式扩大 |
| W08 | 执行进度与恢复 | 节点重试、中断、切页／刷新、故障恢复、结果部分保存、手动重试后模型配置变化、Todo 展开 | 节点与业务状态一致、展开不丢失；已失败任务不遗留等待节点；无多余成功提示和恢复请求风暴 |
| W09 | 上下文 | 新／旧会话、模型窗口已知／未知、用量缓存、90% 压缩、压缩失败、并发、刷新、人设切换 | 显示不闪烁、不捏造容量；压缩后保留当前意图、授权和成果引用；不会重复压缩或串会话 |
| W10 | 联网与材料理解 | 搜索、读取网页、中文新闻、无法访问、内容截断、空搜索、审核拦截、恶意网页指令 | 答案有实际依据；不无故删正文、不说“查了”却不给结果；外部失败显示真实原因 |
| W11 | 成果和沙盒 | 文稿版本、代码计算、9 类生成文件、下载、二次修改、引用转工作、排队／取消、未启用 | 文件存在且可打开、数字正确、版本与来源对应；无伪造执行；未启用时明确限制且可继续其他能力 |
| W12 | 我的工作 | 新建、完整搜索、筛选、分页、详情、字段修改、状态／日期变化、工作引用、删除、过期版本 | 字段真实保存，变更差异和来源准确；确认助手建议不能显示为手动更新；无无效重复版本 |
| W13 | 报告 | 日／周报、汇报待办、生成、修改、候选采纳、来源、提交、删除、失败重试、并发编辑 | 正文、归属、时区、周期、状态和来源一致；用户手改不被后台生成覆盖；重试不重复报告 |
| W14 | 团队看板 | 管理员查询、日期／成员／状态筛选、工作／报告下钻、未上报与已上报、历史周期、删除成员 | 汇总与明细使用同一人员／时间口径；未上报不等于未工作；员工越权和跨公司请求被阻止 |
| W15 | 成员 | 新增、重名／重复账号、边界字符、编辑、启停、重置密码、删除预览／确认、账号重建、当前／最后管理员约束 | 前后端字段校验一致；最低密码长度按现有规则；会话撤销、历史归属与删除影响符合契约 |
| W16 | 模型配置与用量 | 获取／手动添加模型、保存／取消草稿、测试配置、路由、推理参数、语音协议、删除在用服务、环境配置、统计筛选 | 密钥不回显；未保存密钥不丢失或误用；任务使用的配置、成功／失败用量记录可核对 |
| W17 | 声纹与桌面授权页 | 上传、提取、更新、试听、失败重试、删除与清理、员工变更；Web 确认／拒绝桌面登录、回调校验 | 仅授权角色操作；真实受控音频提取成功；下载和登录兑换不越权／重放，不启动 Electron |
| W18 | 规则、通知、反馈 | 时区和汇报规则保存、待办生成／去重／逾期、通知已读、个人／公司反馈筛选、提交／复制、管理员处理 | 周期边界与列表一致；反馈诊断脱敏；错误只在指定作用域展示一次 |

文档格式和媒体 MIME 清单由当前上传 schema、解析器和客户端共同提取。七类既有文档与后续扩展逐个对照，不能把一种 ZIP 容器格式通过等同于 DOCX、PPTX、XLSX 全部通过。

## 跨功能破坏性场景

| 编号 | 操作 | 必须观察的结果 |
| --- | --- | --- |
| D01 | 匿名、同公司他人、另一家公司枚举对象与文件 ID | 拒绝访问且不泄露正文、元数据、摘要、用量、下载或来源 |
| D02 | CSRF／Origin 缺失或伪造、非法跳转、过期会话／回调重放 | 按认证契约拒绝；不会借回调登录错误账号或发送凭证到外站 |
| D03 | 空值、空白、长度上下界、Unicode、无效日期／状态／游标、额外字段 | 字段级提示明确；API 拒绝非法值，不产生半条业务记录 |
| D04 | 相同幂等键同内容／不同内容、两次点击、两标签同时确认 | 符合回执或冲突契约；不重复写入、执行或隐式覆盖 |
| D05 | 旧版本更新／删除、编辑期间后台完成生成 | 有冲突提示与正确版本；既有内容不被静默覆盖 |
| D06 | 接受请求后丢响应，恢复网络后显式重试 | 用户看得懂是否已接受；复用对应回执，不复制同一任务 |
| D07 | SSE 半包、乱序、重复事件、断线后切页／换账号 | 无重复正文／状态倒退／身份串线，连接清理有效 |
| D08 | 写入前后分别终止测试 worker，租约到期后恢复 | 已落库结果最多一次；未完成部分可恢复或明确失败 |
| D09 | 节点超时／429／5xx／审核／无效工具输出及恢复 | 仅重试适用故障、次数有限；不通过无限核对延迟结束 |
| D10 | 执行中取消、取消与成功同时到达、任务结束后再次取消 | 终态确定；已发生的副作用不谎称撤销；无孤儿任务 |
| D11 | 任务执行中删除来源、禁用用户、撤销可访问材料 | 重新校验权限；不给过期授权继续写入或泄露结果 |
| D12 | 网页／文档／文件名嵌入脚本、提示注入、SQL／路径字符串 | 无脚本执行、越权、宿主文件读取或密钥外泄 |
| D13 | 伪造 MIME、空／损坏媒体、超限／解压膨胀受控样本 | 有界拒绝／超时，解析子进程回收，其他请求仍可用 |
| D14 | 沙盒无限循环、内存／进程／输出超量、越权下载、网络访问 | gVisor 与资源限制生效；终止后资源回收，不影响其他用户 |
| D15 | 沙盒排队多用户、服务重启、成果发布半途中断 | 任务、目录、回执与文件按用户隔离；容量释放且可继续 |
| D16 | 独立数据库暂时不可用、测试媒体目录不可写／受限、测试密钥缺失 | 明确错误、事务回滚、恢复后可继续；不操作宿主磁盘填满或真实密钥 |

## 真实 Agent 场景构成

首轮建议 60 条独立场景，不与以上确定性破坏测试数量混算：

| 类别 | 场景数 | 例子与完成标准 |
| --- | --- | --- |
| 普通问答、写作、人设 | 8 | 解释概念、翻译、改语气；直接给有效内容，不强制建立工作 |
| 公开搜索 | 6 | 新闻／行业资料、对比来源、追问结论；结果与工具实际来源对应 |
| 附件理解 | 8 | PDF／表格／图片／语音／混合材料；定位材料内容并承认缺失信息 |
| 工作与连续修改 | 10 | 随机生成示例、创建、补充、纠错、指代“第二项”、引用后换话题；按授权真实保存 |
| 报告与团队 | 8 | 草拟与正式提交的区别、改周期、管理员下钻、员工拒绝越权；数据与时间口径正确 |
| 计算与文件成果 | 8 | 汇总、画图、生成文件、修改上一版；各支持输出格式均有实际产物校验 |
| 多轮综合任务 | 8 | 阅读需求 → 制定计划 → 保存前两项 → 修改其一 → 决定是否汇报；无需重新描述对象 |
| 中断、重试与部分完成 | 4 | 任务执行后答复失败再重试、用户撤回、澄清后继续；不重复副作用、不虚报完成 |

三种执行权限和两种人设采用有意义的组合分布，不机械做全组合。权限正确性另用确定性矩阵完整验证；对自然语言授权和指代至少保留正／负成对案例。

## 模拟真实用户的完整流程

以下 8 条计入上述 60 条场景，每条安排 5～8 轮用户消息，通过真实浏览器执行。箭头表示用户目标变化，不要求助手返回固定措辞；测试者阅读真实答复后决定下一句，追问、澄清与点击均保留记录。

| 编号 | 用户身份与流程 | 重点验收 |
| --- | --- | --- |
| F01 | 员工上传客户需求 → 整理实施计划 → 补充预算／时间 → 把前两项加入我的工作 → “第二项时间太紧，往后推两天” → 打开工作详情核对 | 从材料到计划再到工作，指代正确；仅写指定事项，日期与来源正确 |
| F02 | 员工“随机给我一份工作示例，先别保存” → 换行业／改内容 → “这版可以，存到我的工作” → 补充进展 → 指出状态填错 → 核对最终版本 | 示例与实际记录区分，接受用户纠正；不提前写入、不反复确认明确授权 |
| F03 | 员工上传销售表 → 汇总并生成图表 → “排除退款，刚才口径错了” → 导出 Excel → 继续修改同一成果 → “不要写进工作或报告” → 下载核验 | 计算与文件真实有效，新版本正确，不误触发公司业务 |
| F04 | 员工搜索公开资料 → 对来源追问 → 缩小时间／地区范围 → 换话题 → 要求整理可转发摘要 → 核对来源 | 给出实质答案，跨轮保持或切换目标正确；不被此前工作引用绑住 |
| F05 | 员工引用一项工作 → 只问建议 → 更新指定进展 → 起草周报 → 修改并提交 → 老板登录团队看板查看 → 员工返回检查 | 私人讨论不进入汇报；显式提交后团队可见，角色切换不串数据，汇总与明细一致 |
| F06 | 老板查询团队阻碍 → 按成员／日期下钻 → 追问依据 → 生成跟进建议 → 保存到自己的工作 → 误请求员工私人会话 → 继续合法查询 | 以实际可见记录回答；越权被明确限制，正常查询仍能继续 |
| F07 | 员工提出有歧义的修改／删除 → 回答临时问题 → 查看确认内容后反悔 → 换对象 → 按权限确认或自主执行 → 切页回来核对 | 补充只问必要信息，取消不写入，旧确认不能执行新目标，已明确授权不循环追问 |
| F08 | 员工委托组合任务 → 执行中断网或中断 → 恢复后查看状态 → 按 UI 重试／继续 → 修改剩余目标 → 核对已保存事项和最终交付 | 用户知道已完成和未完成部分；不重复创建，不丢失草稿，失败后有可操作的下一步 |

每条先核对用户目标，再核对对话理解、界面操作、落库／成果和跨页面展示；记录重复描述次数、重复确认、无意义绕路和阻塞点。接口成功但用户无法完成流程，仍判为流程失败。模拟用户只依据界面可见内容交互，独立验收再结合后台证据检查，不能用后台信息暗中给助手提示。

## 证据与缺陷记录

- 每条用例记录：ID、覆盖项、角色、输入／步骤、明确预期、结果、模式（mock／真实 API／真实模型／真实浏览器／真实设备）、提交、环境及证据路径。
- 每条缺陷记录：最小复现、期望／实际、严重程度、产品／模型／环境／测试分类、相关数据断言、修复与回归状态。
- P0：越权、密钥泄露、隔离逃逸、广泛数据损坏；P1：核心流程不可用、重复写入、假成功、恢复失控；P2：局部功能／交互缺陷；P3：不妨碍使用的视觉问题。
- 必测项未执行或仍失败，验收为 FAIL／尚未完成，不用总通过率掩盖；仅范围外或用户明确接受的限制可列为交付限制。
