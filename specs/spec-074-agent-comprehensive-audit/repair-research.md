# 检索、计算证据与成果引用修复

## 实现

- **A074-03**：`tool_progress` 原来把搜索词、结果排序也纳入结果身份，换词返回同一批资料仍被视为进展。现在按 URL、标题、摘要的指纹记录已有证据；子集或重排没有增量时直接给下一次模型调用明确提示，复用已有停滞控制。新网址或新摘要仍属于进展，不限制总搜索次数。当前轮次中相同成功搜索／文件发现／网页片段不再重做；明确的网页拒绝按地址复用，`refresh`、新页、新查找范围及网络／限流／服务暂时失败恢复放行。进度记录只存摘要指纹，保留原租约、来源校验、重放与预算边界。
- **A074-05**：自定义 Python 的回执原来只有 stdout 和文件元数据，模型容易凭代码或记忆重述结果。现在复用发布阶段已经下载并校验的 JSON／CSV 字节，在同一个回执返回 `fileResults` 原文摘录、文件 ID／SHA 和截断状态；全部文件摘录合计最多 4,000 字符，不再请求沙盒或下载。历史 `read_execution` 在原有权限校验后可读这些证据，成果失效时不返回摘录。工具说明要求复用实际值／标签／单位，不擅自增加币种；既有证据筛选也识别无 stdout 的实际文件输出。
- **A074-07**：Markdown 原本只接受绝对 HTTP(S)／邮件地址，不识别生成文件的内部链接。现在由聊天组件向通用 Markdown 注入一个可选解析器，只有当前消息已授权成果的精确文件 URL 可以变成下载按钮；下载继续走现有 `useGeneratedFile` 与统一 API 身份处理。未知内部路径、伪造版本、代码块和危险协议不开放；带首尾空格的标准链接可正常识别。图片的重复文件引用继续由既有图库整理逻辑收拢。

没有新增迁移、服务或模型核对轮次，没有修改 Agent 模型强度、授权或全局时限。额外计算是已有工具边界内的小规模摘要／集合比较，以及仅在 Python 文件生成时有界解码现成字节；普通问答路径没有新增模型／网络调用。

## 验证

- 相关服务端模块合计 90 项通过：工具进度、重复／新来源／暂时故障、恢复及租约边界、执行发布／历史访问、文件摘录与既有证据筛选。测试使用独占且有所有权标记的 PostgreSQL schema，已清理。
- 相关 Web 63 项通过：Markdown、图片引用、成果显示／下载、流式回复。新增验证包括仅本人可用的精确文件引用、元数据移除、下载权限失效和未知路径；不会在渲染时自动下载。
- 改动的前端源码／测试已 Prettier；定向 ESLint 通过。未运行完整项目测试、构建或远端 CI。
- 统一 Web 类型检查发现下载错误可能为字符串或 `Error`，已按现有错误展示约定收窄类型；该文件重新 Prettier，`npm run typecheck:web` 通过。此次仅修前端错误显示，不改变已冻结的后端真实模型 AFTER 对照版本。
- 初次图片引用断言保留了带空格的原始 Markdown，按目标改为保留标签；新增来源变化测试的两次准备方式被真实租约保护拒绝，改为同步真实 `ConversationContext` 后通过。失败没有通过放宽业务权限或断言掩盖。

## 结论边界

这些模块测试证明确定性契约与权限分支，不代替协调 Agent 组织的真实模型修前／修后对照。

- 搜索摘要仍需要模型判断是否足以回答；新摘要也可能是同义内容，不用语义模型或模糊匹配强行认定。不能宣称所有低价值检索都已消失。
- `fileResults` 是实际文件内容，不是模型答案的自动校正器。不能保证模型不再写错自然语言数字、不会忽略字段，也未以本改动声称修复 T74 的自然语言行数算术。截断输出明确保留范围。
- 新增文件证据仅限 JSON／CSV；既有内置表格工具已有结构化 `data`，其他格式仍按现有读取／预览方式处理。预览不执行文件内容，不把其中的指令当作授权。
