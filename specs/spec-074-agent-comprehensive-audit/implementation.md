## 样本及隔离

- 80 个不同任务：58 个至少 3 轮，管理员 39 个、员工 41 个，20 个新增保留任务、46 个重复／循环观察任务。
- 前 60 个复用旧方案的用户输入；不复用历史答案，全部重新真实调用。新增 20 个覆盖代码、恶意附件文本、重复材料、旧 Office、长文件末尾、图文、扫描件、清单、空报告和批量图片。
- 正常 HTTP 组按两个独立账号并行，每个账号组内串行，避免强度／权限／记忆互相覆盖。浏览器使用独立账号。普通任务耗时记录并发条件，不冒充独占性能测试。
- 另外冻结 12 个复杂任务的反档复验、8 类任务 × 两档 × 3 次性能样本。每个复验／性能样本使用独立合成账号及新会话，性能阶段等待常规 HTTP 与浏览器组完成后执行。
- 空工作周报使用专门的空记录员工，避免此前任务留下的工作污染前置条件。

- 旧 `configure.py` 把汇报路由 `report: follow` 当成模型对象，首次配置失败且未开始模型调用；已适配当前统一路由，未修改产品配置规则。
- 旧 `run.py` 的真正调用链为 API → worker → 真实工具／模型；本轮不调用旧 `fixed.py`、`faults.py` 或 model-free load 的模拟模型结果作为覆盖。
