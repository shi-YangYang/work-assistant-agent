## Regression Risks

本轮不修改产品，因此不以本次审计造成产品功能回归为结论；以下证据边界限制后续上线判断：

- forget_memory、finish_task 专用入口未自然触发；delete_work、edit_report 的 Agent 动作路径未执行；独立 document job 与 Job.failed 未观察。不能将其他合法路径或 UI 操作替代这些入口的覆盖。
- 未穷举每个工具的两角色、三权限模式、边界和故障组合。实际循环保护／预算临界、运行时 SSRF 守卫和路径穿越未充分触发；模型拒绝不等于运行时防护已验。
- 未覆盖真正丢失消息 POST 回执、所有提交／取消竞态、页图损坏、媒体磁盘满／权限拒绝、慢流总时限。已有幂等重发及故障恢复不能扩写成这些场景全部通过。
- 并发仅含短答、文本附件和创建工作，未覆盖并发代码、生图、ASR、负载中取消和长期泄漏。运行环境及 worker 并发数与线上不同，单批 P95 不是生产 SLA。
- 未完成相同附件首次处理／复用的成对耗时实验；各转换、渲染、数据库和浏览器绘制阶段无完整独立时钟。HTTP 终态等待时间不等于用户看到完整答案的时间。

上述缺口在最终报告和覆盖索引中明确保留，没有计入 PASS 数；测试交付通过不授权据此宣称全产品无缺陷或所有可靠性边界已验证。
