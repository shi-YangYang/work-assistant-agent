# Agent 全量审计结果

## 结论

本轮真实模型、用户流程和隔离故障测试已完成执行；发现的问题先记录，**产品代码、提示词、模型强度策略和预算均未修改**。当前不能宣布“Agent 全部通过”：有已确认缺陷，也有未触发／未执行的边界。测试交付本身的独立验收见 [acceptance.md](acceptance.md)。

主要问题集中在：历史文档页图追问选错工具；报告实际内容与成功回复不一致；搜索低增量往返造成等待；一次报告子任务无效响应；生成文件与聊天数字不一致；材料读取范围说明和成果链接呈现。详见 [问题清单](issues.md)，共 7 组确认问题，另有 2 项产品边界／待复现候选，未立即修复。

测试中没有发现已经成功写入的业务对象被重复创建，也没有观察到持续无进展的无限工具环。这个结论只适用于本轮轨迹；未自然触发的预算临界、A-B-A-B 等分支不能因此算通过。

## 执行规模

下面是不同分组和计数口径，不能将“任务数、消息数、HTTP 请求数”直接相加作为总任务量。

| 分组 | 实际执行 | 核验方式 |
|---|---|---|
| 主功能任务 | 80 个不同任务、198 轮；58 个至少 3 轮；管理员 39、员工 41；20 个新增保留样本，46 个重复／循环重点任务 | 原始答案＋工具轨迹＋数据／文件读回，逐例语义审查 |
| 新账号复杂配对 | 12 个任务 × low／high，共 24 个结果 | 相同输入、独立账号／会话，避免主组历史数据污染 |
| 性能 | 8 类 × 两档 × 3 次，共 48 次串行样本 | 实际发送至终态、SSE 观察、请求和副作用 |
| 直接模型 API | low／high 各 3 次，共 6 次 | 同短问题、同服务商，真实参数、上游状态及答案 |
| 自然补充旅程 | 3 个冻结任务 | 补充团队来源、进展与持续任务上下文，不强行指定工具序列 |
| 浏览器 | 12 条主旅程，手机 6、桌面 6，覆盖管理员／员工；含恢复共 31 个真实 job | 真 UI 发送、切页、刷新、取消、确认、下载；21 张截图实际目检 |
| 故障 | 20 个故障 case | 独占进程／容器，实际异常、恢复和幂等读回 |
| 并发 | 1／5／10／30／50 人五档，共 96 个任务 | 各自账号与唯一标记，逐条核对答案／对象所有者 |

[逐例语义审查](../../artifacts/spec074/20261017-real-audit/semantic-review.json)记录主 80 项为 73 PASS、7 FAIL；新账号复杂配对 24 项为 20 PASS、4 FAIL；补充 3 项为 PASS。FAIL 保留任一轮的实质问题，不被后续恢复覆盖；这些是本组冻结任务的判定，不是全产品准确率。已答对的任务仍可能存在额外调用／延迟问题，另见问题清单。

80 个主任务的状态、人工结论与工具覆盖由对应逐例覆盖文件记录；任务收到终态、内部 `succeeded` 或 `awaiting_input` 均不能单独作为正确率。纯聊天的 `awaiting_input` 常表示等待下一条用户消息，要结合 `taskOutcome`、正文和实际副作用判断。

## 用户流程与成果验证

- **附件**：浏览器先验证单条超限拒绝，再按 9＋9＋4 分批发送 22 个不同文件，早期与末尾材料仍能正确查询。上传不提前启动 Agent；空文件、20 MB＋1 字节、单消息 10 附件、EXE 分别触发真实前置拒绝。
- **文字、代码和旧 Office**：验证可读内容、转换失败、长文件尾部、隐藏表／图表／备注及原件执行。范围声明不准确的问题独立记录，不能以某个事实答对代替整份文件完整读取。
- **图文**：首轮实际页图传入并答对；随后追问存在 A074-01。扫描 PDF／文档图片不是模型不支持，而是部分追问没有把对应页图传给模型。
- **工作与报告**：清单更新、指定对象修改、权限确认、保存材料后删除源会话再读取副本、空工作不生成空报告均走真实链路。报告风险字段假成功与“只有正文、没有进展”的来源边界分别记录。
- **文件成果**：CSV／JSON／DOCX 等实际下载并核对内容及版本；故障恢复生成的两份 CSV 各 100,000 行，逐行验证序号及平方，合计 333338333350000，未凭模型自报成功判分。
- **图片**：一次批量工具生成多图，后端串行；请求 100 张按现有上限生成 4 张。浏览器取消后保留已完成图片，其余显示取消；刷新和 PNG 下载有证据。
- **语音**：固定音频走真实上传／ASR／改文字；长按取消无消息 POST，长按发送仅发语音且草稿保留。截短音频和真机权限不混成 ASR 故障。
- **流式**：在真实 SSE 正文事件上主动重排 3→3→2，随后恢复原生连接并刷新，最终 606 字、8 段各出现一次，只有 1 次消息 POST。没有注入预制正文。

浏览器细节见 [浏览器报告](../../artifacts/spec074/20261017-real-audit/browser/report.md)、[截图索引](../../artifacts/spec074/20261017-real-audit/browser/screenshot-index.json)。截图索引只将实际查看的 21 张列为目检证据，未声称查看全部原始截图。

## 重复工具与恢复

主组同参候选已逐项裁定：T38／T39 首次执行被已有版本读取要求拦截，补读后再执行只有一次实际写入，是合法恢复；T68 相同空搜索没有新增状态，属于可减少的无效重查。

故障 F01b 在工作真实提交后杀 worker，租约恢复使执行入口重入两次，但复用幂等回执、数据库只有一项工作。发送同幂等键 5 次也只对应一个消息。这些不能误算为模型循环或重复成功写入。

不同参数搜索仍可能低增量，T05／T09 已单列性能问题；“没有重复写入”不代表“没有浪费调用”。证据：[重复候选裁定](../../artifacts/spec074/20261017-real-audit/loop-adjudication.json)。

## 故障及并发

20 个故障 case 中，19 个已执行的有限断言通过，另 1 个为写入后取消的状态展示候选。通过仅指表内实际变体，不表示对应故障类型的所有分支通过：模型层拒绝 localhost 不等于运行时 SSRF 防护被触发；忽略恶意附件指令也不等于恶意写入已进入授权守卫。

隔离故障包括真实请求后的进程退出、写入后的进程退出、独占数据库／Redis 暂停、媒体缺失、Office 转换进程卡住、执行中的沙盒控制器退出、403／429／503／断流／损坏响应／空正文注入、撤销测试成员权限。故障解除后的成功均有真实上游调用与实际读回。

96 条混合负载全部完成且归属正确。worker 并发为 3，50 人档总耗时中位约 58.90 秒、最慢约 95.24 秒，受理至首次模型调用中位约 53 秒，明显包含排队。此处是本地受控环境，不是线上 8 核 16G 容量保证，也没有证明长期无泄漏。

详细数据、实际故障注入点和未测变体见 [故障报告](../../artifacts/spec074/20261017-real-audit/faults-owned/report.md)，统一正常性能口径见 [性能基线](performance.md)。

## 明确保留的覆盖缺口

以下不计作通过，也不以假模型补造。注册清单有 37 个工具、141 个 API operation；本 Spec 是 Agent 相关端到端审计，列出 API 入口不代表每个 API 都做了穷举测试。

- `forget_memory`、`finish_task` 两个专用工具没有自然调用；独立 document job 构造入口没有观察到。忘记偏好通过 save_memory 合法完成，不能混淆功能目标与入口覆盖。
- 未自然触发所有工具环、目录循环、工具／模型／时间预算临界和恢复后的预算累积边界。
- 没有真正截断客户端的消息 POST 回执；测试的是已知同幂等键重发及写入后的 worker 崩溃。
- 没有穷举每个工具／写回阶段的进程退出；取消竞态没有覆盖报告提交与所有生图完成时机。
- 没有覆盖页图损坏、媒体磁盘满／写权限拒绝、慢流和持续活跃超过总时限。
- 提示注入／SSRF 测到模型层拒绝，未触发运行时恶意写入／SSRF 守卫；路径穿越专项未执行。
- 并发混合仅短答、文本附件、创建工作；没有并发代码、生图、ASR、负载中的取消响应和长期资源泄漏观测。
- 未完成同题附件首次处理与复用的耗时配对；不能宣称处理产物复用带来的速度收益。
- 性能 HTTP／SSE 时间不等于浏览器可见时钟；转换、渲染、数据库等各阶段没有完整独立测量，不虚构分解占比。
- 手机采用浏览器视口及固定音频，不覆盖实际 vivo／钉钉麦克风权限、物理设备录音质量。

## 测试工具问题与原始记录

修正仅发生在审计驱动：统一模型路由 `report: follow` 的适配、真实附件路由及错误码预期、报告子任务失败后的等待器、浏览器报告操作等待条件。首失败与后续修正分别保留；未把脚手架等待时间加入用户性能结论。

T59 冻结 oracle 原写合计 150／C 项缺名，实际输入 JSON 为合计 200／B 项缺名；模型首答按原文件正确。这是测试真值错误，保留原输入及原预期并单列更正，不按旧 oracle 计产品失败。主组复用旧输入但从不复用旧答案。

脚本做了对应语法／格式或定向 Lint；文档按 S0 检查引用与 diff。未运行与本次无关的全量产品测试、构建或 CI，不能宣布 CI 通过。
