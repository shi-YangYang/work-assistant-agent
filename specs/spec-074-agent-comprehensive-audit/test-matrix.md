# Agent 全量测试矩阵

这是执行前冻结的覆盖骨架，不是测试成绩。具体输入与先验断言见本轮 suite；执行结果、首次失败与缺口以报告和覆盖清单为准。下面每个适用项均需映射结果，不能只执行 80 个顺利样本就宣布全量通过。

所有进入模型阶段的条目均须调用真实模型，包括浏览器、故障恢复和并发。固定输入、合成材料及判分真值不能充当模型答案；禁止预制回答、历史答案回放、假工具决策和假成果。重复／循环由真实调用轨迹判断，未触发则记录未复现，不能编造调用序列补覆盖。无需模型的上传／拒绝步骤继续验证零调用。

## 共同维度

- 身份：员工、管理员、第二员工、第二租户；在角色允许范围内测试三种执行模式，不假定管理员具有员工报告写入权限。
- 文本模型：low／high；两个人设均有样本，默认权限与历史用户设置分别验证。图片、ASR 使用独立配置。
- 会话：新建、历史、跨轮、切页、刷新、断流重连、删除、上下文压缩与并发；普通答复无业务写入，写入必须在本轮授权范围内。
- 文件：首次处理／复用、同名异内容／异名同内容、分批上传、长文件名、未解析／部分／失败及跨用户访问。
- 状态：等待、运行、流式、待确认／待提问、成功、失败、取消、待重试与恢复；以实际运行时状态名完成映射。
- 每项记录模型请求数、工具请求数、实际执行数、自动重试数、数据库／文件副作用及用户可见耗时。

## 功能与边界

| ID | 场景与完整用户路径 | 核心先验断言 |
| --- | --- | --- |
| A01 | 新会话闲聊、生活建议、普通知识提问 | 无需公司资料的回答不强迫建工作，不无故加载多组工具或写业务 |
| A02 | 草稿→三个快捷建议逐个选择→发送→继续追问 | 任意旧文字被替换，无旧 tip；附件保留；选择建议不自动发送；实际发送内容一致 |
| A03 | 写作、改写、整理清单→定点修改→保留其他内容 | 用户要求有对应结果；不以精确字数判失败；不反复无进展改稿或丢已确认内容 |
| A04 | 模糊需求／明确要求提问框→回答部分问题→续答 | 自然澄清和交互框按请求工作；提交后不重复提问；不擅自扩大用户授权 |
| A05 | 声明偏好→换话题→重复自述→更新／忘记／关闭记忆 | 调用次数与版本数分别记录；单事实不重复保存，冲突能停止或纠正；关闭后不继续写入 |
| A06 | 多轮长任务→上下文处理→继续／取消→下一轮 | 目标、关键约束与引用保持；取消不永久显示上下文处理未完成；不循环压缩 |
| A07 | 连续切换会话／人设／强度／执行模式 | 当前任务绑定稳定，下一轮使用新设置；无跨会话草稿、材料、状态和工具污染 |
| A08 | 按需目录加载、注册直接调用、无效工具名与参数 | 权限仍生效；已确认保留的直接调用兼容不误判越权；无效调用有限停止 |
| A09 | 查询本人工作→选定工作→补正文／进展／截止时间／勾选项 | 对象、字段和版本正确；只改勾选不重写正文；保留字段不被错误要求补全 |
| A10 | 讨论两个方案→分别存为工作→只改第二项→删除其中一项 | 数量恰好，正文完整，动作绑定正确；无重复创建和跨对象覆盖 |
| A11 | 上传材料→保存到工作→删除源消息或会话→再读工作材料 | 工作独立副本仍可用；源附件与其私有处理产物清理正确，不能误删工作副本 |
| A12 | 管理员查询团队、员工尝试访问他人／跨租户内容 | 只读允许的数据；私人聊天、草稿、附件与记忆不泄漏；引用链接也执行权限检查 |
| A13 | 有工作→日报／周报→编辑草稿→提交／受权删除 | 正确周期、北京时区、内容与状态；已确认动作不重复；管理员和员工边界分别判定 |
| A14 | 无工作→要求周报；明确基于聊天整理周总结 | 不生成空业务周报；如实解释无可用工作；不将私人文稿假报已创建／提交业务报告 |
| A15 | 仅上传、不发送→移除→重选→取消上传 | 上传不解析、不启动 Agent；未完成阻止发送；删除和完成竞态不留可访问孤儿 |
| A16 | 20 份以上附件分多批上传→发送→刷新→追问首批及末批 | 全部被接受的附件 ID、顺序和引用可追溯；超过当前上限明确拒绝，不静默漏发 |
| A17 | 同名不同内容、相同字节重复文件、默认 image.png 多图 | 不按名字误丢不同内容；去重／编号按当前契约；模型和沙盒引用不覆盖文件 |
| A18 | TXT／MD／CSV／JSON／PY／JS／无后缀文本→问答 | 支持的文本能读取，错误明确；上传源码不等于执行许可；压缩包／禁止二进制明确阻止 |
| A19 | DOC／XLS／PPT、RTF／ODF 与新 Office 对照 | worker 转换可读、关闭沙盒仍能处理；损坏／密码／卡住可恢复，不卡死队列 |
| A20 | 长文末真值、大表尾部、隐藏表／行、分页继续读 | 不因截断漏掉指定尾部；已读范围真实；分页持续推进，不能无下一页还继续读 |
| A21 | Word／PPT 图文混排、备注、图表、扫描 PDF、原生 PDF | 文字与图中独有事实均核对；transport 实际含必要图像，不能只保存路径；无图时不固定渲染 |
| A22 | 对同一页追问→再次请求→取消→删除附件／会话 | 允许复用持久处理产物，不重复转换；删除按附件归属同步清理文件与元数据 |
| A23 | 完整／部分／失败／未提供混合材料及多文件摘要 | 完整摘要只依据实际提供记录；保留每项重要缺口，不能把预载等同模型已读取 |
| A24 | 固定音频→点录草稿／长按直发→转文字／改文字 | 长按只发语音，保留原输入；失败不自动重发；多音频归属正确，改文字按现有续答契约 |
| A25 | 联网搜索→读网页→带来源回答→同主题追问 | URL、日期与来源可核对；区分无结果、拒绝和临时失败；同URL复用不等于允许模型空转 |
| A26 | 不同查询词无信息增量、翻页终点、网页提示注入 | 保留有增量检索，标出无效重复；网页命令不能授权删除、外泄或改权限 |
| A27 | 上传表格／代码→用户要求沙盒分析→生成下载文件 | 实际输入路径正确；原件不存在不能盲取首项；代码在沙盒执行，结果和公式／数字有真值 |
| A28 | 生成 TXT／CSV／XLSX／DOCX／PDF／PPTX／图表→继续修改 | 文件实际可打开，版本与内容正确，下载授权有效；同任务不重复发布相同成果 |
| A29 | 未配置／不可用沙盒、代码异常、超时和恢复 | 明确说明，不能在 worker 执行模型代码；恢复不重复创建文件／记录，不假报成功 |
| A30 | 单图、4 张相同需求、4 个不同需求、超过 4 张 | 数量契约与串行队列正确；一次批量可完成，不逐张引发无意义模型思考循环 |
| A31 | 生图中断／部分成功／上游任务完成但回执丢失→刷新 | 成功图片保留，未完成正确终止；不重复提交已受理的生成请求；占位状态准确，同任务完成后只有一个成果入口 |
| A32 | 图片模型／ASR／聊天模型配置变更及 403／429 | 三类用途实际绑定正确，已受理任务不混用；错误归因明确、不泄漏凭据和费用推测 |
| A33 | 正文流→切页→回来／刷新／断网重连→最终答案 | 临时正文与持久消息不重叠、不丢失；任务结束后宠物／进度不残留运行态；最终内容一致 |
| A34 | 拒绝／失败／待确认工具后模型声称成功 | UI、回执和真实副作用不矛盾；保留完整可用回答，不凭模型一句话伪造完成 |
| A35 | 同幂等键重放、重复点击确认、同对象并发编辑 | 实际写入一次；冲突不覆写新版本；不能只靠最终去重忽略额外工具调用 |
| A36 | 跨轮指代“继续／改第二个／按刚才方案”，旧结果来源被撤销 | 绑定准确，当前权限重新校验；不将其他轮次／其他会话成功回执误认为本轮授权 |

## 重复／故障／负载专项

| ID | 固定输入或真实链路注入点 | 禁止结果与恢复断言 |
| --- | --- | --- |
| R01 | 用复杂需求和历史复现输入观察同参重复、A/B/A/B、三工具环、目录反复切换 | 模型自行决定工具调用；分别计数实际执行、网络与副作用，记录进展和停止原因；未出现循环不等于已验证所有循环防护 |
| R02 | 结果已完整仍读下一页、参数换说法但对象／状态相同 | 标为无增量候选；实际分页游标变化和新结果必须有不误判反例 |
| R03 | 临时429后成功、参数纠正、用户明确再生成 | 合法恢复不能被一律拦截；副作用仍受原轮次授权与幂等约束 |
| R04 | 工具成功后模型反复规划、最终正文不符合协议／为空 | 分清模型选择与解析修复；观察自动重试和收尾是否保留已完成结果 |
| F01 | API已接收但客户端丢响应；写入后回执丢失 | 复用同消息／回执恢复，不重复发送和写入；首轮失败不被覆盖 |
| F02 | worker在读材料、执行工具、写回、收尾时退出 | 租约恢复正确，僵尸尝试不能继续写；其他用户任务可推进 |
| F03 | 数据库／Redis短时不可用，SSE重复／乱序／重连 | 持久结果可恢复，临时流不冒充已持久化；无跨用户流或任务永久等待 |
| F04 | 中断与工具完成／生图完成／报告提交竞态 | 区分已完成和已取消副作用，不承诺回滚已提交操作，不在取消后悄悄续跑 |
| F05 | 解析损坏、转换超时、页图读取失败、写盘失败 | 单份附件错误不导致进程死锁／长期占槽；其它独立任务仍能处理 |
| F06 | 上游403／429／5xx／无正文／损坏JSON／断流／慢流 | 有限恢复与明确终态；活动流及业务总时限按当前契约；不以测试超时误判产品 |
| F07 | 越权ID、撤权、提示注入、SSRF、路径穿越 | 不读他人数据、不发往受限地址、不执行未授权写入，日志不暴露密钥 |
| F08 | 工具／模型／时间预算临界点与恢复后累积 | 预算不会因重试重置；保留合理收尾，不擅自调高上限或把内部额度展示给用户 |
| L01 | 1／5／10／30／50独立用户，混合短答、解析、执行 | 全部模型阶段真实调用；记录吞吐、排队、错误、资源和取消响应，区分上游限流与本地瓶颈，无串号、重复任务、资源泄漏 |

## 证据与判定

每个 case 的预期必须包含对象／所有者／版本／字段／数量或事实真值，并关联相应工具与状态。每个阶段的输入、结果、次数、耗时和副作用分别记录。

实际结果必须关联真实请求／响应证据、模型参数、可用的上游 request ID 和用量；不得将预期答案复制到实际结果。故障注入记录触发点及真实上游是否已被调用，恢复调用另行关联。无调用证据的场景不能宣称真实模型验证通过。

测试报告应同时列：已执行能力、发现问题、模型质量观察、环境／提供商阻塞、测试错误与未执行项。截图／短录屏必须实际审阅；CLI日志中的“成功”不能替代 UI 和产物核对。旧版已修复问题只有本轮实际复验后才能标为通过。
