## 如何理解 PASS 和 FAIL

程序修复通过、模型回答正确、完整用户流程通过，是不同层次的结论。局部 PASS 不抵消同批其他失败，后续补验也不改写原始结果。日志、截图和真实回复位于链接的 `artifacts/`，不随 Git 分发；新检出仓库缺少这些本地产物时，不代表已经重做或通过验收。

历史调用路径按当时版本保留。当前 Agent 评测统一从 `eval/agent-evaluation.py` 进入，不能直接复制旧文档中的 `scripts/benchmarks/agent-evaluation.py` 命令。
