## 受控并发与故障

本轮执行 1／5／10／30／50 人五档受控任务与 HTTP 流程，均限制每档不超过 60 秒。HTTP 组使用独立账号登录、浏览、创建工作、入队消息并由所有者取消，**不运行真实模型或 worker**；任务执行与恢复由另一组验证，不能混为 50 个真实模型并发。

HTTP 五档没有请求错误或跨用户输出，50 人组请求 p95 约 863ms。该值是本地 10 逻辑核机器的一批短请求观测，不是持续负载容量，也不是线上 8H16G 的性能保证。完整请求、CPU／RSS、连接归还及队列取消证据见 [http-load.json](../../artifacts/spec068/20261013-0fd76fe/backend/server-owned/http-load.json)。

故障包括自有 TCP 代理在实际 INSERT 后、commit 前断连，确认 503 后无部分写入，恢复后 201 且只有一份工作／版本／回执；独占 worker 的 SIGKILL 与租约恢复；拥有的媒体权限／容量错误；独占 Redis 容量和重启；受控模型拒绝／超时／限流、取消及迟到结果。数据库故障没有停止共享 PostgreSQL。完整分项见[后台与故障矩阵](../../artifacts/spec068/20261013-0fd76fe/backend/matrix-summary.json)。

## 未覆盖与结论限制

- 真机 iOS／Android／vivo／钉钉 WebView、物理麦克风、软键盘和系统文件选择器没有设备实测；Playwright WebKit 不代表 iPhone 认证。真实企业 OAuth／回调及外部声纹夹具也未完成。

- 沙盒协议和实际 Python 运算有证据，但未拥有可销毁的真实沙盒容器，真实提交回包丢失、导出租约丢失、worker 死亡及 cgroup OOM 未完成；受控错误不等价于这些故障。
