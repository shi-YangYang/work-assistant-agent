## Required Rework

**P2：图片技术地址整理会改写合法 Markdown 代码。**

位置：`apps/web/src/features/assistant/components/messages/reply/image-references.ts` 的围栏识别与逐行替换（本次预审第 20–32 行）。

`compactImageReferences` 只用 `line.startsWith('```')` 切换代码块状态，未识别 `~~~` 围栏、最多三个空格缩进的围栏及行内代码。对 API 已验证图片 URL，以下内容会被错误修改：

- `~~~http` 围栏内独立一行的已验证 URL 会被删除。
- 缩进三个空格的反引号围栏内，同样会删除地址行。
- 行内代码中的 `[下载](已验证URL)` 会被改成 `下载`。

这超出了移除普通正文冗长技术路径的范围，与“代码示例保留”的实现约束不符。应保留代码区域原文，仅处理允许整理的正文引用，并补充该函数的最小定向回归。无需因此重跑浏览器全量审计或真实模型。

协调 Agent 已安排新的实施 Agent 返工；最终代码、检查和性能证据交由新的独立验收 Agent 审核。
