# Electron 界面与交互统一改造

## 背景与当前行为

Web 已采用中性黑白灰设计，Electron 仍使用蓝灰主题、蓝色主操作和较重的内容卡片。桌面端已有会议列表、录音、纪要与文字记录、模型服务、本地模型、公司声纹和外观设置；本次将这些真实页面统一到 [UI 设计基准与归档原型](../../docs/design/README.md)。

## 目标

- Electron 与当前 Web 保持一致的灰阶、控件层级、密度和交互语言，并适配桌面会议场景。
- 右侧主内容铺满可用宽高，减少卡片套层、重复标题和过大间距，把空间留给会议内容。
- 保留全部现有能力、真实数据和用户设置，覆盖浅色、深色及跟随系统。

## 非目标

不增加业务能力，不改 Web、公司后端、ASR／声纹／纪要算法、数据结构或发布流程；不把桌面改为 Web 套壳，不引入翻书登录、聊天助手或手机导航。不重做系统窗口装饰、安装包图标，不开展整套前端架构或 CSS Modules 迁移。

## 目标行为与功能需求

### 应用框架与公共控件

- 侧栏、顶部导航及右侧画布使用设计基准的中性灰阶；主操作采用反色，选中和悬浮用明度区分。移除遗留的蓝紫强调和偏色灰阶，录音、错误、风险等真实状态保留必要语义色与文字／图标。
- 保留“桌面会议助手”名称，复用现有品牌资源；侧栏 Logo 浅色下为黑色、深色下为浅色，大小与文字协调，不拉伸、不复制素材。
- 导航保留会议记录、活动中的当前会议、模型服务管理、本地转写模型、外观及公司身份入口。会议入口在上，设置入口成组靠下，公司身份固定底部；不恢复“工作空间”“设置”等侧栏装饰标题。
- 顶部轻量显示当前位置，会议详情表达“会议记录 → 会议名称”，可返回列表。正文只有一个主标题，主操作就近同行；长标题可换行或截断并提供完整名称，不挤掉操作按钮。
- 主画布直接铺满右侧，不套外层圆角卡片、阴影或大块外围留白。普通内容以分区、轻分隔和局部柔和底色组织；独立弹层、输入控件等仍可有适当圆角与边界。
- 统一按钮、输入／搜索、日期、选择器、页签、状态标签、折叠区、进度条、播放器、菜单、Tooltip、弹窗及滚动条。具备默认、悬浮、选中、焦点、禁用、忙碌及错误状态。
- 控件焦点贴合自身轮廓，不出现带空隙的紫色外圈。下拉层靠近触发器，文字宽度足够，靠视口边缘可调整方向，不被列表、折叠区或滚动容器截断。
- 动效只用于反馈展开、切换、按压等操作，遵循减少动态效果偏好；实时文字与进度更新不反复触发整个区域入场。

### 页面覆盖

| 页面／区域 | 改造重点及必须保留的行为 |
| --- | --- |
| 会议记录 | 紧凑标题与开始会议按钮；搜索前缀图标、日期和筛选形成一致工具栏，日期整框可打开选择器。仅结果区域滚动，筛选和分页可达；保留完整搜索、每页十条、返回位置、重命名、复制／导出及删除。单条记录的更多菜单也不得截断 |
| 当前会议 | 将录音状态、时长、输入音量和暂停／继续／结束组织为紧凑控制区，实时文字获得主要高度。切换页面仍录音，活动录音条保持可达，不遮挡当前页面操作；忙碌、中断、保存及恢复信息可辨认 |
| 会议详情 | 返回、状态、时间及复制纪要／导出／更多操作集中排列；纪要和文字记录页签下方直接使用画布，减少顶部占高。保留来源跳转、时间定位、重新转写、处理队列及失败恢复 |
| 纪要与分析 | 标题、摘要、发言人摘要、共识／分歧、行动项、风险及建议按阅读层级呈现，不每段套一张卡；保留含姓名／纯文本输入选择、生成／重试、旧结果和输入变化提示、引用原文 |
| 文字记录与说话人 | 保留带说话人／纯文本两种视图、时间戳与播放定位、姓名及分段更正；发言分组紧凑易读，状态和操作有清楚归属，不把未知发言者显示成已识别员工 |
| 录音播放器 | 以紧凑、稳定的独立控制区呈现，正文在其上方滚动。保留播放／暂停、拖动、前后十秒、倍速、音量／静音、时间及快捷键提示；不改成原生音频条，不增加重复播放器 |
| 模型服务管理 | 服务列表与编辑区明确分工，当前编辑对象和正在使用的服务易辨认。保留新增／修改／删除、获取及手动输入模型、自定义推理预设／参数、流式开关、连通性测试、保存和设为当前服务。高级内容可折叠，主操作、字段错误及保存反馈就近展示，切页不丢草稿 |
| 本地转写模型 | 默认模型、识别语言和 CPU／GPU 设置紧凑排列；六款模型以清晰列表／分区展示，不堆满独立大卡。下载状态与操作常显，说明和实测详情可展开；保留硬件名称、后端区别、错误率／内存及实测条件、下载／取消／删除和使用中保护，不改写实测结论 |
| 公司连接与员工声纹 | 公司身份、登录状态、缓存与同步形成连续分区。游客仍可登录；未配置地址或网络异常有清楚反馈。保留同步、离线缓存、清缓存和退出确认；不恢复服务器地址输入框，不新增强制登录 |
| 外观与命令面板 | 外观预览与实际浅／深主题一致，设置区域随窗口伸展。保留系统跟随、已存偏好及 Cmd/Ctrl+K、搜索、上下键、Enter、Escape、关闭后焦点返回 |

### 排版与状态

- 列表和设置使用可用宽度，模型编辑区不因固定窄宽留下大块空白；长篇纪要可控制文本行宽，但整个主画布仍铺满。
- 折叠只收纳次要说明、详细参数和长分析。录音控制、关键错误、确认操作、当前编辑内容和下载进度不能被默认隐藏。
- 空列表、筛选无结果、尚无纪要／文字、模型未就绪、加载及失败分别呈现真实状态；提示只说明原因和可执行下一步，不增加开发过程文案。
- 窗口缩小时工具栏可换行、多栏可改纵排，保持控件可读；不等比例缩小整页。主要内容区域承担滚动，避免页面与内部重复滚动，最后一段正文不被播放器或活动录音条遮住。

## 边界条件与兼容性

- 保留当前 900 × 640 最小窗口、1240 × 820 默认窗口，适配更大窗口；不以扩大最小尺寸掩盖溢出。macOS 与 Windows 的字体、选择器和快捷键差异继续受支持。
- 主题存储键、默认值与系统跟随不变。主题切换或导航不能重新挂载音频播放器、录音订阅或模型服务编辑器，也不能重置播放、文字阅读位置和草稿。
- 保留 `window.paa`、IPC 信任边界、内存导航、录音状态机、原生关闭保护和已有请求流程；页面不引入新的权威业务状态。
- 录音、会议、声纹缓存、已下载模型、API Key 与公司身份不迁移、不清空。断网、未连接公司或公司 API 未启动，不妨碍已有本地能力。
- 键盘焦点、标签、页签及弹窗语义有效，危险操作确认保留。鼠标、键盘均能访问关键操作，不能仅靠颜色识别状态。

## 技术约束

沿用 Electron、React、TypeScript、Lucide 和现有选择控件，通过桌面自身组件及 CSS 实现。颜色和交互细节引用统一设计基准，不另建一套设计文档，不修改归档原型来迎合实现结果。

主要修改限于 `apps/desktop/src/renderer/` 及直接关联的桌面测试。桌面独立维护样式，不导入 `apps/web/src/` 的组件、Hook 或 CSS；品牌图片继续使用现有共享资源。不新增 BeUI、Tailwind 或动效依赖，不顺带重构 main／preload／Python 核心。
