# Implementation — 工作助手发送与附件体验

## 状态

业务实施与定向返工完成，[新独立验收 PASS](acceptance.md)。行为与资源上限分别见 [Spec](spec.md) 和 [Plan](plan.md)，本文仅保留实现与验证增量。

## 实现

- Web 三种入口共用附件校验；录音加入原草稿，保留上传身份与原键重试。新增 `AttachmentPreview.tsx`：图片画廊、主动 HEIC 预览、PDF 原页查看与失败重试，关闭时回收资源。
- MP3 进入现有 FFmpeg／转写链路，HEIC 通过受限图片子进程解码，XLSX 通过现有文档子进程提取可见单元格与公式保存值；混合材料进入同一次 harness。原件不改写，预览发布前重新鉴权并与删除同步，孤立清理包含派生物。
- 增量依赖：PDF.js 6.3.289、pillow-heif 1.7.0、openpyxl 3.1.5／et_xmlfile 2.0.0。PDF worker 与 200 个字体／映射／解码资源本地输出；Caddy 只增加同源 worker 和 `wasm-unsafe-eval`，不开放 JS `unsafe-eval` 或内联脚本。没有新增表或 migration，未修改 Electron。
- 初轮失败已修复：openpyxl 改用文件流读取没有扩展名的私有 UUID 原件；图片预览释放长操作期间的公司锁，在最终发布前重新鉴权，避免阻塞并发删除。页面复核另修正 PDF 页码换行。

## 验证

- 2026-09-16，协调 Agent 在现有 `paa-company-spec015:service` 镜像的临时 Linux ARM64 容器中安装 `pillow-heif 1.7.0`、`openpyxl 3.1.5`、`et_xmlfile 2.0.0`，以 `python -I` 调用本次受限解析子进程：真实 HEIC 主图预览返回 `ready`；包含中文 B3 单元格及无缓存公式 C3 的 XLSX 返回 `partial`，明确提示缺少保存值、没有执行公式。命令退出 0，容器未挂载用户数据。本项验证安装／解析兼容性，不等于完整生产镜像或 Windows 已验收。
- 日常 `npm run dev:company` 环境：协调 Agent 用未发送合成材料检查 PNG／HEIC 画廊、放大和左右键、Esc 返回原草稿，HEIC 主动私有转换后显示成功；PDF 两页真实渲染、翻页、缩放和适应宽度通过。1280×720 与 390×844 下检查控件；修正了 PDF 页码受通用 label 样式影响换行的问题。
- 同一草稿加入两张图片＋PDF＋MP3，真实浏览器剪贴板粘图在第五个附件时弹窗拒绝，移除一项后可粘贴；普通文字粘贴保持可用。未发送消息或调用模型，检查后清空本次未发送草稿。一次 HEIC 主动预览产生的私有临时附件由既有孤立清理处理。
- 实施 Agent 报告：服务端 36 个唯一相关用例通过，覆盖附件体验、文档解析／授权生命周期、图片进入 harness；Web 41 个唯一相关用例通过，覆盖文件、录音、会话／身份草稿、API 与私有字节鉴权。初轮服务端两项失败修正后只复测受影响项，未扩大为完整测试。
- `npm run typecheck:web`、涉及文件的 ESLint／Prettier、`git diff --check` 通过；普通 `npm run build:web` 通过（1,908 模块及本地 PDF worker／200 个资源）。最后的画廊失败重试与边界键盘修改之后，类型及该文件 Lint 通过；没有重跑未受影响的构建。未触发 CI、提交或推送。
- 协调 Agent 用现有构建产物与部署 Caddy 的同一 CSP，在临时本地静态入口检查 PDF：实际渲染并翻至第 2 页，worker／字体工作，浏览器未记录错误或警告；共享日常 API 只读，不创建消息或使用模型。检查后关闭临时页面与容器，不等同完整生产部署验收。
- 首次独立验收的 P2 已由新实施 Agent 定向修正：画廊方向键监听提升至当前 `<dialog>`，覆盖初始“关闭”按钮的焦点。两文件格式化、一次 Web 类型检查及 diff 检查通过；协调 Agent 在日常界面重新打开两图预览，未先点击工具栏即 Right→第 2 张、Left→第 1 张，边界保持，Esc 关闭并恢复原缩略图焦点。未重跑服务端或构建，新的独立验收确认问题关闭。
- 拖拽的浏览器文件投放、发送后预览及真实触摸操作未在本轮日常界面实操，须与自动模块证据区分。
