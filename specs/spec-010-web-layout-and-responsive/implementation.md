## 2026-09-13 返工：弹窗 Esc 关闭

独立验收发现：删除服务时忙碌保护会保留 React 弹窗状态，但原生 Esc 默认关闭仍会隐藏 dialog，导致失败信息不可见。`ui.tsx` 的 `onCancel` 现先阻止默认动作，再调用原有 `onClose`；普通弹窗仍由状态关闭，忙碌中的删除／测试弹窗继续显示。未改变删除接口或撤销语义。

按 S1 使用 Prettier 整理该文件，定向 `npx eslint src/web/ui.tsx` 通过；静态核对现有 Modal 关闭回调及本次差异。未重复全 Web 检查或新增镜像测试，未操作日常服务数据；交新的独立验收确认。
