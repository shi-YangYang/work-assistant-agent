## Spec Coverage

- R1：六款固定来源／清单、校验发布、单次准备、取消／重试、默认持久化与引用删除保护具备实现和定向检查证据；日常窗口实际看到六款模型，并完成默认模型切换及重启保留。
- R2：三种真实 Provider 配置、任务快照与旧配置恢复已有检查。返工后 `continuationBlockedReason` 与 `canContinue` 从同一持久任务解析结果生成；缺失／损坏和版本不匹配给出原模型说明，UI 不再依赖全局默认就绪状态，实时与历史页面均能导航到模型设置。没有悄悄替换任务快照。本轮实际通过控件选择英文和中英混合，核对核心返回及持久设置，刷新 renderer 后仍为混合，最后通过控件恢复中文。
- R3：候选 generation、失败／取消保留、事务发布、晚到结果拒绝、搜索与游标版本、纪要互斥和过期引用处理已有审查和定向检查证据。成功重转写不触发自动付费纪要，旧引用不会指向新片段。本轮在日常会议实际打开确认框，选择 large-v3／中英混合，核对确认按钮可用；取消与 Escape 均关闭弹窗并恢复触发按钮焦点，再次打开仍使用未变的 small／中文。没有提交用户会议重转写。
- R4：六模型×三语言均实际尝试，17 组完成，base／中文触发既有 500 输出词保护而失败，完整指标留空并解释。固定真人语料、归属、计分和原始结果可追溯；UI 仅展示错误率及基准进程峰值内存，明确包含模型加载、解码与评分开销。结果和局限见 [verification.md](verification.md)，失败组不算基准通过。
- R5／资料保护：CPU INT8、单 worker、录音解耦及旧资料保留有实现和检查证据。默认加载 90 秒／单块推理 180 秒仍有界，可取消且不自动重试；显式短预算继续生效。此前常规／填充窗口观察，加上本轮原生 900×640 窗口（内容 900×608）证据，支持宽／窄布局标准：默认区、列表、展开的三语指标和居中确认框均未见裁切或横向溢出。全部六条验收标准现有证据支持。
