## 覆盖与证据

- **上下文入口**：发送按钮左侧环形图标、详情、未知状态、压缩状态、账号／会话／执行版本隔离及复用 SSE 已通过定向 DOM 测试。主 Agent 实际操作电脑和手机视窗、浅／深色、Escape、刷新恢复；验收 Agent复核了电脑与手机截图。390×568 视窗无横向溢出。
- **容量与计量**：定向测试覆盖官方原厂 1,000,000、Vanchin 1,048,576、手动覆盖、未知模型、90% 精确边界、输入限制、输出预留，以及正文／工具／图片估算。累计预算改为容量乘调用次数，经代码审查；未单独实测超过 256,000 的累计输入。
- **JSONB 与恢复**：定向数据库测试覆盖历史复用、迟到回复、来源失效、跨账号／公司拒绝、权限下降、未来摘要隔离、无权历史排除、checkpoint 已写但发布中断、同摘要只发布一次、新进程恢复核对证据。自身工具通过真实回执推进版本后可恢复，外部修改仍拒绝。
- **查询路径**：24 条历史的固定样本，冷启动 36 次查询／19.53ms，增量读取 9 次／5.72ms；测试确认普通租约检查不读取 JSONB 正文。该测量只代表本地固定样本，不是线上性能保证。
- **真实模型**：`deepseek-v4.1-flash` 官方窗口识别为 1,000,000，28,573 tokens 的输入估算成功执行，突破旧 24K 工程限制。另用 65,536 测试覆盖值完成真实四轮：生成计划 → 指定第二项写入工作 → 修改同一工作日期 → 查询核实；压缩估算由 79,823 降至 34,044，工作没有重复创建，后续任务复用 JSONB。原始业务记录保留。
- **迁移与边界**：0017 测试库迁移成功；主 Agent 已完成日常库迁移及 API／Web／worker 启动。删除会话／账号清理、事务锁与来源修订保护经过代码审查；没有另做并发压力或真实断电测试。
