## 存储、接口与数据流

- 新增公司服务表，保存 `company_id`、服务 ID、名称、Base URL、加密 Key、版本、创建／更新时间。模型及其预设为有界配置，身份以服务＋模型 ID＋协议区分；限制沿用桌面基线（16 家服务、每家 32 个模型配置、每模型 16 个预设、单配置 48 KiB）。
- 新增公司用途配置，保存工作助手、报告（跟随或独立）、语音三项选择与 revision。字段变化以 `expectedRevision` 检测冲突，同公司约束在事务内校验，不能选择另一公司的 service ID。
- 服务的不可变修订保存运行所需参数及加密凭证引用，Job 绑定该修订和用途版本；明文凭证仅在发出请求的服务端内存中使用。修订只用于恢复，不提供查看历史密钥入口。删除服务撤销未发出调用及其凭证可用性，已完成业务记录只保留无密钥的来源摘要。
- 拟增加 `/settings/model-services` 列表／创建，`/{id}` 读取／更新／删除，`/models` 目录查询、`/test` 检测、`/import-environment` 显式导入，以及 `/settings/model-routing` 读取／更新。采用现有 session、CSRF、错误信封和版本冲突约定；具体路径保持无歧义，静态子路由优先于 ID 路由。
- 草稿查询／检测提交配置与可选已存服务引用；旧 Key 只允许用于同公司、同地址的对应版本。公开 DTO 仅包含 `hasKey`、非敏感版本、选项及检查结果；不回显用户输入的 Key，也不把服务密钥缓存到 Web 状态持久层。
- 请求标识绑定服务、草稿版本、模型、协议、预设和流式选择。前端丢弃过期响应；服务端检测记录只保存摘要及通过／失败状态，不存完整输入输出或响应头。

## 协议与参数边界

| 协议 | 请求与结果 |
| --- | --- |
| 兼容聊天 | `POST {baseUrl}/chat/completions`，由现有 ChatOpenAI 集成承接文字、图片与工具往返；明确 `use_responses_api=False`、`max_retries=0` |
| 文件语音转写 | `POST {baseUrl}/audio/transcriptions`，multipart 提交 `model` 和内部规范化 WAV 文件，首版读取 JSON `text`；不复用聊天消息结构 |
| Qwen-ASR 兼容 | 保留聊天端点的 `input_audio.data` Data URL 请求并读取转写正文；不假定同名模型或所有地域都支持此方式 |

- Base URL 已包含版本路径，统一去除尾部斜杠后追加协议路径，不自动补 `/v1`。目录优先 `GET {baseUrl}/models`；百炼官方端点可沿用经核对的同源目录适配（含业务空间专属域名），其它端点不改投猜测的域名。目录限制分页、条目数、响应字节与总时限，目录 URL 不能接受任意完整地址。
- 文本预设简单值映射 `reasoning_effort`；高级 JSON 中标准参数与厂商扩展分别交给 SDK 的标准字段／`extra_body`。服务默认传空参数，移除当前全局 `enable_thinking=False` 回退。保留字段保护，递归拒绝输入、Key、URL／header、工具、`stream`、输出格式和资源限制覆盖，以及原型相关键；TS 与 Python 校验使用一致边界。
- 聊天流式保持同一模型调用预算路径，完整汇总工具名称、ID 与参数后执行；超时、错误、无完整结束或工具参数不合法时失败。不能通过改用流式绕过 `reserve_call`、输出上限或工具次数限制；不自动请求服务未声明的 usage 扩展。
- 语音继续使用现有有界 WAV 转换和 180 秒输入上限；按接口分别校验实际编码大小、响应长度与转写文本。首版语音使用非流式；只提供已支持的语言等结构化选项，不开放任意音频请求模板。

## 凭证与出站访问

- 主密钥由部署方保存在独立私有文件，路径通过 `PAA_MODEL_KEY_FILE` 指定；本地辅助命令可在首次启用时生成一次，权限限制为服务账户读取。API 与 worker 使用同一文件；已有加密配置时缺失／损坏密钥必须失败，不能偷偷生成新值或退回明文。
- 使用现有 `cryptography` 的认证加密（AES-GCM），每次加密独立随机 nonce，附加数据绑定公司／服务／凭证版本。密文入库，主密钥不入库、不进镜像或 Git；数据库与密钥文件分别备份，恢复文档明确配对要求与密钥丢失后的重新配置方式。
- 可配置地址意味着新增服务端出站入口：默认仅 HTTPS，拒绝 URL 用户信息、query、fragment、控制字符；拒绝回环、私网、链路本地及云元数据地址，不跟随重定向。DNS 解析后校验所有候选地址并将本次连接固定到已校验地址，保留原域名 TLS 校验，不能仅校验字符串后重新解析。
- 确有内网网关需求时，由部署方在服务器配置精确允许的源站；Web 管理员不能通过请求参数关闭检查。测试使用注入的受控 transport／明确测试源站，不改生产缺省边界；传输不隐式读取不受控制的代理设置。
- 对目录和测试设置有界超时／响应和公司并发限制。沿用现有公司调用额度，测试预留调用计数；失败响应只保留安全错误类别、状态码、request ID 和耗时，避免第三方错误体回显密钥。

## 配置生效与恢复

1. 未开始执行的 Job 在首次领取时解析用途：若报告跟随工作助手，展开为具体模型；将无歧义配置修订引用原子绑定到任务。任务未具备必要配置则保留原始材料并明确失败。
2. 同一任务执行及普通重试固定到原修订，不因管理员编辑或更换用途切到新地址。修改现有服务须提示旧运行任务仍使用原修订；显式删除／撤销服务后，后续外部调用不再使用旧凭证，已发出请求可能完成，不能承诺取消计费。
3. 失败任务可由所属员工选择“使用当前配置重新处理”，明确这是一次新的处理尝试且可能再次调用服务。同配置普通重试复用已有 checkpoint；新配置尝试增加配置摘要／attempt 维度，不能恢复旧配置的 pending steps。旧建议及员工已确认内容保留，不重复执行确认或发布；使用现有工具幂等和报告版本检查防止晚到覆盖。
4. 每次外部调用前校验服务仍可用及原凭证版本；临时读取明文并只注入本次模型客户端，不把 Key 写入 RunContext 序列化、Job JSON、checkpoint、回调或追踪。用量记录区分工作助手、报告、ASR 和管理员测试。
5. 输入修订继续采用 Spec 008 的版本／摘要隔离和事务内核对；配置版本不能替代输入版本。长上下文摘要使用本任务选定模型，额度仍计入本次限制，不暗用另一家服务。

## 迁移与兼容

- 新增 Alembic 增量迁移，扩展配置／修订／用途和任务绑定；不重建员工、消息、工作或报告表，不复制附件。迁移前备份，失败回滚，升级后的配置写入不能由旧程序解释；回滚须恢复对应备份而非直接降级删表。
- 无数据库配置的公司保留现有环境模式。管理员显式导入当前环境服务时，在单个事务中创建服务和三类用途：助手沿用原图文模型，报告跟随助手，ASR 保留 Qwen 协议，聊天保留原非流式与参数。无完整旧配置时说明缺项，不伪造可用状态。
- 环境导入是一次公司范围的显式接管，禁止每次启动再次导入；接管后空用途不回退环境配置。其它新公司不能自动继承环境 Key。迁移期间旧排队任务首次执行按明确模式绑定；已发出但中断的旧任务保持人工重试入口，不能因配置迁移自动重发。
- 更新 `.env.company.example`、`deploy/company/` 的密钥挂载与备份说明、README 的管理入口和迁移步骤。此处只修改部署支持，不开通服务器、域名或在线服务。

## 实施顺序与相称验证

规格文档按 **S0** 检查差异与引用。业务已按以下顺序完成多 Agent 实施与独立复验；涉及凭证、鉴权、出站和持久化的检查按 **S3** 选择定向范围，实际证据统一记在实施／验收报告。

1. 配置契约、凭证保护、增量迁移和版本存储。
2. 目录／协议／检测边界、用途解析，以及 worker／harness 的固定配置恢复。
3. 管理员 Web、用途分配、草稿保护和迁移入口。
4. 仅验证此次受影响的服务端与 Web；涉及鉴权、凭证、出站和持久化，实施按 **S3** 选择必要检查，不追加桌面录音、模型下载或安装包验证。

定向证据包括：管理员／员工／跨公司权限；密钥不可回显、换址与加密故障；版本冲突和迁移；三种请求协议、目录异常、自定义参数、流式工具及断流；任务中换配置、旧配置重试、新配置尝试与输入纠正组合。使用固定服务响应和独立测试数据，不引用用户真实密钥或材料。按改动运行 `test:server`／`test:web` 中对应文件及 Web 类型、lint，修改源码使用项目格式化器；只有新增入口或构建配置受影响时补相关普通 Web 构建。

真实联调为单独、用户主动发起的小范围检查：一组已授权图文／工具模型和 ASR，固定中文文字、图片及短音频，核对“初稿完成／等待报价→报价已到”的事项连续性与人工纠正，再提交报告并由管理员查看来源。缺少服务条件时保留未验证项；不扩大为所有服务商、所有型号测试，也不自动将付费测试接入 PR CI。
