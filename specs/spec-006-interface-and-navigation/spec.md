# Spec 006 — 界面层级、页面导航与会议交互

## 状态

ACCEPTANCE · 2026-09-11。用户已体验并认可原型，实施完成，正在独立验收及核对本次 CI。已确认中性灰阶与蓝色强调、浅深色及跟随系统、已结束会议默认纪要／活动会议默认文字，以及录音控制条、引用联动和命令面板。调研与取舍见 [决策 0009](../../.ai/decisions/0009-interface-design-direction.md)，工程安排见 [Plan](plan.md)。

设计参考：[交互原型](prototype.html)。可直接在浏览器打开，使用内置示例数据演示页面与状态；录音、播放、连接测试和保存为模拟，不访问应用数据或外部服务。实际实施须接入已有业务逻辑，不复制模拟结果。

## 背景与当前行为

- 当前浅绿色背景、区块、辅助文字及按钮的明度接近，主次难辨；部分辅助文字只有 9～11 px。
- 会议详情把元信息、播放器、全文、纪要纵向堆叠；设置把服务配置、模型下载和能力说明放在一个长页面。
- 活动录音及实时全文挂在页面分支之外，进入设置时也会占据大块空间。
- 页面依赖 `App.tsx` 的局部状态与 `hidden` 切换。录音、服务草稿与回放已有保留／互斥规则，重设计须维护这些行为。

## 目标

1. 建立文字、导航、内容面和操作的清晰层级，适合长时间阅读中文会议记录。
2. 按用户任务拆分页面，稳定导航、上下文标题与主要操作的位置。
3. 围绕会议采集与回顾形成连贯交互，减少寻找原文、控制录音和切换设置的步骤。

## 非目标

新增周报／Memory／聊天模块、全文检索后端、录音剪辑或波形生成、服务协议替换、业务数据库迁移、品牌名称重命名、插件化主题、多窗口或可拖动工作台。不得加入没有业务能力支撑的导航占位。

## 目标行为与功能需求

### R1 — 视觉体系

- 采用中性灰阶内容面、清晰正文与蓝色强调，整体为简洁桌面工具风格。背景、导航、内容、弹层及选中状态由统一语义色值管理，原型中的浅深色变量作为设计起点。
- 区分标题、正文、辅助文字和状态；正文建议 14～15 px，辅助信息建议不小于 12 px。颜色不能独自表达录音、错误或选中状态。
- 以 WCAG 2.2 AA 对比度为设计底线：普通文字至少 4.5:1，大号文字至少 3:1；必要的控件边界、焦点和状态标识至少 3:1。装饰分隔线无需全部加深。
- 支持浅色、深色与跟随系统，默认跟随系统。记住用户选择，同一组件覆盖两种主题；系统主题改变时仅“跟随系统”模式自动切换。

### R2 — 页面组织

导航结构如下。侧栏分“工作空间”和“设置”两组，直接进入对应子页；设置子导航不要求再经过一个无内容的总览页。

```text
会议记录
├── 会议列表
├── 当前会议（有活动录音时出现）
└── 单场会议
    ├── 纪要
    └── 文字记录
设置
├── 模型服务管理
│   └── 单个服务：连接配置 / 模型与推理
├── 本地转写模型
└── 外观
```

- 会议列表集中呈现标题、日期、时长和处理状态，主操作为“开始会议”，不为拆页另建空首页。
- 已结束会议默认进入纪要，尚无纪要时显示实际生成／未配置／失败状态并提供原文入口；录音中默认呈现实时文字。
- 会议工作区固定标题、状态、页签和播放器位置；元信息放在轻量详情区，正文拥有主要空间。纪要与全文不再整块前后堆叠。
- 设置提供子页面导航。模型服务采用服务列表与所选服务编辑区，内部按连接和模型参数分组。折叠用于高级参数，不承担顶层导航。
- 原“录音与转写”的麦克风就绪信息移至开始／当前会议，转写就绪信息归入本地模型页；不为两条只读说明建立空壳子页面。
- 返回列表保留滚动位置，同一会议切页签保留阅读位置。标题、选中导航与键盘焦点同步变化。

### R3 — 会议交互

- 离开当前会议时显示常驻紧凑录音条：状态、有效时长、暂停／继续、结束及返回入口；设置页不再显示整段实时全文。
- 串联纪要引用、原文与音频：点击引用在上下文面板显示原文及时间戳，可定位播放；进入完整文字后显示目标片段，返回保留纪要阅读位置。空间不足时采用单列展开，避免压缩正文到不可读。
- 同一会议的页签共用一个播放器，切换不重建音频；离开会议、换会议、开始录音或重连时继续遵守停止回放规则。
- 提供可点击入口与 `Cmd/Ctrl+K` 命令面板，查找已有页面与操作；不把它描述为会议全文搜索。首版包含会议记录、当前会议、开始会议与三个设置子页；操作共用实际可用性判断。
- 状态反馈位于相关操作附近，录音、保存、下载与连接检测显示实际忙碌状态，失败保留恢复入口。
- 统一菜单、提示、弹层与焦点行为：菜单依附触发器，适应窗口边缘和长文本，Esc 关闭并返回焦点；离开页面无残留浮层。动效短且克制，尊重减少动态效果偏好。

## 边界条件与兼容性

- 导航不停止录音、模型下载、ASR 或纪要任务；活动录音期间仍禁止历史回放，不补暂停静音，不因切页提前生成纪要。
- 设置子页／页签切换不丢失草稿；切服务或离开未保存编辑时明确保留或提示，不自动提交密钥、发起测试或付费调用。密钥不写入新增界面偏好存储。
- 无记录、无模型／服务、离线、任务失败、长标题、中英混排及长会议均有完整界面状态。
- 覆盖 macOS / Windows，沿用 900 × 640 最小窗口；导航和主要操作可达，避免整页横向溢出与播放器遮挡正文。
- 快捷键不抢占输入框、预设编辑器或播放器操作；隐藏页面不留下可聚焦控件。

## 技术约束

保持 Electron / React / Python、既有安全边界、业务协议、目录和用户数据；不引入无必要的 UI 重依赖。拆页先分清渲染和状态职责，不能通过重挂载业务任务实现导航。

## 验收标准

- [ ] 确认后的配色与主题覆盖列表、录音、详情、设置、弹层及错误状态，文字与必要控件满足 R1 对比度目标。
- [ ] 实际页面与确认的结构一致，返回／页签／滚动／焦点行为符合 R2。
- [ ] 当前会议和紧凑控制条状态一致，切页不中断采集或后台处理，设置中不出现整段实时全文。
- [ ] 引用可找到原文并定位音频，同一会议切页签只有一个播放器，返回列表无残留播放器或菜单。
- [ ] 多服务、动态模型列表、推理预设、连接测试、流式默认值、模型下载及草稿保留没有回退。
- [ ] 命令面板中的已有导航和操作可用，忙碌／不可用状态准确，键盘不与输入控件冲突。
- [ ] 中文长文本、最小窗口、键盘导航与减少动态效果可用；独立验收区分日常环境、两平台 CI 与物理设备验证。
