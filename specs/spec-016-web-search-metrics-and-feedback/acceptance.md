## Issues

**首轮 FAIL：P2 — 发送前被地址安全检查拒绝的操作仍计入实际模型请求（已关闭）。**

原实现进入 HTTP 传输及 DNS 检查前发出 `started`；随后 `CheckedBackend` 拒绝受限地址，实际未发送请求却按已有 `started_at` 归为 `failed`，计入请求总数、成功率和耗时。

返工仅对 `safe_error` 得到的 `code='address'` 且无 HTTP 状态的失败清除 `started_at`，由统一逻辑归为 `not_sent` 并清空耗时，保留错误诊断。独立确认该条件仅对应 URL／DNS 地址校验；收到远端重定向带有 HTTP 状态，不会被抹除。超时、传输中断的 `unknown` 分支未改变。结合上述两项回归证据，修复未扩大到已发送请求，问题关闭。
