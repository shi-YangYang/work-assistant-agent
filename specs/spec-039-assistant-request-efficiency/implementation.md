# 实施报告

## 改动

- 新增显式内存查询资源与订阅 Hook。身份、公司／成员／角色、完整路径参数隔离；并发读取共享，单个取消不影响其他订阅者，闲置资源有限期释放。
- 区分被动刷新、真实失效和完整写入响应；失效发生在 GET 期间时补读一次，旧响应不能覆盖新值。
- 会话详情供标题、面包屑及恢复入口共享；历史、活动任务、临时问题、回执和上下文各有单一读取来源。原有 `useResource` 不变，分页共享显式接入。
- 合并 online／visibility 恢复，取消助手 focus 刷新；SSE 不因搜索／思考／核对阶段切换而查询，媒体完成和任务终态按需同步。迟到 SSE 终态不能关闭较新的流。
- 名称、人设、权限及问题回答使用完整写入结果，保留分页、草稿、手动重试及身份清理。
- 返工：恢复入口每次手动重试显式消费一次 fresh 读取，普通 get 保留稳定错误与 Retry-After；未共享分页恢复写后补读；Assistant 持有详情阶段的恢复监听，聊天区注册刷新回调，详情错误提供重试。
