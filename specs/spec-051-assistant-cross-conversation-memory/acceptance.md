- 当前输入的消息归属、修订及摘要绑定写入依据；版本冲突拒绝覆盖，人工保存、删除和开关变化使旧代次失效。恢复与最终交付复核回执，旧任务不能恢复已删内容或重放过时成功。
- 原样保存、完整片段移动保留各自来源／期限；被编辑的注解整体变成人工内容，避免仅留下永久单字，同段未改动的独立注解仍保留原元数据。自动局部补丁保护人工内容并保留无关排版。

- Web 双角色入口、开关独立提交、草稿和冲突合并、安全预览、取消、容量、清空确认与错误状态均有对应证据；保持既有请求入口、CSS Modules 和中性灰设计。
