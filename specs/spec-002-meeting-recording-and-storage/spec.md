# Spec 002 — 会议录音与本地保存

## 状态

DONE · 2026-09-09 · [独立验收 PASS](acceptance.md)。恢复重试问题已闭环；报告记录本阶段实际平台范围。

## 背景

[Spec 001](../spec-001-product-and-technical-foundation/spec.md) 已交付桌面和 Python 控制核心，本阶段为后续转写提供原始音频。

## 目标

用户主动开始默认麦克风录音，结束后保存音频与元信息；重启可查找和回放，故障时保留可恢复内容。

## 非目标

ASR / LLM / 模型、系统声音 / 屏幕 / 混音、多场并录、暂停续录、录音中换设备、托盘常驻、删除 / 导出 / 编辑 / 复杂检索、账号 / 云同步、周报 / Memory、安装包。

## 当前行为

实施前会议列表为空、开始按钮禁用，无音频依赖、数据库或播放；关闭窗口直接退出核心。

## 目标行为

核心和存储就绪后允许开始，用户操作才触发权限与设备检查。输入流成功打开才显示录音；最小化和切页持续采集。结束显示保存中，文件与元信息成功后进入详情。设备或系统中断不得伪装成完整录音。

## 功能需求

### R1 — 开始与权限

- 采用开始时的系统默认输入，显示实际设备名；之后默认设备变化不自动换源。无设备、拒绝授权或存储失败如实提示，不自动采集。
- 默认标题“会议 YYYY-MM-DD HH:mm”，唯一 ID、带时区时间；启动、录制、收尾期间全应用只允许一场活动会议，多实例不能绕过。
- 开始前停止回放，录音期间禁止播放历史音频；失败中间记录明确标记。

### R2 — 持续录音

- 实时写文件，回调、写入与 UI 分离，队列有界；回调块有顺序 / 样本偏移且可配置，与未来 ASR 业务块分开，不在录音路径执行推理。
- 录音标识、设备、输入音量及时长来自真实状态；静音可为零，不生成随机反馈。时长按单调时钟或采样进度，最终以有效帧为准。
- 驱动或队列丢帧显式中断；音频不经 JSON 高频传送。轮询有界且不重叠，切页不会停止采集。

### R3 — 停止与保存

- 顺序：停止采集 → 排空已接受缓冲 → 关闭音频 → 提交元信息。收尾期间明确显示正在保存。
- 开始 / 结束幂等；请求超时先查权威状态，不盲目重放或假报成功。
- 磁盘不足、不可写、文件关闭或数据库失败保留源文件和原因；可恢复部分明确为中断。暂时无法生成恢复副本时保留重试入口，解除故障后重连 / 启动可恢复。

### R4 — 历史与回放

- SQLite 元信息和 WAV 位于应用 userData，保存相对路径，与仓库和 cwd 无关。列表倒序展示标题、时间、实际时长和状态。
- 详情支持播放、暂停、定位；可信边界只接受合法会议 ID，不能向 renderer 开放任意文件路径。
- 文件缺失、损坏或不可读明确报错；播放可用性取决于真实文件，不能仅凭状态或存在性宣布成功。重启保留音频关联。

### R5 — 生命周期

- 关闭 / 退出 / 重连共享会话保护，允许继续录音或停止保存后退出；保存失败保持窗口可见。
- 休眠、设备失效、核心崩溃、强制退出后恢复已落盘完整帧并标记 interrupted；不自动新建、续录或掩盖缺口。
- 不能保证内存队列、系统缓存及断电时零丢失。

## 数据与状态

| 对象 | 最小信息 |
| --- | --- |
| Meeting | id、title、createdAt / startedAt / endedAt、status、durationMs、可空 errorCode |
| Audio | meetingId、相对路径、format、sampleRate、channels、sampleWidth、有效帧 / 字节数 |
| RecordingStatus | meetingId、state、elapsedMs、deviceName、归一化 inputLevel、可空错误 |

状态：starting / recording / stopping / completed / interrupted / failed。只有完整收尾且文件和元信息一致才 completed；部分恢复为 interrupted；无可用音频或恢复暂失败为 failed。核心 ready 与录音 available 均不保证设备本次打开成功。

## 边界条件

权限拒绝、无设备 / 断开、静音、快速重复操作、超时或回复丢失、关闭与结束并发、中文 / 空格路径、数据库锁、磁盘不足及文件缺失。文件与 SQLite 非同一事务；缓冲或 WAV 容量达到上限须安全停止并说明原因。

## 技术约束

采用 [决策 0006](../../.ai/decisions/0006-recording-and-storage-baseline.md) 的 RawInputStream、wave、sqlite3，保留现有工程目录。保持 sandbox / contextIsolation、IPC 来源和参数验证，拒绝摄像头等无关权限；不引入业务 HTTP 或收费 API。音频 / 数据库不入 Git，测试数据隔离。

## 兼容性要求

macOS / Windows 差异在适配层处理，设备实录与合成测试分开记录。本阶段允许 macOS 实机验收，Windows 无实机时标为未实测；正式分发继续遵守 [决策 0005](../../.ai/decisions/0005-self-contained-desktop-distribution.md)。
