## Issues / Required Rework

1. **已关闭 — DNS 解析收尾超过总截止时间。** `llm_provider.py` 的请求私有事件循环改用 Provider 自有 `_Resolver`，不再把系统解析放入默认执行器；可取消的异步等待结束后不会在 `asyncio.run` 收尾时等待该解析。锁与存活检查将未完成 OS 解析限制为每个 Provider 一个 daemon 线程，忙时立即失败；线程仅捕获解析参数与结果，不持有事件循环、Future 或请求凭证，晚到结果不会发送 HTTP。数字 IP 路径及 httpx 原始主机名／TLS 校验保留。已核对新增测试的时间、次数、IP 可用、晚到无请求与恢复断言及通过日志，无继续返工依据。
2. **已关闭 — 已知非文本模型手填绕过。** 核心可信目录按服务、地址和密钥指纹隔离；保存、切换、检测和实际生成均使用 `assert_text_model`，刷新后发现现用模型为非文本也拒绝外发。界面提示并禁用相关操作，未知手填 ID 保持可用。已核对跨进程调用链、缓存删除／在途失效代码，以及最新 Python、TypeScript、真实 Electron 模拟服务测试断言和通过日志，没有发现该缺陷仍可通过原路径复现的依据。
