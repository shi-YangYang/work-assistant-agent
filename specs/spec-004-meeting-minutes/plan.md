## 修改顺序

1. 定义结果、任务与配置摘要契约，实现 SQLite schema 2 → 3 增量迁移及旧版本升级链。
2. 实现加密设置和 Provider，先覆盖请求、错误、响应及引用校验。
3. 接入核心完成事件、任务队列、幂等标记和恢复，再连接主进程与 preload。
4. 完成设置、纪要阅读与来源定位，验证录音期间、退出和重启行为。
5. 按下述范围验证并独立验收；更新技术栈的实际实现状态，只保留一份实施摘要和验收结论。

## 接口变化

拟增加 `summarySettings.list/get/upsert/remove/select/check/models`、自动生成开关操作及 `summary.generate/status/get`；自动生成不向 renderer 暴露触发入口。服务配置有稳定 UUID、名称、Base URL、当前模型、各模型的推理预设及版本，全局保存 activeProfileId 和 autoGenerate。公开列表仅含摘要，详情有界读取，均不返回密钥；留空密钥仅在同一服务及地址未变时表示保留，改变地址必须重新输入密钥。保留现有来源验证与参数校验，禁止通用网络代理或任意核心方法转发。

主进程用已安装 Electron 支持的异步 `safeStorage` 加解密，密文原子保存于 userData 独立设置文件；系统保护不可用或解密失败时显示重新配置入口。保存后经受控 stdio 将配置交给核心内存，核心重连时恢复；不放入 argv、环境变量或会议数据库，不返回或记录密钥、完整请求／响应体。

每家服务的密钥单独加密；只将当前配置交给核心用于纪要，非当前服务仅在用户获取模型或检测时建立临时上下文。设置保存／切换串行且原子，失败保留原设置与活动配置，不因列表查询失败清空配置。服务 UUID、版本和草稿请求标识共同隔离模型目录及检测结果；移除配置同时清除其缓存。服务数量和分页输出有界，密钥不计入公开列表。

### Provider 与边界

- API 地址是包含服务版本路径的 Base URL，例如 `https://example.com/v1`；规范化末尾斜杠后追加 `/chat/completions`，不擅自追加 `/v1`。正式配置只接受 HTTPS，禁止 URL 用户信息、query、fragment，禁止自动重定向；隔离测试可注入 loopback HTTP。
- 请求使用 Bearer 密钥、`model` 和文本 `system/user messages`。每个服务可选择非流式或流式，新建服务默认流式，已有服务保留已保存选择；流式时读取 SSE 并汇总最终正文，界面仍以校验后的完整纪要为准，不按模型 ID 猜测传输模式或自动二次调用。推理参数按下述预设构造；不要求通用服务支持 response_format 或工具调用。固定提示约束 JSON，再做本地校验；不保存或展示服务返回的思维链。优先复用现有锁定的 HTTP 依赖，若成为直接依赖则同步声明，不引入完整 Agent 框架。
- 地址、模型、密钥分别限 2048、256、4096 个字符，拒绝控制字符；已序列化的完整模型请求最多 256 KiB。此为应用资源上限，不代表任意模型都具有足够 token 上下文；服务报告上下文不足时给出可操作错误，保持完整原文。
- 连接超时 10 秒、单次调用总截止时间 180 秒、HTTP 响应读取最多 1 MiB；统一放在可注入的边界配置中，测试使用短超时。连接检测通过同一 Provider 发送固定小样本，不生成会议任务，也不自动反复执行。
- 只接受非空文本结果、正常结束且没有拒绝或工具调用的响应。允许剥离包裹整个 JSON 的单一代码围栏；不从混杂文本中猜取 JSON，不静默修复字段。结果带结构版本，校验类型、必要字段、数组数量、文本长度及来源 ID，序列化结果限 48 KiB；所有 stdio 消息连同信封维持现有 64 KiB 边界，超限明确报错。
- 原文作为数据传入，模型不获得工具。引用只可指向本次快照中的真实片段，行动项未知字段用 null，相对日期保留原话；界面渲染文本，不能执行模型返回的 HTML。

### 模型发现与自定义推理预设

- 模型发现与生成共用受控 HTTP 传输。取消逐厂商／型号的推理适配器及能力注册表；服务名称只是用户标签，不决定请求参数。
- 通用入口为 Base URL + `/models`，解析 `data[].id`，去重并校验 ID。百炼官方域名使用同源 `/api/v1/models` 的分页接口，归一化 `output.models[].model`；只转换经核实的官方域名路径，不向其他域名转发密钥。GLM 等端点未提供兼容目录时显示不支持并允许手动 ID，不伪造目录。
- 网络列表响应有大小、条目数、分页次数和总时间边界；通过本地分页返回，不能突破现有 IPC 限制。当前草稿的请求标识用于隔离结果，变更地址或密钥清除旧目录及检测结果；原模型从刷新结果消失时保留为手动值并提示，不自动换模型。
- 每个模型保存 `presets[{id,name,mode,value/parameters}]` 和 selectedPresetId，null 表示服务默认。简单模式将任意有界非空字符串映射为 reasoning_effort，不枚举厂商强度；高级模式保存 JSON 对象。切换模型恢复其自身配置，绝不隐式复制上个模型的预设。
- 参数对象限制大小、深度、键数和合法 JSON 类型；禁止原型相关键、模板／执行表达式，以及覆盖 model、messages、stream、tools、tool_choice、functions、function_call、response_format、n、store、凭证和地址等受保护字段。应用先校验预设再合并到受控请求，测试和实际生成共用此路径；不为兼容而静默丢弃非法参数。
- 不内置“此模型支持这些强度”的结论，用户自行定义如 low/medium/high 或嵌套 thinking 参数。表单需区分预设名称和实际请求值；连接检测只报告该请求收到有效回复，不宣称推理强度确实生效。
- 获取模型及连接检测为异步受控任务，不能在 stdio 控制循环内等待网络；生成测试使用与纪要相同的请求构造器及预设。SSE 在有界内存内读取，必须有正常结束标记，断流、超时或仅思维链没有正文均失败。

### 任务与结果

任务表记录会议、输入摘要、配置版本、触发来源、状态与规范化错误；成功结果独立存储结构版本、生成时间、服务／模型、输入摘要与纪要 JSON。输入摘要覆盖片段 ID、时间、文字及来源完整性。活动任务与成功结果分开，重试失败不会破坏旧结果。

完成事件内事务登记自动尝试标记，以会议和输入摘要去重，再入队；任务同时保存不含凭证的配置标识。队列只在当前进程继续执行，启动时将未完成任务标为中断，不能因重启或重新配置再次自动提交。网络全局并发为 1，连接检测也受限，控制循环保持响应。配置变更或移除时中断旧配置尚未发出的任务；已发出的任务沿用内存快照，不改投新地址。关闭时有界停止 worker，晚到结果不得覆盖已终止或更新后的任务。

## 测试计划

规格补充按 S0 检查文档 diff 和引用；业务实施涉及 schema、凭证和跨模块接口，按 S3 选择必要验证：

- Python：迁移与回滚、完整转写快照、输入／响应校验、引用约束、任务幂等和重试、慢 Provider 下录音继续、超时与退出恢复。
- Desktop：配置与密钥边界、系统加密不可用、IPC 参数与来源校验、核心错误传播和生命周期；补充草稿获取模型、模型切换、推理选项重置、过期异步响应隔离及更换地址不能沿用旧密钥。
- Electron：服务未配置、新旧会议生成、阅读／定位、失败后重试、重启持久化；本机桌面验收遵循 [用户日常环境约定](../../AGENTS.md#21-测试与验证规则)，CI 使用临时测试数据。
- 真实 Provider：提供独立、手动运行的集成入口，使用应用配置与固定中文／中英混合会议样本，覆盖明确决策、未知负责人、相对日期、末尾关键事项和无行动项；记录实际地址的主机名、模型、结果及人工事实核对，凭证不进入参数或产物。实际调用需用户在应用配置并授权费用，不向聊天索要密钥；至少完成一次真实“转写完成 → 自动生成 → 原文核对 → 重启读取”。无条件时标明未验证，不用模拟响应代替实测。
- 故障测试使用本地兼容服务覆盖认证、额度、超时、截断、无效 JSON／引用、输出超限与重定向；增加模型列表空值／权限错误／分页、自定义新型号与多个预设、字符串／布尔／数字／嵌套参数、受保护字段、SSE 正常完成／断流，以及生成失败不能被列表成功掩盖。CI 不依赖付费服务或真实凭证，新增纪要桌面用例须在 macOS / Windows 都执行。已有平台受限场景仍单独记录。
- 按实际改动运行相关类型、lint、格式和必要构建；推送后检查对应提交的 macOS / Windows CI，不重复已通过且未受后续修改影响的检查。现有命令见 [技术栈](../../constitution/tech-stack.md#工程命令)，新增命令在实现时同步。

## 风险

模型仍可能遗漏或误解事实，引用存在不等于语义正确，必须人工核对真实样本。兼容接口不保证所有服务的上下文、JSON 遵从性或错误格式一致；单次完整输入策略限制了超长会议。退出时已发出的请求可能已由服务处理，不能承诺取消即不计费，也不能自动重试未知结果。

## 迁移策略

新增纪要任务、自动尝试标记和结果表，不重建会议表或重写 WAV／转写。迁移前用 SQLite 备份接口保留 schema 2 数据，事务提交 schema 3，失败回滚且保留备份；旧版本依次升级。旧会议保持未生成状态；不自动降级数据库，回滚程序需显式恢复对应备份并说明其后新增数据的处理。凭证不进入会议存储，删除或更换配置不能删除历史资料。
