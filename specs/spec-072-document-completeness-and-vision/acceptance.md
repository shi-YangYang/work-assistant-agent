## Regression Risks

1. 模型仍可能漏答或夸大阅读范围；本次已经保留具体实例。系统可提供真实范围和必要内容，不能用处理成功状态保证每个回答完全准确。
2. 首次多页原生渲染有成本，复杂图形、小字和旧格式转换仍不保证无损；页数、输入、时间和资源边界继续生效。
3. high 稀疏尾表真实质量与速度因网络故障未验证。无鉴权连通性检查不能证明模型 API 恢复，也不能推断故障确因额度、服务商或解析。
4. 全新生产 worker 镜像、远端 CI、Windows 原生渲染、生产最大并发及矩阵中明确未做的真实组合不在通过范围内。
