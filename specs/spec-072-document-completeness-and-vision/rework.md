# 集中返工

独立验收发现六项直接影响本规格的准确性、等待时间或安全边界的问题，详见首轮 [验收报告](acceptance-initial.md)。正式基准已暂停，失败版结果保留在 `artifacts/spec072/performance/formal-system/`、`formal-live/`。

## 修复目标

1. 视觉探测只依据实际内容，纯文字 Word 的主题样式不能触发页面读取；保留真实图片、图表、文本框及绘图结构的识别。
2. Word 段落保留制表符和换行分隔语义；嵌套区域不重复提取。
3. Excel 累计时长保持持续时间含义，日期、时刻和公式保存值继续正确。
4. 渲染前拒绝简单字段属性和拆分复杂字段中的活动指令；回归验证不实际访问外部资源。
5. 页图预算使用与最终请求一致的消息、工具、输出预留和图像切片计量；预载的 LangChain 消息不能漏算页引用。可读文字仍能回答，超预算页面明确分批。
6. CI 显式安装 Poppler/CJK 字体并执行真实转换／页面预检，避免依赖缺失导致视觉测试全部跳过。

后续独立复核确认合法 XML 注释／处理指令被当成普通元素传入 `QName`，导致原本可读的 Word 失败。按 [复核报告](acceptance-rework1.md) 只修复非元素节点过滤，并保留真实字段校验；普通固定样本不含这些节点，已有 A/B 结果继续保留，新能力测试使用最后冻结版本。

## 验证与停止

- 新实施 Agent 集中修复，执行直接相关的解析、字段拒绝和模型输入预算回归；不重复无关模块测试。
- 使用已有 Debian worker 基础镜像验证新增原生依赖和预检，不为此重新下载推理模型或构建整个产品。
- 再次冻结后补测受影响的普通 Office／重复材料路径，完成尚未进行的新增能力和缓存／批量对照；旧失败结果与修复后结果分开报告。
- 由新的独立验收 Agent 复核修复及最终证据，不由实施 Agent 自行给出最终 PASS。
