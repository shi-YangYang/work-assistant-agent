# Spec 053：工作助手思考强度与输出限制调整

状态：已实施，独立验收通过。

## 目标

管理员直接配置模型的可选思考强度与初始强度，用户在输入框选择并跨会话沿用。删除独立的推理预设概念、名称、ID、编辑器、开放开关和绑定流程。取消工作助手额外施加的输出 token 上限，保留服务商及运行安全边界。

## 当前行为与调整

已实现的版本通过预设名称、参数值、开放档位和用途初始预设配置一个强度，信息重复且入口分散。改为模型自身维护可选强度、初始强度和必要的协议参数；用户偏好直接保存强度。历史预设仅能出现在旧数据迁移和不可变任务快照兼容代码中，不能成为新配置的运行抽象。

## 功能需求

### 模型配置

- 一个模型只在模型设置中维护一份可选强度和初始强度；不再创建、命名、选择或开放预设。
- 使用实际档位字符串，如 low、medium、high、max；不假定所有模型都支持相同档位，不新增通用“默认”用户选项。
- 列表非空时初始强度必须属于该列表；为空时使用已有服务商参数/默认行为，用户选择器隐藏。初始强度只有一个编辑入口。
- 仅管理员修改可选范围；输入校验、受保护参数、安全边界继续有效。
- 特殊服务商参数保留在折叠的高级设置及内部协议适配中，不要求管理员为了普通强度创建参数组合或重复填写同一个值。
- 用途分配继续负责模型与请求方式，不重复配置工作助手初始强度。独立报告原有显式参数选择迁移后保持有效；必要的报告专属参数是兼容配置，不复建预设管理。

### 用户选择与任务运行

- 输入框右侧为：上下文、强度、麦克风、发送／中断；左侧原有按钮保持。
- 用户只看到允许的实际强度。偏好按公司和账号持久化，跨会话、刷新和重新登录有效；没有有效偏好时用模型初始强度。
- 保存失败、快速切换、配置过期、附件上传期间修改强度不得丢草稿或静默发送另一档位；沿用单一错误区域，不增加轮询。
- 用户在任务运行中切换仅影响下一条消息。接受消息时冻结强度与模型版本；排队、自动重试、worker 重启、问题卡续接保持原快照。
- 手动重试使用最新配置及账号选择，参数变化使模型节点缓存失效，已完成业务写入不重复。
- 主任务、规划、需要推理的授权判断、数值/事实核对与答复修复继承所选强度，不隐式降到 low 或关闭思考。原有简单机械核验可保持轻量策略。

### 输出限制

- 工作助手调用不发送 max_tokens、max_completion_tokens、max_output_tokens；移除旧单次 2k/4k、累计 32k/8k 输出停止条件。
- 保留真实用量统计、上下文容量、90% 压缩、输入规划预留、调用次数、节点期限、中断及有限重试。
- 服务商的输出/上下文限制继续生效；截断不能冒充成功。不新增无限续写。
- 独立报告、模型测试、记忆、Electron 等未纳入范围的调用策略保持不变。
- 已有答复 16,000 字符、流式 JSON 32,000 字符、请求通常 60 秒边界独立存在，本 Spec 不扩展它们。

## 兼容与技术约束

- 更新共享契约、管理界面、本人设置接口、发送引用与任务绑定，新的活动配置和账号选择不包含 presetId、selectedPresetId、presets。
- 通过迁移转换已有活动模型、用途和账号偏好；不修改加密凭证、业务数据，不改写历史不可变模型版本和已接受任务的语义。
- 老预设转成直接强度/参数映射，保留实际选中的主任务及独立报告行为。无法表示成强度的高级参数保留实际参数，不能无声丢弃。
- 旧任务、旧幂等重放和暂存发送引用有兼容路径；兼容集中在边界，不让旧实体贯穿新运行逻辑。
- 使用现有账号隔离、版本冲突、统一请求入口和缓存，不新增状态管理框架或依赖。
- 不动无关业务、Electron 预设、发布流程，不恢复已取消的 token 限制。

## 验收标准

- [x] 管理界面只直接配置可选强度与初始强度，没有推理预设管理和重复的开放档位输入。
- [x] 新服务、已有模型、语音协议切换、保存后用途分配和助手选择器可用；无预设 ID 的新契约贯通。
- [x] 旧 simple/advanced 预设、不同报告参数、账号偏好迁移后行为保持，旧任务仍按历史版本解析。
- [x] 权限隔离、配置冲突、保存中发送、附件上传竞态、幂等、自动/手动重试及任务快照保持。
- [x] 真实请求参数对应所选强度；未配置走服务默认，输出限制删除的既有成果无回归。
- [x] 管理配置和用户按钮在桌面/窄屏可用，私有样式无溢出；相关后端/Web检查通过，未执行项如实记录。

## 非目标与待确认问题

不新增 RAG、模型能力在线抓取、完整供应商目录、通用命名参数模板或新的管理页面。无阻塞问题。
