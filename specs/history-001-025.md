# Spec 001～025 摘要

| Spec | 做了什么 |
| --- | --- |
| 001 | 确定 Electron、React 和 Python 技术方案，建立桌面应用与本地核心骨架。 |
| 002 | 实现麦克风录音、本地保存、历史回放和异常中断恢复。 |
| 003 | 接入本地 Whisper 转写，支持模型下载、录音中出字、补尾和断点恢复。 |
| 004 | 接入在线模型服务，自动生成会议纪要，支持服务配置、推理预设和失败重试。 |
| 005 | 安装包内置 Python，增加录音暂停／继续、设置折叠和自定义播放器。 |
| 006 | 重整桌面主题、页面导航、会议页签、录音控制和命令面板。 |
| 007 | 增加会议搜索、日期筛选、重命名、复制、导出和删除。 |
| 008 | 建立公司 Web、共享后端和账号权限，打通员工消息、工作进展、日报／周报与团队看板。 |
| 009 | 增加公司模型服务管理，分别配置助手、报告和语音用途，支持模型目录、测试与加密存储。 |
| 010 | 整理 Web 各页排版、控件尺寸、内容宽度和手机响应式布局。 |
| 011 | 补齐多级面包屑、工作／报告管理、多会话、角色入口和汇报规则控件。 |
| 012 | 支持 PDF、DOCX、PPTX、TXT、JSON、Markdown、CSV 的发送、解析、来源引用和私有存储。 |
| 013 | 增加六款转写模型、中文／英文／中英混合模式及历史重转写，展示实测错误率和内存占用，并补充 GPU 评测。 |
| 014 | 增加管理员团队问答和本人督办，统一来源授权、权限撤销及历史结果失效处理。 |
| 015 | 整理多端仓库和共享包，接入 npm workspaces，更新构建路径并清理无用文件。 |
| 016 | 完善工作分页与完整搜索，统一看板统计口径，增加聊天处理反馈和模型用量。 |
| 017 | 支持多人任务并行、报告结构校验与可靠保存，增加汇报待办和站内提醒。 |
| 018 | 优化网络异常、过期登录和草稿恢复，增加首次使用入口、问题反馈及手机操作适配。 |
| 019 | 增加粘贴／拖拽附件、语音混发、MP3／HEIC／XLSX 支持、图片画廊和 PDF 预览。 |
| 020 | 接入钉钉登录、管理员配置、员工自动开户、账号绑定及本地密码设置。 |
| 021 | 让助手按明确指令执行工作和报告操作，与页面共用业务规则；提交和删除保留确认。 |
| 022 | 增加公司声纹登记、桌面登录与同步，支持离线姓名匹配、游客模式和人工纠正。 |
| 023 | 增加发言人／纯文本视图、纪要输入模式，以及观点、分歧、行动项和风险分析。 |
| 024 | 按业务重构 Web 前端，拆分页面、组件和 Hook，统一请求入口与模块边界。 |
| 025 | 将 Web 组件样式迁入 CSS Modules，与 Electron 样式分离维护。 |
