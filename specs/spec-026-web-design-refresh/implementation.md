# 实施摘要

- Web 对齐归档原型的实际灰阶、内嵌画布、侧栏层级、字体和控件尺寸；顶栏与外观页共用主题状态，保留系统随动。
- 工作助手分开呈现用户气泡、助手正文、处理反馈和业务确认，来源按需展开；欢迎区、790px 输入器、圆形发送与双行快捷卡对照原型，图片／文件集中到附件菜单，保留原状态与请求生命周期。
- 模型服务采用 220px 服务侧栏与平铺编辑区，压缩表单重复间距，模型标题与操作同行；手机纵向排列。用途分配保持独立，草稿、密钥和协议处理沿用原逻辑。
- 手机使用导航抽屉，清除重复设置横栏；保留管理员／员工的原有路由与权限。
- CSS 继续由 Web 的主题与就近 Module 维护。登录书本、Electron、服务端、API、依赖和数据结构未改动。
