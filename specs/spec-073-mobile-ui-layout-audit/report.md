## 问题与建议顺序

1. **先处理明确影响操作的局部问题**：MUI-003 长文件名裁切、MUI-004 小按钮触摸范围、MUI-005 大字面板标签。
2. **再统一布局密度**：MUI-001 页头与返回区留白、MUI-002 窄屏团队工具栏换行。
3. **用户确认产品取舍后调整**：MUI-006 宠物隐藏时的通知入口、MUI-007 材料范围说明、MUI-008 原生确认的一致性。

这些是后续修复建议，不是已实施变更。可优先使用 CSS、命中区和本地展示整理解决，避免增加 Agent 提示词、模型核对或往返；不牺牲附件部分读取／未读取提示。
