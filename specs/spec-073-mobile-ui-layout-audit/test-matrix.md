以下保留实施前冻结清单，初始均为 **NOT_RUN**；不把一行中的全部内容当作单个已通过用例。实际子范围、执行结果及未验证项已写入 [覆盖结果](../../artifacts/spec073/20261017-015130-b9afe2a/coverage.json) 和 [报告](report.md)，以最终记录为准。

| M17 | `/settings/login` | 管理员 | 所有配置子页、敏感字段显隐、长地址、复制、校验、保存反馈与授权提示；仅合成配置 |

| M19 | `/settings/usage` | 管理员 | 统计、筛选、长服务名／模型名、横滑表格、固定列、失败明细、分页和空态 |
| M20 | `/settings/memory` | 员工／管理员 | 搜索、长记忆、编辑／删除确认、空态、提示与失败恢复 |

## 跨页面状态与设计检查

| 编号 | 条件 | 关注点 |
| --- | --- | --- |
| S01 | 空、单条、多页、无搜索结果 | 空态位置、分页可达、统计与内容一致，不用大空白填充 |
| S02 | 长中文／英文／URL／文件名／姓名，大数字、跨年日期 | 合理省略或换行、信息不压缩图标、操作位置稳定 |
| S03 | 初次加载、延迟、局部刷新、切 Tab、返回／刷新 | 闪烁、双 loading、页面跳动、错误范围、滚动和草稿保持 |
| S04 | 弹窗、下拉、抽屉、二次确认、预览 | 视口内定位、层级、滚动、遮罩、触摸关闭和焦点返回 |
| S05 | 固定／吸底操作、输入聚焦、低高度、横屏、安全区 | 最后一项可见、按钮不遮挡正文、滚动不失控；真实键盘另记 |
| S06 | 上传／保存中、网络失败／恢复、取消／重试 | 禁用原因清楚，错误可读可操作，状态不残留，未完成不伪装成功 |
| S07 | 浅／深色、系统切换、文本放大、减少动态效果 | 层级、对比、布局、按钮可达；不能为截图关闭待检动效 |
| S08 | 宠物隐藏／显示、通知角标、正在工作／已完成 | 不改变已确认的悬浮规则；记录真实遮挡及不可替代操作受影响情况 |

## 必查连续旅程

| 编号 | 起点 → 过程 → 最终结果 | 重点证据 |
| --- | --- | --- |
| J01 | 登录 → 打开导航 → 系统设置 → 子页 → 返回主菜单 → 聊天 → 刷新 | 两套菜单、当前选项、关闭、返回及加载衔接 |
| J02 | 输入多行草稿 → 打开“＋” → 上下文／强度／权限分别选择 → 关闭 → 继续输入发送 | 浮层位置、草稿保留、触摸和低高度；真实软键盘另测 |
| J03 | 多批上传文档＋图片＋音频（累计超过单次上限）→ 同名与长名 → 上传失败／删除／重试 → 发送 → 回复／成果 → 刷新并追问较早材料 | 附件卡片和错误、发送限制、无重复状态、最终结果及跨批材料展示；只用隔离数据 |
| J04 | 有文字草稿 → 长按录音 → 上滑取消 → 再次长按松手发送 → 失败提示／成功消息 → 播放／转文字／改文字 | 波形与取消反馈、焦点、只发送语音、无草稿录音闪现、多音频条和修正文案 |
| J05 | 发送 → 思考／工具执行／正文流 → 切其他页 → 返回 → 完成／中断 → 查看上下文 | 状态去抖、正文稳定、输入可达、宠物状态与上下文同步 |
| J06 | 请求多图 → 后端串行状态 → 等待／生成／成功／失败／取消 → 最终回复 → 预览 → 刷新 | 同行缩略图、不同占位、一次任务成果入口、预览关闭及已完成图片加载 |
| J07 | 会话进入工作 → 清单勾选／编辑／材料 → 失败重试 → 保存 → 返回 → 刷新 | 返回不重叠，长说明下操作对齐，滚动位置和最终可见结果 |
| J08 | 会话进入日报／周报 → 草稿编辑 → 校验失败 → 保存 → 提交 → 历史／团队嵌入详情 → 返回 | 顶部层级、底部按钮、跨年日期、只读差异及首末屏；包含无工作可生成的提示 |
| J09 | 团队工作／报告切换 → 日报／周报 → 范围／员工／关键词组合筛选 → 无结果 → 清除 → 详情 → 返回 | 筛选条换行、时间语义、首次加载与列表位置 |
| J10 | 通知入口 → 提醒／公告 → 标已读 → 详情 → 返回；管理员草稿 → 编辑发布 → 列表删除确认 | 未读角标、长正文、列表操作、确认弹窗和最终列表结果 |
| J11 | 账户／规则／登录方式的子页 → 长字段 → 错误 → 保存 → 返回；模型服务 → 模型设置 → 用途 → 保存 | 不漏弹层、标签过多、字段和操作对齐、禁用／错误状态 |
| J12 | 提交反馈 → 记录 → 详情 → 管理员处理 → 用户查看；成员／记忆／声纹列表 → 详情或编辑 → 取消／保存 → 返回 | 角色差异、长内容和状态反馈、弹层关闭、末页末项与空态 |

J04 的真实录音权限、真机键盘与钉钉行为单列；模拟音频只验证产品状态与交互。J03／J05／J06 可使用受控模型，但完整链路结论必须经过实际待检入口，不能用预制最终页面代替。

## 结果格式

- `report.md`：冻结基线、实际设备／浏览器、页面与完整流程覆盖、设计结论、未执行／受阻、证据位置和资源清理。
- `issues.md`：`MUI-001` 起编号，严重度、角色／页面／条件、操作步骤、预期／实际、影响、图片／视频、建议、相关用例。
- 截图索引：每图的用例与环境、稳定态／动态态、审阅结论及关联问题；生成但未审阅的截图不得标记完成。
- 独立验收：审计交付 `PASS / FAIL`，产品结果另列；任何失败／未测都不因交付 PASS 而变为已通过。
