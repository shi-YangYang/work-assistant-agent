# 附件准备性能对照

## 状态

普通路径前后配对满足门槛；新增格式、重复／成功复用与四任务并发验证完成。本文为实施验证记录，不代替独立验收，也不代表真实模型 low／high 或线上容量验收通过。

## 环境与口径

- 基线为 `ca9d7c0036e73e904c6adbea296440f2ca59923d` 的 `git archive` 快照；没有重置开发工作区。
- 本机为 Mac17,2、10 个逻辑核、16 GiB 内存。转换性能使用宿主 LibreOfficeDev 26.8；固定生产镜像 LibreOffice 7.4.7.2 的真实转换由协调 Agent 单独验证，不能把宿主耗时当作线上容量结论。
- 使用本次独占 PostgreSQL 容器 `noria-spec071-test-postgres`、固定测试端口 15471、临时合成账号与媒体。浏览器和并发负载另有独立 schema；没有读取生产数据。
- 路径为实际上传 API → 消息 API → `process_job` → 解析子进程 → 数据库分段 → `find_documents`／`read_document` → 完成回复 → 再读消息。只替换外部模型，不替换解析器、文件、数据库或工具。
- 每组 30 个正式样本，另记录首轮 1 次并排除于分位数；前后使用同一冻结字节与固定模型，按组和样本编号配对。没有清除操作系统缓存，因此首轮不等于机器冷启动。
- 上传耗时单独记录；除已解析复用组，计时从发送开始，到模型首次调用／最终消息读取。已解析复用组先模拟已完成的附件准备，再计 worker 恢复路径；其 priming 耗时另存，不冒充用户首次读取提速。
- `prepare_ms` 为 worker 准备阶段；`first_model_ms` 包含发送和模型请求前应用处理；`total_ms` 包含受控模型和全部实际工具／持久化。不是服务商推理耗时、HTTP SSE 首字或浏览器绘制时间。
- 常规单任务对照按相同顺序在前后两个时段执行；保留所有尾延迟，不删异常值，不据此推断微小差异来自改动。
- 真实 low／high 未执行：本次隔离环境没有可用模型配置，未访问线上或复制真实凭证。首段 SSE／浏览器绘制不在本脚本计时范围内。

## 四任务一慢三快

在独立 `spec071_load_*` schema 中运行实际 `run_slots`，单 worker 进程 3 个任务槽、转换槽 1、直接解析槽 2。4 个账号同时提交：一份真实 3501 段 DOC（约 394 KB）和三份带不同账号标记的 TXT。没有模拟 sleep 或替换转换／队列；每条最终正文与自身附件引用一致。

| 任务 | 等待实际 worker 接手 | 首次模型 | 最终完成 |
| --- | ---: | ---: | ---: |
| 大 DOC | 347.6ms | 2100.8ms | 2566.9ms |
| TXT 1 | 87.8ms | 517.8ms | 1216.2ms |
| TXT 2 | 67.0ms | 497.4ms | 1231.3ms |
| TXT 3 | 1173.5ms | 1393.7ms | 1937.7ms |

三条轻量任务全部先于大 DOC 完成；第四个任务仍等待已有 worker 槽，这不是无限并发。四条任务各 3 次模型调用；DOC 转换 1 次，TXT 直接解析各 1 次。大材料回复明确是已读部分片段，没有把首段读取冒充全文分析。

每 250ms 采样本测试进程及可追踪子进程，观察到聚合 RSS 最高 485696 KB（约 474 MiB）、`ps` CPU 最高 136.1%、进程数最多 3。不包括 PostgreSQL／浏览器／容器，CPU 为操作系统报告值，离散采样可能漏过瞬时峰值。该单次四任务案例验证不被转换阻塞，不能据此推断生产最大并发或计算有代表性的负载 p95。

## 未覆盖的性能指标

- 未运行真实模型 low／high 各 3 对：隔离环境没有可用服务配置；没有为了补样本访问生产或复制密钥。
- 未计服务商首字、HTTP SSE 首字、浏览器绘制、真实用户上传网络与生产多 worker／多租户容量。协调 Agent 另用独立 Redis 和受控分块正文完成实际浏览器流式→终态→刷新功能验证，不能代替这些性能指标。
- 没有清 OS 缓存或重启机器测严格冷启动；没有将宿主 LibreOfficeDev 26.8 的速度外推至生产 7.4.7.2。固定生产版本功能验证单独记录。
- 性能采样后，生产 7.4 边界验证修复了 ODS 重复空白区域被误计入内容上限、严格等值布尔／数值 0／1 的保存类型差异，以及缺失／非法布尔缓存不能默认成 false。这些最终修复不在本次采样源码哈希内，由 [公式与目标版本补验](rework.md) 核对；没有改变普通路径、模型轮次或调度。已测宿主正常样本未触发这些边界，未将其性能结果冒充生产版本的实测耗时。
