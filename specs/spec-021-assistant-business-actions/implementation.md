# Implementation

已接入本人工作创建／更新、报告生成／草稿编辑、提交／单条删除确认及汇报待办查询。页面新增手动工作与截止日期；管理员督办仍归本人，员工业务保持既有授权边界。

- `business_writes.py` 复用页面与工具的写入规则；`business_actions.py` 保存操作回执、版本及确认影响。独立语义校验仅读取真实用户文字与用户历史上下文，写入前再次校验权限、来源和版本。
- 同消息操作意图绑定持久记录，换 tool-call ID／step 不重复创建；新消息允许新工作。报告仍异步交专用任务，不占住聊天任务等待。
- 操作卡来自持久结果；生成状态、确认／取消、冲突与已提交结果分别展示。删除回执只保留必要引用，不复制已删除正文。
- 授权校验区分成功查询与前置写操作；只使用本次查询摘要和重新授权的来源元信息。最终答复由独立语义请求核对，保留有实际查询证据的业务事实与正常澄清；本轮执行叙述统一由持久回执生成。历史操作以当前状态提供给模型，避免复用过期的待确认叙述。
- 答复核对最多增加一次调用，沿用现有预算；原文分段只能保留或排除，不接受核对模型改写。来源编号、完整分段和业务查询工具类型由程序复核；核对失败仍展示已保存结果。流式请求协议与用量记录不变，页面先显示处理进度，核实后显示答复。
- 迁移为 `0010_business_actions`，旧工作来源默认建议确认、截止日期为空。测试库与开发库已分别升级；开发库升级前备份由协调 Agent 完成。

## 限制

自然语言意图仍依赖模型的语义判断；权限、版本、确认及幂等由服务端强制约束。纯语音／文件材料不能自行授权写入，用户须用文字明确要求执行。未运行 Electron、发行包或远端 CI；未 commit／push。
