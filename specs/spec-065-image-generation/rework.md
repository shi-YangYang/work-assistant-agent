# 未发布图片缓存恢复返工

独立验收复现：超过保留期的未发布 PNG 已被清理，但操作仍保留 `files` 元数据；重试返回成功成果，下载实际为 404。

## 修改

- 发布前在数据库连接之外校验缓存文件的普通文件类型、非符号链接、大小和 SHA-256；读取期间检测文件身份变化。
- 图片发布与清理复用已有 `generated-storage` 事务锁。清理在锁内获取保留集合；发布在锁内快速复核已校验文件的身份，避免清理旧快照删除即将发布的文件。完整读取和摘要计算不占用数据库连接。
- 缓存失效清空待发布元数据，只查询已有 task_id 并恢复下载。原任务或原结果返回 404／410 时明确结束为失败；不会重新提交生图，也不会留下成功成果链接。
- 完好缓存仍直接发布；发布前现有租约、归属、来源与服务撤销校验保留。
