## Regression Risks

- 实际服务回归仅覆盖现有 Wan2.7 Token Plan 方图。Pro 4K、未知兼容模型及原生异步实服仍是受控协议／业务测试，未验证具体账号权限或每种模型质量。
- 兼容范围限于现有两个请求／结果协议及 PNG。不同协议、Base64、JPEG／WebP、参考图或编辑需要独立适配，不能仅修改模型 ID 声称支持。
- 外部成功与本地回执持久化仍无法保证端到端 exactly-once；沿用无回执未知请求不盲目重发、有回执只恢复结果的规则。
- 原完整 Spec 尚未实测项及既存无关架构失败沿用[此前验收](acceptance.md)的明确限制，不被本次 PASS 覆盖。
