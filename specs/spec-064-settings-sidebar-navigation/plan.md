# Plan：系统设置侧栏导航

## 对应 Spec

[系统设置侧栏导航](spec.md)。菜单切换不触发页面跳转，具体菜单项沿用现有路由导航；实施及独立验收已完成。

## 涉及模块

- `Sidebar`：切换主菜单／设置列表、返回按钮、焦点交接及响应式样式。
- `Shell`：保持现有路由、身份过滤和页面生命周期；按需要传递身份范围，不另建导航服务。
- `useNavigationDrawer`：保留移动端抽屉的关闭、遮罩和焦点规则；仅清理失效的设置浮层假设，保留其他弹层所需处理。
- `navigation-items.ts`：继续作为菜单数据来源，不另存一份入口或权限列表。

## 修改顺序

1. 按 Spec 梳理菜单层级、路由同步和焦点交接的实现边界。
2. 增加布局私有菜单状态 Hook，将手动选择与当前路由／身份范围关联。初始化和真实导航时由目标路由决定层级，同路由重渲染保持手动选择。
3. `Sidebar` 替换设置浮层，复用已有导航区域和已过滤入口；处理返回按钮、当前项高亮及切换后的焦点。
4. 适配图标栏和移动端抽屉，清理旧设置浮层样式与专有行为；不修改共享 Popover 或业务表单。
5. 执行导航子系统定向检查及有限浏览器验收，修复本次改动直接引入的问题。
6. 由新的独立验收 Agent 检查需求覆盖与验证证据，完成后记录验收结果。

## 状态与数据流

```text
身份 + 当前路由 → 现有 allowed / allowedSettings → Sidebar
                     ↓
           路由默认层级：主菜单 / 设置
                     ↓
     入口 / 返回 → 当前路由下的临时手动选择
                     ↓
             同一导航区域替换列表

具体链接 → 现有离页检查 → Router 成功导航
                           ↓
                 同步菜单并收起移动抽屉
```

- `main | settings` 与 `expandedNav` 是不同状态，不能用抽屉是否打开推断菜单层级。
- 用路由 key 关联临时手动选择，避免用持续监听 pathname 的副作用把返回操作立即覆盖。刷新时不恢复手动覆盖。
- 身份范围使用现有公司／成员／角色边界；退出或身份变化后清理菜单状态。
- 菜单按钮不执行 `navigate`、`history.back` 或请求；不写草稿，不挂载额外页面。
- 焦点转移只响应用户菜单切换，不因后台数据更新反复抢占右侧输入焦点。

## 接口变化

仅布局内部 Props 和菜单状态 Hook；不更改 HTTP 接口、共享 API 类型、路由路径、服务端授权、数据表或模型提示词。

## 测试计划

文档阶段按 S0 检查需求、引用和 diff，不运行测试。实施涉及布局、路由同步及移动端抽屉交互，按 S2 运行导航子系统检查，不默认执行全量测试、Build 或模型调用。

定向检查：

```sh
npm run test:web -- tests/web/dom/shell/sidebar-navigation.test.tsx tests/web/navigation/navigation.test.ts tests/web/navigation/routes.test.ts
```

源码按项目配置格式化；若调整 `Shell` 的类型契约，再执行 `npm run typecheck:web`。已通过的检查不重复。

覆盖以下行为，优先补充有实际交互意义的 DOM 测试：

- 员工与管理员的主菜单／设置菜单内容，返回后的高亮，云搭子保持禁用。
- 菜单切换不改 URL、历史或右侧实例；用固定输入验证草稿、流式消息和录音不因菜单切换中断，不依赖真实模型或麦克风。
- 设置深链接、刷新初始化、命令入口、浏览器前进后退、无权地址回退；不同身份不复用导航选择。
- 相同路由重渲染及抽屉开关保留手动选择，成功导航后正确同步；取消录音离页时保持原页面与菜单状态。
- 抽屉内切换不关闭，选择页面后关闭；键盘进入、返回、Escape、遮罩及重新展开，断点变化不丢层级。

浏览器选取桌面、平板图标栏、手机三种代表宽度，检查管理员较长设置列表、低视口滚动、浅／深色及当前页边界；保存必要截图即可。手机原生浏览器与钉钉实机未执行时应明确记录，不将响应式模拟等同于实机通过。

## 风险与处理

- 路由与手动菜单选择互相覆盖：限定手动状态作用于当前路由，避免每次渲染都强制跟随 pathname。
- 把返回菜单误写成路由返回：以“不变更 URL、不触发页面卸载”断言约束，避免退出应用或丢失编辑。
- 移动端焦点停在被替换列表或抽屉被误关：切换后显式交接焦点，抽屉关闭与菜单切换独立处理。
- 删除设置浮层时影响通知／命令面板：仅移除设置专有代码，现有通用焦点及弹层优先级保留。

## 迁移与回滚

无需数据库或用户配置迁移；所有路径保持。回滚只涉及前端布局与本次新增 Hook，恢复旧导航呈现不影响已有设置数据。

## 实施验证结果

- 导航子系统累计 19 项通过。首轮发现抽屉关闭后的焦点恢复问题，修复后仅重跑受影响的 8 项侧栏测试并全部通过。
- 改动源码已用 Prettier 整理。未调整 Shell 类型契约，未运行全量测试、构建、Lint 或类型检查。
- 隔离页面使用正式侧栏组件，在桌面、平板、手机尺寸和浅／深色主题下检查通过；未进行手机或钉钉实机验证。
- 独立验收 PASS；完整证据与限制见 [acceptance.md](acceptance.md)。
