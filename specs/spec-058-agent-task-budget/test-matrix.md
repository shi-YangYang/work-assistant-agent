# 测试矩阵

目标：证明额度扩大、计数一致、恢复安全、及时反馈与收尾可用。实际执行证据见下方；矩阵是验证目标，未单独执行的旅程不视为通过。

| 组 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| 策略 | 普通任务、新旧策略、配置更新 | 新轮次 1800s／64 工具／96 模型；在途策略冻结，旧任务不免费扩容 |
| 原边界 | 17+ 工具、33+ 模型、36+ 图步、421s | 仍能执行并正确交付，不被残留常量截断 |
| 新边界 | 每种额度 N-1／N／N+1 | 预占精确，越界操作实际未执行；有收尾额度 |
| 并行 | 剩余 2 次同时请求 5 个工具；模型也并发预占 | 最多 2 个工具获准；总计数不超额，未执行项有明确结果 |
| 重试 | 工具瞬时失败后成功、模型失败后重试、预算不足 | 工具逻辑调用一次；模型实际尝试逐次计数；仍最多 3 次自动重试 |
| 恢复 | 预占后崩溃、调用成功回执已存但节点未完成、worker 换租约 | 不免费重置，不重复业务，不重复扣同一恢复输出；未知消耗保留 |
| scope | 材料／业务版本变化、模型配置恢复、图重建 | 当前执行轮次用量和截止继承，结果按既有版本规则失效 |
| 人工续接 | 主动重试、回答澄清、确认操作、重复提交续接请求 | 新活动轮次预算，原操作回执不丢；人工等待不耗时，幂等有效 |
| 来源隔离 | 员工、管理员、其他账号／公司、多会话同时执行 | 预算和成果各自归属；越权、删除、确认保护不受额度影响 |
| 时间 | 准备、工具等待、模型思考、退避、排队、人工等待 | 前四项计时；排队、终态后人工等待不计；worker 恢复不延长期限 |
| 流式 | 持续正文、长思考、只有心跳、服务无响应、断网 | 总时限与网络静默独立；有效流不中途被旧 420s 限制截断 |
| 软收尾 | 工具耗尽、模型探索额度不足、进入 120s 预留 | 关闭新探索，保留主模型答复，禁止辅助模型消耗收尾名额 |
| 硬截止 | 收尾期间仍超时、最后请求失败、没有可用资料 | 不再调用模型；保留安全可用成果，明确 partial／blocked，不假成功 |
| 中断 | 收尾与中断同时到达、长工具取消、后台报告已入队 | 中断优先，释放可取消资源，已提交结果不重做；子作业状态如实保留 |
| 长短任务 | 一个长任务与其他用户短任务同时执行 | 可用 worker 槽位正常处理短任务，预算不互相锁住或串用 |
| 反馈 | 内部提醒、实际收尾、终态、提醒阈值跨越 | 提醒只供模型使用；用户看到真实活动、收尾与结果，未执行节点不一直等待 |
| 可见边界 | Job、SSE、节点详情、用户错误、模型最终答复 | 不含内部预算字段或额度说明；停止时说明已有结果和未完成项，不透传原始预算错误 |
| UI | 展开后切换节点、窄屏、短暂阶段、秒数增长 | 无额度组件、剩余时间倒计时或额度警告；展开状态保持，秒数变化不挤压错位，既有防闪烁与光带不退化 |
| 重连 | 刷新、多标签页、旧 attempt／fence／seq 乱序、字段缺失 | 不重置、不倒退、不串轮次；旧消息保持原有显示 |
| 请求量 | 正常流、内部预算变化、客户端计时、断线 | 复用 SSE，内部计数变化不单独发公开事件；无新增定时 GET／POST，无每秒数据库写入 |
| 普通问答 | 无需工具的提问与长文 | 无额外模型调用；有答案即结束，不因额度增加拖延 |
| 搜索 | 多关键词、多网页、翻页、搜索失败与重复结果 | 足够资料即收尾；受控复杂研究超过旧上限；引用真实结果 |
| 公司业务 | 员工创建／更新工作、报告入队；管理员查询团队与督办 | 权限与确认不变，回执正确，预算终止／重试不重复写入 |
| 记忆 | 保存、相同事实重复调用、清空后恢复旧任务 | 去重与来源屏障不退化，成功回执正确，恢复不复活旧记忆 |
| 材料／沙盒 | 附件阅读 → Python／内置工具 → 生成文件 → 修改文件 | 实际成果可下载、可继续修改；父预算与沙盒自身限制独立 |
| 混合旅程 | 搜索 → 整理方案 → 生成文件 → 用户要求写入工作 | 同轮共享预算、跨轮新预算；私人成果不自动进入公司业务 |

## 执行方法

- 先运行纯策略／计数和隔离集成测试，再进行受影响 UI 与少量真实旅程；使用注入时钟和受控模型达到限额，不靠长时间 sleep 或反复真实请求撞上限。
- 集成使用真实 PostgreSQL 事务、worker／harness、SSE 与隔离账号；HTTP／模型故障定向注入。所有 fixture、端口、Redis namespace、文件和沙盒任务与日常环境隔离。
- 框架派生限制分别验证最大合法串行路径、合法批次和有界恢复历史；不通过无限调大图上限掩盖循环。
- 真实旅程固定服务修订、思考强度、输入与资料，记录每条用例的实际调用数、耗时、任务状态和最终成果；不得把单次模型响应变快当成稳定性能提升。
- 测试报告保留用例、结果、失败原因和证据路径。通过项不无理由重跑，失败只修复并复验受影响范围；验收缺口明确标注，不无限扩张测试矩阵。
