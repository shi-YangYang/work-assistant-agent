# 返工：硬截止交付校验

依据 [独立验收](acceptance.md)，修复硬截止降级交付的两处校验遗漏。

- 无论正文来自 Redis 还是已持久化的 `replyStream`，交付前均重验权限、来源与版本；无效片段不得写入正式答复。
- 沿用正常交付的记忆来源屏障。用户修改、清空或关闭记忆后，旧的记忆声明不得借降级路径重新交付。
- 保留仍有效的正文、成果和业务回执；不新增模型核对、不重放工具，不把整条已完成操作回滚。
- 使用独立验收的两个隔离复现与直接相关交付测试验证；补充有效片段继续保留的边界。已有通过的计数、真实模型和 UI 测试不重复执行。

返工后由新的验收 Agent 独立验收，原 FAIL 和复现日志保留。
