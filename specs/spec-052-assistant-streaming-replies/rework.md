# 返工

## 成果来源的流式范围

团队查询保存的成果可能在任务中断后继续被读取。成果保留团队来源，尚未正式交付的消息却没有继承该范围，下一轮预览因此被误判为个人内容。

- 成果目录、读取及显式引用入口使用成果时，保留并校验它的真实来源范围。
- 预览发布和刷新读取校验已读取成果的版本与访问范围；团队来源缓冲到完整核对，失效来源撤下预览。
- 加入“团队查询→保存成果→中断→下一轮读取”的回归及成果失效断言，保留本人普通成果的流式能力。
- 不调整团队访问权限、数据库结构或核对模型预算。仅运行相关定向检查，完成后由新的独立 Agent 验收。

## 长文核对输出截断

真实模型核对原长文时，2,000 个输出 token 全部用于推理，正文为空，供应商返回 `finish_reason=length`。原节点的 3 次重试机会重复同一配置，无法完成核对。

- 保留明确的输出截断标记，不把内容审核、普通格式错误或网络失败混为输出不足。
- 专项核对首次截断后，在下一次既有重试中关闭已知混合模型的额外推理，继续核对相同正文和证据。未知供应商不擅改参数。
- 同一候选的截断信息随任务保存，恢复任务时不反复使用已耗尽预算的推理配置；新的候选重新判断。
- 保留严格结束标记、JSON 格式与证据校验，不增加重试次数、超时或输出上限，不跳过数值核对。
- 定向验证协议标记、重试与恢复、失败边界；使用原长文请求进行真实模型完整流程复测。
