# Spec 001 — 产品与技术基础

## 状态

DONE · 2026-09-09 · [独立验收 PASS](acceptance.md)。本 Spec 只代表当时的开发骨架；后续能力见 [Spec 索引](../README.md)。

## 背景

项目已有目录骨架，需确定 Meeting Agent MVP 的产品边界并建立可运行工程。长期目标沿用 [使命](../../constitution/mission.md)，用户已选择 [Electron](../../.ai/decisions/0003-electron-desktop.md) 和 [双平台](../../.ai/decisions/0002-target-platforms.md)。

## 目标

明确产品、技术方案与模块边界，交付按文档可安装、启动和验证的最小桌面应用。

## 非目标

真实录音、ASR、LLM、业务数据库、周报 / Memory、产品多 Agent、安装包 / 自动更新 / 云部署；不迁移既有目录或更改许可证。

## 当前行为

实施前只有目录和说明，无应用入口、依赖、测试或构建。

## 目标行为

桌面显示真实核心连接、空会议列表和未接入能力。没有模型、LLM 密钥或麦克风权限也能启动；Python 缺失时窗口可用、错误可理解并支持重试。演示数据必须标注，未实现操作不能伪造成功。

## 功能需求

## 边界条件

关闭和重连需清理子进程；超时、非法响应和并发请求有界。当前只设计音频积压、ASR / 总结失败及收尾顺序，不把流程文档当作真实业务验证。平台专属加速与未知硬件性能不得默认成立。

## 技术约束

采用 [决策 0004](../../.ai/decisions/0004-foundation-stack.md) 的 Electron / React / TypeScript、Python 3.12 和 stdio。保留既有结构及 MIT LICENSE，不重新初始化 Git，不绑定具体 ASR / LLM，不强制编排框架。正式分发遵守 [决策 0005](../../.ai/decisions/0005-self-contained-desktop-distribution.md)。

## 兼容性要求

目标为 macOS / Windows。本阶段验收是 macOS ARM64 实机与 Windows 配置 / 路径检查；当时未运行 Windows，不宣称其运行通过。最低系统和安装包另行验证。
