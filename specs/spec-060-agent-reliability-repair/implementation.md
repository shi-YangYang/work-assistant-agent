## 状态

## 改动

- 统一工具进展控制：相同结果、交替调用、目录空转和已读完范围提前停止；合法分页、修参、新来源和版本冲突仍可继续。状态随任务持久化，内部重试与新调用分开计数。
- 操作结果依据真实回执，保留完整模型正文与流式回答。不同目标、来源、实际字段、副本和报告提交要求不能互相清除失败或复用成功；参数纠正后能承接原事项，兼容建议也使用真实内部事项标识。
- 工作变更按原子范围校验，省略保留字段不再误拦。建议转工作保存正文和条件；合法部分可分步保存，整份计划完成后才允许单回执直接结束。
- 完成判断复用已有计划和本地回执，没有新增全局模型核对。待确认、异步处理、未执行和成功分别呈现；未完成的内部步骤不要求用户重复授权。
- 原计划保存完整后，核销先前错误保存位置留下的拒绝；来源／计划不兼容证据持久保留，不因后续省略字段误清。兼容建议使用实际变更范围，恢复重放不多写版本。
- 未尝试但已识别的剩余事项随原回答的可选元数据交付，普通收尾与预算收尾统一接收；完整正文继续流式显示，不增加单独的状态工具轮次或模型审稿。
- 短文件按内容量合页，长文件继续有界分页；记忆修改保护人工格式和未选片段，关闭记忆后不泄漏全文。
- 明确临时提问工具的使用说明；工具目录继续负责发现能力，执行入口保留权限与来源校验。
- 拆除流式反馈模块等导入环；迁移 43 项旧测试，保留有效的权限、撤权、恢复与零重复写入断言。

无新增服务、第三方依赖、数据库迁移或历史数据回填。具体文件见[改造目录](plan.md#改造目录)。
