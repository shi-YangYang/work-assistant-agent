# 返工

## 必须修复

- **结果归因**：不同来源条目、对象或实际字段不能因步骤号相同而互相清除失败。修正原失败成功时仍应正确收敛；操作反馈与最终任务结果使用一致依据。
- **网页进展**：抓取时间和缓存标记不代表新内容。覆盖刷新、完整阅读后的空页、关键词定位及顺序分页；保留真实内容变化和合法新范围。
- **拒绝路径**：混批与无效收尾仍不执行，但其结构化拒绝必须进入进展观察，防止绕过收尾上界。
- **否定范围**：显式字段拒绝不能因错误分类而跳过原子范围检查；真实授权、目标和来源拒绝保持有效。
- **当前修改指令**：真实 T73 已完整创建两项工作，但随后只改第二项下一步的明确指令被计划判为保留。检查计划输入、来源承接、已完成步骤与缓存；修复通用根因，不能靠样本文字强行授权。
- **其他业务结果**：报告类型与周期、报告栏目、兼容进展建议同样需要稳定的事项身份，不能由另一项成功清除失败。
- **真实待答交互**：临时提问框已有真实持久问题时，即使另有权限拒绝，也应保留用户回答该问题的通路。
- **修正恢复窗口**：worker 在范围修正标记和节点执行之间中断，恢复时仍须进入同一修正节点，不能凭提前标记跳过未完成操作。
- **漏传恢复标识**：修参时模型未携带原事项 ID，已有独立授权器可根据真实失败候选和原用户来源明确承接同一事项；服务端继续验证操作、目标、来源和字段。不能按步骤号或标题相似自动清除失败，也不额外增加正常路径模型调用。
- **缺信息屏障**：同一已绑定事项仅改写标题或参数，不代表用户提供了新信息；不同事项、实际新增来源与参数纠错分别处理。
- **兼容建议归因**：拒绝结果与成功回执携带已验证的内部事项 ID；修正内容成功后清除本项旧失败，不影响其他事项。
- **副本身份**：未显式填写的第 1 份与第 2 份仍是不同事项；默认值必须参与身份校验，不能由另一份成功清除原失败。
- **历史回执复用**：显式标识、精确提案与跨轮自动匹配使用相同的身份检查；已成功操作核对实际工作字段和报告提交要求。旧事项从有权读取的真实回执补齐身份，不能因缺新字段而重复执行。
- **部分保存后的收尾**：当前原子组保存成功不代表整份工作计划完成。根据同输入、目标与基准版本的计划及真实回执判断剩余字段；有剩余时不走单回执直达，继续现有模型流程，完整单操作仍保留快速返回。明确保存位置优先，同一事实不默认同时写正文和独立进展。
- **错误提案核销**：原计划全部真实保存后，可核销先前被判为额外字段的未执行提案；不同明确事项、进展子操作、来源和计划不能互相核销。来源变更的不兼容证据须保留，不能因后续计划省略已完成字段而消失。兼容建议按实际变更范围记录反馈，持久重放不能多写一版。
- **未尝试事项的交付状态**：模型已经识别但未执行的事项，可随现有正文标记的 `remaining` 元数据交付，不再要求为此另走工具轮次。普通收尾也要接收这些信息，不能只在预算耗尽时接收；与已有剩余范围合并，不授予权限、不恢复旧操作，也不能清除真实失败。仍保留完整正文和正常流式，不增加审稿或正文关键词识别。

## 提示词精简的质量边界

建议转工作必须保留靠前的前置提示：先保存／读取真实成果条目，再在首次创建中完整保存内容并关联条目。只合并一般重复说明，不把关键步骤完全藏入长工具说明。低强度多轮实测曾出现首次创建无关联、随后长时间补来源失败；失败轨迹保留，不能用后续保存的成果补证首次创建，也不能放宽授权校验让测试通过。

## 变更计划格式契约

- 文本字段的 Schema 与实际校验一致：普通文本由后续提案核对，计划只允许 `null` 或明确清空的空串；不能向模型声明允许任意字符串，再把正确文本当作格式错误拒绝。
- 固定反例证明并修复这一不一致；现有重试反馈定位具体字段，不增加重试次数、模型核对或授权放行。十字段完整性、原文引用、保留字段及状态／日期规则继续生效。
- 历史四次失败没有留存具体解析原因；新的同输入诊断首次成功，不能将其追认为历史失败根因或修复效果。修复后只验证计划解析相关模块和一次单字段真实流程，保留原始失败记录。

## 主模型工具契约澄清

真实 T73 第四轮出现 2 次错误依赖、4 次参数错误后才完成两项创建，无重复写入。现有工具说明将业务操作编号、依赖对象与工作字段位置表述得过于泛化。

- `step` 仅标识当前消息的业务事项，不计其他工具调用；纠错保留原编号。
- `requires_step` 仅引用当前消息中已成功的 `execute_business_action`，不引用保存建议或查询。
- 工作字段放在 `changes`，创建要求 `changes.title`。
- 只修改工具说明，不调整执行逻辑、权限、Schema 或修参策略。保留首轮真实失败证据；定向检查后复验受影响的 T73 流程。max 对照已完成，不追加性能采样，结果只适用于第一版提示词。
