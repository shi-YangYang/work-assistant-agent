# Noria 产品定义与全端品牌更新

## 状态

已实施，品牌代码与资源独立验收通过；实际验证范围与未实测项见 [验收记录](acceptance.md)。

## 背景

现有助手已支持材料理解、联网查询、方案产出、多轮修改和业务操作，对外介绍却仍偏重记录与汇报。统一品牌为 **Noria**，名称灵感来自**诺亚方舟**，采用用户提供的小熊图片作为正式 Logo。

## 目标

- 明确定位：**Noria 是面向公司的云端工作助手，理解材料、协助完成任务，并按用户意愿连接工作管理与团队汇报。**
- 统一 Web、Electron、浏览器图标、安装包和产品文档中的品牌名称、图形与介绍。
- 保留现有功能、账号、数据、配置和界面交互。

## 非目标

不重做页面布局、配色或功能流程，不新增导航和设置。Muse 式任务协助是体验方向，本次不新增云电脑、任意代码执行、第三方业务写入或主动定时任务，也不承诺与其他产品功能等同。

## 当前行为

- Web 支持多会话、文字与附件理解、联网工具、任务成果、工作／报告操作和团队问答；公司 API 与 worker 执行任务。
- Electron 支持本地录音、转写和会议纪要，游客可用，登录公司后可同步员工声纹。
- 用户可见名称混用“工作助手”“公司工作助手”“桌面会议助手”等；README 仍以仓库名呈现产品。
- 品牌资源集中在 `packages/ui-web/brand/`，部分界面用 CSS mask 显示旧单色 Logo。
- 桌面显示名称、打包名称与内部身份分离；旧内部名称关联用户目录和系统密钥存储。

## 目标行为

### 产品定位

主流程为：提出目标与材料 → 助手分析、查询、产出结果 → 用户继续修改 → 按用户要求写入工作或报告。

例如：上传客户需求，整理实施计划，调整第二项时间，再将前两项加入“我的工作”。只要求计划时，成果不自动变成工作记录或团队汇报。

员工处理自己的材料与任务；管理员在授权范围内了解团队进展并跟进。公司角色、资料权限与执行规则继续生效，管理员权限不等于能查看员工全部私人聊天。

“云端”指公司服务端承载 Web 任务与数据，可部署于云服务器或公司内网，不表示已有托管式多租户 SaaS。Electron 是同一品牌下的桌面会议入口，仍默认本地保存，不因品牌变化上传会议。

### Logo 与各端图标

- 以用户提供的小熊为形象基础，生成白底圆形头像，保留奶白毛绒、浅蓝围巾与耳朵、指南针吊坠及角色神态。
- 所有品牌图标使用同源头像与白色背景，圆形外透明；加载头像适当放大，不能拉伸或截断耳朵等关键轮廓。
- 浏览器 16／32px 图标、手机网页图标、Electron 窗口／Dock／任务栏图标、macOS `.icns`、Windows `.ico` 全部更新；README 与归档原型的品牌资源同步。
- 保留一个正式源图和必要的派生资源，集中在原品牌目录。最终资源不能依赖临时附件路径。
- 彩色 Logo 使用图片展示，取消旧 Logo 的单色 mask、反色等处理。深色模式也保持白底圆形头像，不能把小熊变成单色剪影。
- 延续已确定的黑白灰 UI，仅 Logo 保留原色；不将页面整体改成蓝色或米色。
- 更新缓存版本和实际引用；旧 Logo 无引用后删除，不保留两套在用品牌。

### 桌面品牌与升级兼容

- 开发启动和打包安装后的用户可见名称均为 Noria，包括窗口标题、Dock 悬浮名称、任务栏、安装包及应用文件名。
- 保持现有 `appId`、内部包名、协议、用户目录和密钥存储身份。当前 `app.setName('个人工作助手')` 承担兼容职责，不直接改名；显示品牌通过窗口与应用包元信息处理。
- 现有会议、录音、转写、模型、API Key、公司登录和声纹缓存继续可读。不创建一套空数据目录，不引入重复的系统密码提示。
- 开发启动器继续保留 Electron 可执行文件与签名策略；不为改名重新签名或修改二进制。安装、卸载和包检查中的路径须与新显示名称一致。

## 边界条件

- 仓库名仍为 `work-assistant-agent`，技术包名、`PAA_*` 环境变量、数据库、API 路径和部署目录不随品牌更换。
- 保留包含旧内部名称的兼容路径说明；历史 Spec、提交记录和已有用户聊天不批量改写。
- 桌面游客模式和离线使用不变；Web 断网、任务恢复和权限行为不变。

## 技术约束

沿用 React、Web CSS Modules、独立桌面样式和共享品牌资源。只调整品牌展示、资产、元信息、相关文档与受影响的校验，不新增认证接口或数据库迁移。

## 兼容性要求

已有 URL、账号、权限与业务行为保持兼容。允许安装包文件名变为 Noria；内部身份保持稳定，macOS／Windows 升级不能形成另一套应用数据。
