# 桌面公司连接与员工声纹

## 目标与现状

原有桌面在转写完成后区分会内说话人并允许手动命名；公司 Web 已有账号密码、钉钉登录和管理员权限。扩展为公司统一登记声纹、桌面按权限同步、录音中本地匹配员工姓名。产品取舍见[公司声纹决策](../../.ai/decisions/0011-company-agent-direction.md#桌面登录与公司声纹)。

## 功能与边界

- 桌面默认可作为游客使用，不要求后端在线，保留现有录音、转写、纪要、说话人区分、手动命名及本地资料。
- 桌面公司连接允许填写自托管服务地址，不写死 IP；正式环境有效 HTTPS，本地开发允许 loopback HTTP。复用公司的账号密码／已启用的钉钉登录，通过系统浏览器授权桌面，凭证不进入 renderer 或日志。不将 Web 页面注入桌面可信页面。
- Web 提供管理员声纹管理：选择本公司成员，上传单人录音并确认本人知情授权；显示处理、就绪、失败状态及可操作错误，支持替换／删除。覆盖员工及可能主持会议的管理员本人。只允许管理员读取、管理或同步公司声纹，跨公司不可访问；用户修改角色、停用或会话撤销后不得获得新的服务端访问权限。
- 声纹由固定预训练模型提取，不逐人训练。中文／英文采样均可登记；用多段有效特征改善鲁棒性。原始录音私有保存，模板记录模型／预处理版本；版本不兼容不得静默匹配。上传大小、时长、格式及后台处理资源有界，不阻塞 API 请求。
- Electron 只下载本公司必要的成员标识、姓名及声纹模板，在本机处理会议音频；不自动上传会议或桌面 API Key。新增公司声纹不进 Git。
- 已下载模板长期离线可用，无租约或定期强制联网。断网、重启、登录会话过期不清除模板、不阻止匹配。退出账号或主动清缓存删除本机公司声纹；不删除已有会议。缓存和凭证按服务／公司／账号隔离，切换不混用；已下载副本不支持服务端强制撤回。新同步仍需有效管理员身份。
- 录音时先显示临时说话人标签，累计足够有效语音、匹配可靠后立即更新姓名及对应发言。低置信度、外部访客、重叠或过短发言不强制分配姓名；不能将相似度百分比展示为准确率。支持人工纠正，后续自动更新不覆盖人工命名；会后全量分段与校正保持可用。
- 录音、ASR 和声音匹配互不阻塞；暂停／继续、停止、退出和故障均能收束后台任务，失败保留录音和文字。推理耗时跟不上时显示实际处理状态并继续处理已保存音频，不能假装实时或丢弃文字。

## 非目标

不做声纹登录、声音克隆、人员监控、会议自动上传或 Web／桌面全部数据同步；不承诺固定识别延迟或零误识。声纹仅用于发言标签，不能赋予员工权限。

## 验收

- [ ] 游客单独 `npm run dev` 可用；公司地址可配置，浏览器授权支持既有登录方式，授权取消／超时可恢复。
- [x] API 的管理员、公司、停用、重放、过期与参数校验有效，声纹管理和同步不依赖前端隐藏按钮实现授权。
- [x] 实际录音可登记为声纹；上传失败／模型缺失／处理失败可定位并重试，不展示假就绪状态。
- [ ] 桌面同步后可重启和断网识别；会话过期不清缓存，退出／清缓存即时停止使用公司模板，旧会议保留。
- [x] 录音中的临时标签与姓名更新、未知发言拒识、人工更正、会后校正形成闭环。
- [x] 用与登记录音不同的公开真人语音做真实模型验证，记录正确匹配、误认、拒识及耗时；测试结论不冒充公司会议准确率。
- [ ] Web／桌面新增页面沿用现有视觉与响应式；定向自动测试和实际日常桌面验证分别如实报告，Windows 未实测不写通过。
