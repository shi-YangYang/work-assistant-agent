# Spec 011 — Web 功能管理与交互完善

## 状态

**DONE · 2026-09-13。** 业务实现及返工后的独立验收已完成，结论为 [PASS](acceptance.md)。实际验证范围与未实测边界见验收记录。

## 背景、当前行为与目标

Web 已有员工上报、工作／报告、团队及设置。代码中的面包屑固定为两段；工作编辑名为“更正进展”，报告详情有“编辑草稿”，但缺少统一管理入口和删除；个人入口同时向管理员开放，成员列表也返回管理员。时区使用英文 IANA 输入框＋datalist，时间输入依赖原生控件。

聊天目前只有按用户聚合的一条消息流，没有业务会话实体；输入已有自动增高和 CSS 上限，但用户要求改为固定高度、内部滚动。目标是让现有功能易发现、角色职责清楚、控件行为一致，延续 [界面方向](../../.ai/decisions/0009-interface-design-direction.md) 与 [Spec 010](../spec-010-web-layout-and-responsive/spec.md) 的全宽布局。

工作助手是业务 Agent 的交互入口；会话组织交流，工作与报告承载可持续跟进的业务状态。管理员跨员工问答与 Agent 督办留到后续 Spec，本轮完善管理与多会话，不把助手永久限定为员工上报表单。

## 功能需求与目标行为

### R1 — 完整面包屑

- 按实际页面层级显示所有层级，例如“我的报告 → 某日日报”、“团队看板 → 员工姓名 → 某日日报 → 工作详情 → 原始上报”；不固定最多两段，不把无意义的“工作空间”算作业务层级。
- 祖先可点击返回，当前页不可点击并有当前页语义；保留父页的员工、标签、筛选与来源上下文，页面标题和面包屑同步真实对象名称。
- 根据页面归属与已校验来源构造，不把每次点击历史无限累加。刷新／直接打开也有授权范围内的合理父级；不能凭来源参数泄露其他员工信息。
- 窄屏可折叠中间层级，但通过省略入口能访问完整路径，当前层级与返回始终可达，不产生整页横溢。

### R2 — 我的工作与我的报告管理

- 工作／报告的列表及详情按权限提供一致、可发现的管理入口；菜单、确认和错误反馈沿用当前主题，鼠标、键盘和触屏均可操作。
- 工作编辑复用已有标题、进展、状态、阻碍、下一步及修订机制；报告编辑复用已有草稿，已提交版本的更正仍需再次提交后才对老板生效，不直接覆盖发布历史。
- 删除使用确认框说明对象与影响，成功后同步列表／详情／相关看板，详情返回正确父级；失败保留内容，重复点击不重复执行，版本冲突不覆盖并发编辑。
- **已确认**：员工不能删除本人已提交报告；已提交后再编辑形成更正草稿，也不能绕过此限制。管理员可删除本公司报告，包括已提交报告，并连带删除对应原始消息。删除权限不能只靠隐藏按钮实现，也不能跨公司操作。
- 员工可编辑／删除本人工作及从未提交的报告草稿；管理员可管理自己的工作。个人工作删除不默认连带清除已发布报告或原始消息；管理员的报告删除权限不等于代员工更改进展、确认或提交。
- 管理员删除报告时，原始消息范围按该报告实际引用的工作修订追溯，不能按员工或日期批量清空。原始文本、语音转写及附件内容须实际清理，不能仅隐藏列表。确认框展示关联影响，处理中的任务和已有缓存不得让材料重新出现。
- 同一原始消息被其他工作／报告引用时，清理该消息及附件，保留其他已确认业务记录，来源显示“原始消息已删除”；不递归删除其他工作／报告。草稿可见范围仍沿用原权限，不因新增删除能力自动公开员工私有草稿内容。
- 删除对象从对应普通列表、详情、看板和后续 Agent 输入退出；删除当前周期报告后不自动再生成，晚到结果不得恢复对象。本轮不提供回收站或恢复入口，不通过员工重新生成绕过管理员删除决定；可保留不含正文的删除标记用于阻止复活。

### R3 — 管理员与员工入口

- **已确认**：管理员保留“工作助手”和“我的工作”，默认仍进入团队看板；“我的工作”承载管理员自己的工作，后续可承载 Agent 提出的督办事项，不等于把员工工作混入个人列表。
- 管理员不显示个人日报／周报入口；本轮完成现有能力管理及多会话，管理员跨员工问答、Agent 创建督办事项另开后续 Spec。当前工具权限未实现跨员工问答，不能把保留入口表述为已有该能力。
- 员工保留工作助手、我的工作、我的报告及有权查看的设置。导航、命令查找、品牌入口和直接访问路由一致，不能仅隐藏菜单。
- 管理员继续通过团队上下文查看员工工作、已提交报告与原始上报，并按 R2 删除报告；员工不能跨员工操作。自己的助手与工作不授予其他管理员查看权限。
- 左下角角色名称分别显示“管理员”“用户”；底层仍为 `admin`／`employee` 两种角色，不新增角色，不改变员工业务称谓。
- 既有管理员账户、会话与历史材料不删除、不改角色。停止新建管理员个人报告，历史材料保留；个人消息处理与工作进展功能继续运行。

### R4 — 成员管理仅管理员工

- 成员列表、统计及添加入口仅包含员工；不展示管理员，也不从该入口新建管理员、停用管理员或重置其密码。服务端范围与前端一致。
- 现有管理员账户保留，自己的账户／密码仍在账户设置维护；本轮不新增管理员管理页面或第三种角色。员工既有添加、启停、重置临时密码规则保持。

### R5 — 中文时区与时间选择

- 公司时区改为实际可展开、可选择的控件，使用中文名称，例如“北京时间（UTC+08:00）”；底层继续保存 `Asia/Shanghai` 等 IANA ID，不改变报告周期算法。
- 中文显示应用于规则编辑、员工只读规则、报告时区及冲突展示；保留已有有效时区，非预设时区不能被悄悄替换。涉夏令时地区不显示错误的全年固定偏移。
- 菜单符合现有主题，贴合触发器、长选项可读，支持键盘／触屏。
- 日报／周报的生成时间和截止时间，点击输入区域或右侧图标都打开时间选择；保留键盘输入、清空、校验及分钟精度。浏览器不支持原生整框展开时提供可用替代，不只绑定一个无效调用。

### R6 — 工作助手输入与限制反馈

- 输入文字区采用固定高度：桌面默认 128px，窄／短屏默认 96px；高度可随视口断点调整，但不随内容增减。连续换行、长文本、粘贴及删除均不撑高输入区，超出后内部滚动。发送／附件／录音操作保持可达，其他页面的编辑框不一并改成固定高度。
- 移除输入框点击后的紫色 border／outline 效果，保持普通边界；若需要键盘焦点提示，使用与主题一致的中性提示，不影响其他表单控件。
- 删除底部常驻“图片最多 4 张／每张 5 MiB；语音最长 3 分钟／20 MiB”提示；图标只显示操作名称，不用悬浮提示重复堆放限制。
- 用户实际触及数量／大小／时长或不支持格式时，用现有风格弹窗说明本次具体限制和处理方式；不在打开输入框或正常添加时弹窗。关闭后保留文字和已有有效附件，一次操作不连弹多框。
- 限制数值及服务端校验不放宽；图片／语音不能混传。超过 180 秒的录音自动停止并保留可试听片段，提示达到时长上限；超限上传／识别失败保留已有原材料。网络错误、麦克风拒绝等继续有明确恢复入口，不伪装成容量超限。

### R7 — 多会话管理

- 管理员和用户均可新建、查看／切换、重命名、搜索和删除自己的会话；新会话默认“新会话”，首次发送后可用首条文字摘要命名，不为标题额外调用模型。列表按最近活动排序，长标题截断但可查看完整名称。
- 桌面在工作助手内提供会话列表与新建入口，窄屏使用可收起列表；不新增永久挤占内容区的全局侧栏。会话有稳定地址，刷新、直达、返回和面包屑对应正确会话；无会话时提供明确的新建入口。
- 旧消息完整迁入本人默认会话，保留 ID、附件、回复关系、来源和处理状态，不复制材料、不丢记录。每个会话分别保存消息与未发送草稿；切换不能把文字、附件或晚到结果发到另一个会话。正在录音时切换须明确处理，不能静默丢弃录音。
- 各会话聊天记录独立，不自动拼接其他会话的闲聊；同一用户已确认的工作仍是共享业务事实，Agent 可按权限检索和跟进。会话不是新的员工／公司权限边界，管理员不因此获得其他人的私有聊天上下文。
- 删除会话移除会话入口和未成为业务来源的消息；已被工作或报告引用的原始材料保留在对应业务来源中，不重新作为聊天历史加载。员工不能借删除会话绕过已提交报告的保护；管理员按 R2 删除报告时，再清理所关联原始材料。
- 删除前说明是否有业务来源保留；删除后不能继续发送、确认旧草稿或由晚到结果恢复该会话。访问他人会话、跨会话伪造回复目标、使用已删会话 ID 均由服务端拒绝。

## 非目标与兼容边界

不做云部署、Electron 功能变更、SaaS 注册／计费、批量管理、回收站、管理员组织层级、跨员工问答或 Agent 督办工具；不升级依赖或增加默认重型 CI。保留公司权限、人工确认、版本和幂等；原始材料删除后的引用行为遵循 R2／R7。

本机测试使用日常 Web 与现有配置，破坏性／竞态检查仅用独立测试数据，不删除用户资料或调用真实付费服务。真实实体手机与浏览器缺口按实际条件记录。

## 验收标准

- [x] 多级详情、来源跳转、刷新／直达和返回显示正确面包屑，手机完整层级可达。
- [x] 工作／报告管理入口一致；员工不能删除已提交报告，管理员删除报告及原始材料符合确认范围，失败／并发／共享来源处理正确。
- [x] 管理员与员工导航、直接路由及服务端行为符合 R3；团队来源查看不受误伤。
- [x] 成员管理只返回／创建／维护员工，现有管理员账户和资料保留。
- [x] 时区中文显示、点击选择和保存恢复正确；四个时间控件点击整框可选择，窄屏／键盘可用。
- [x] 左下角显示“管理员”／“用户”；连续输入至少 30 个换行、长文粘贴及删除不改变文字区固定高度，内部可滚动，点击无紫色边框，发送操作可达。
- [x] 无常驻输入限制 tip；实际超限弹窗明确、无重复弹框、有效草稿保留，服务端仍拒绝超限。
- [x] 两类角色均可完成会话增删改查、切换和刷新恢复；旧消息无损迁移，草稿／回复／异步结果不串会话，共享业务来源与删除权限正确。
- [x] 仅相关 Web／公司服务定向检查和独立验收通过，记录真实执行范围，不宣称未执行的平台或 CI 通过。
