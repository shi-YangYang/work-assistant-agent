## 实现

- 公司服务新增 `Conversation` 及增量迁移 `0003_conversations`，按原用户无损归入默认会话。新增会话列表／搜索／分页／重命名／删除，消息发送、回复和 harness 聊天历史绑定会话；已确认工作仍可跨会话检索，其他会话闲聊不能经工具读取。
- 工作／报告删除使用所有者行锁、版本校验和无正文删除标记。员工不能删除曾提交报告；管理员按报告修订来源清除原始消息、语音文字、附件及上下文，其他确认摘要保留且来源标记已删除。附件清理失败返回可重试状态，worker 维护继续清理。

- Web 增加助手内部会话导航、分会话草稿、完整面包屑及实际父级返回、列表／详情管理动作；成员管理只包括员工，管理员保留助手／工作并移除个人报告，身份显示为管理员／用户。
