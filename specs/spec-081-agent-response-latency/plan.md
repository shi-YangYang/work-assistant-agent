## 实施边界与顺序

本计划对应[提速需求](spec.md)。由一个 `high` 实施Agent处理耦合路径，再由新的 `high` 独立验收Agent检查；不创建调研子Agent或子Agent的子Agent。文档检查按S0，业务验证按实际改动风险选择范围。

1. **冻结基线和有限场景。** 核对真实模型配置、low／high参数、执行权限、源码SHA、数据与历史。复用既有隔离环境和真实浏览器驱动，不使用线上账号／数据；基线与候选使用等价但隔离的数据副本，避免前者写入影响后者。
2. **沿关键路径补齐归因。** 先利用现有日志，必要时扩展 `Timing` 的有界事件。真实基线取证必须包含实际传给模型的消息／工具定义及返回内容，以识别上游缺失、契约歧义和模型自身问题。生产不记录完整正文。已有合格基线直接纳入对照。
3. **选择有收益依据的系统修改。** 按对用户等待的贡献排序，先做少量必要修改；候选表列出保留条件与停止条件。网络／供应商问题不改；纯模型问题归档停止；原因不明的继续针对性定位，不增加模型审查。
4. **相称检查并真实对照。** 只运行修改涉及的模块检查，保持原调用预算，冻结输入与AB／BA顺序；同一次真实页面运行同时采集耗时、回复、回执与数据库结果，避免重复生成。
5. **独立验收与停止。** 验收Agent审查diff、归因、原始证据与边界，优先复核已有证据，不重复通过项。只对具体未决问题补最小检查。没有系统缺陷或收益不成立的候选允许“不修改”，如实说明。

## 数据流与优化位置

```text
Web发送／用户确认
  → API接受与入队
  → worker领取（租约与身份）
  → 材料／上下文准备
  → LangGraph主模型 ⇄ middleware ⇄ 工具／授权／业务操作
  → 合法正文发布与SSE → Web有效内容可见
  → 最终持久化／必要子任务 → 真实结果可用
```

每次模型和工具调用关联其父任务及作用。主任务、报告／文件子任务分别完成时记各自结果；用户等待确认的间隔从系统处理时间中分开。计时使用各进程单调时钟计算本地时长，跨进程时间关联记录墙钟及误差，不能直接比较无共同起点的相对值。

| 候选 | 需要先拿到的证据 | 允许的方向 | 不能省略 |
| --- | --- | --- | --- |
| 多余模型往返 | 完整请求与回执表明已有明确合法下一步，程序仍多走一轮 | 修现有流转、工具描述／参数／结果，复用已有等待和回执结束入口 | 用户尚未完成的回答需求、必要澄清与授权 |
| 上下文／Schema开销 | 分角色输入体积、重复片段与准备耗时 | 合并重复治理内容、复用不可变序列化结果 | 原文事实、字段身份、条件、来源版本、恢复状态 |
| 重复准备／查询 | 同一有效输入在关键路径重复处理，且有失效依据 | 同请求复用、版本约束缓存、独立只读准备并行 | 权限撤销、源数据变化、并发写入冲突检查 |
| worker等待 | 空闲轮询而非积压或锁占用造成可测延迟 | 评估既有设施唤醒并保留漏通知恢复 | 领取锁、公平性、租约、每用户并发边界 |
| 发布／页面等待 | 已校验内容到可见之间有重复处理或额外等待 | 合并重复工作，优化消费与绘制 | 来源与权限校验、顺序、取消及会话隔离 |

不按候选数量考核完成度。避免在收益未确认前增加缓存体系、调度器、更多工具或提示规则。

### 每项结果的必填内容与停止条件

每个结果至少包含：场景／分支ID、fixture哈希、源码指纹、账号角色和执行模式、实际模型及推理参数、完整用户输入与后续点击、实际模型输入／响应和工具顺序、页面结果与准确对象链接、前后持久快照、逐条断言结论、首个有效输出／写入／最终可用耗时、模型与工具次数、重试／失败及证据路径。涉及下载补文件哈希和内容核对；涉及来源补实际版本／页码；无法获得的指标保留null和原因。

速度只在同一输入、来源、历史、权限和档位的基线／候选间比较；不同工具路径和冷暖缓存分层报告。受控故障耗时不混入正常真实模型速度均值，失败恢复的完整耗时不得删除首个失败。用户等待选择的时间与系统处理时间分列，不用加载动画、首次SSE包或queued替代有效交付。

某条失败先记录实际刺激、原始输入、程序路径、最终副作用，再区分实现缺陷、测试假设、环境故障、原因未定和已确认模型错误。确认模型错误后不补规则、不增加模型审核、不重跑到绿；该条仍为fail。扩展集合全部通过后才可宣布该集合质量通过，速度仍逐场景解释，不能从有限样本推断全产品准确率或全面提速。

测试设计已按S0检查场景数、引用、旧结论边界和diff。扩展执行按既有Spec实施／独立验收流程，复用相关本地用例和精确适用的既有证据，补真实流程缺口；不改写旧样本、既有验收结论或原始失败。达到冻结范围和相称验证后停止，不追加随机用例追求绿灯。
